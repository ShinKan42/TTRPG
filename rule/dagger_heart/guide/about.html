🎯 第一次玩？

什么是跑团？ 🎲

如果这是您 第一次跑团，建议先看看 "跑团怎么玩"

这里您只需要知道：

跑团就像一群人一起拍电影

您是主演，我是专属导演+编剧，故事由 您的选择 决定结局

您不是在看故事，而是在和朋友们 一起编写故事

什么是匕首之心？ 🗡️

匕首之心是一款 以共创叙事为核心 的奇幻角色扮演游戏

即使在战斗，也能随时提出行动，开启二元骰的对戏

我们每个人都根据骰面自主描述行动的细节，并说明如何体现成功程度

主题由我们决定——奇幻、科幻、现代、任何 IP——只要我们想讲，就能讲

共创思维 🎭

这是匕首之心的根本前提。
像即兴戏剧——我接你的戏，你抛我的戏，互相给对方创造空间

你 主动抛出事件。
每句话都是你把球抛出去，看对方怎么接

提示

如果你说"我不知道该做什么"——答案很简单：你的角色想做什么？

匕首之心适合有创作欲的人

创作欲是一份 邀请——你负责想故事要讲什么，系统负责让它在桌上发生

共建世界 🌍

世界没有预设。
匕首之心用 战役框架（Campaign Framework） 来启动

第 0 场时，我们一起讨论：

这个世界什么样的？有什么势力？什么危机？需要有什么规则？

  • 我们一起定制 专属规则
  • 我们一起填充 世设细节
  • 我们一起决定 故事方向

这桌讲什么故事，完全由我们决定

用现成的 IP 做改编团、从头新建一个世界、把几个设定混在一起玩，都可以

只要我们这桌的人想讲，就能讲

重要

核心规则 + 战役框架，才是完整的匕首之心

战役框架决定了所有风味——故事、规则。
最大的影响是：怎么看待世界，以及怎么经历/游玩世界

叙事流动性 💫

二元骰决定的是 谁拿到叙事资源——希望骰高、资源归玩家；
恐惧骰高、资源归 GM

资源就是用来推进故事的：加细节、定结果、推情节

行动和叙事是所有人+骰子共同拥有的

模块化构建 🧩

卡片组合

  • 种族——你是谁
  • 社群——你从哪里来
  • 经历——你经历过什么
  • 职业——你擅长什么
  • 领域——你的能力领域

五个模块 独立运作

选同一个职业的两个人
因其他模块不同
可以是 完全不同的角色

适合DIY

如果你想要造一张新卡片

  • 本质相同——五类模块共用同一套格式
  • 数值简洁——核心数值清晰，造新卡门槛低
  • 独立运作——改一个不影响其他模块
  • 试错成本低——不满意就换掉这一张

由于共创与留白
能力可以随心所欲设计
平衡起来相对容易
也没有太多世设的限制

❔ 怎么玩？

共创战役 🗺️

在匕首之心里，故事掌控在玩家自己的话语里

这句话分四个层面成立。

一层比一层细，也一层比一层贴身

游戏主题——开桌之前，全桌共笔

第 0 场，我们一起把世界搭起来

什么势力在角力，什么危机在逼近，这一季想讲一个什么故事

此后每一场冒险，都长在这片全桌亲手选定的土地上

角色能力——建卡之时，您一个人说了算

种族、社群、经历、职业、领域，五个模块自由拼装

能力卡从挑到配都在您手里

想要的效果没有现成的，就照公开格式自己做一张

动作描述——掷骰之后，画面按结果分配

骰子只回答两件事：成了几成，代价多大

成功是什么样子——根据成功等级，您描述有利于您的，主持描述不利于您的

那些画风上的不同，可以用同样的能力/数据，用不同的描述方式来表现出来

叙事——一言一语，桌上的每个人

场景里添什么细节，对话往哪边走，一件小事对角色意味着什么——每一句都算数

一个人接另一个人的话，不论 PL 还是 GM

故事就这样一句一句现场长成

从世界的样子到一句话的措辞——四个层面，全是玩家说了算

行动博弈 ⚖️

匕首之心没有先攻表，也没有轮次圈

桌面上的注意力聚在谁身上，谁就站在 聚光灯 下

想动就说，镜头跟着话走

出手，就是一次冒险

您描述行动，掷出二元骰——每一次出手，都可能失败，并把叙事移交出去

失败时，聚光灯交到主持手里

他做一次动作，局面随之转动——增援赶到、地板塌陷、身后的人亮出刀

交出去的镜头，一定会回来

主持的动作做完，聚光灯回到玩家手里

您的角色想动，随时再说一句

出手，也是赚希望点的时机

希望骰更高时，无论成败，您都收下 1 枚 希望点

冒险与收益，押在同一掷上

叙事经济 ⏳

二元骰产出两种点数：希望点归玩家，恐惧点归主持

双方都用各自的点数，把聚光灯拉到自己这边

主持这边：危机用恐惧点换

花恐惧点抢过聚光灯做一次动作

可以让更多敌人接连出手，也能启动标了恐惧消耗的强力招式

攒得越多，能换来的场面越大

您这边：转机用希望点换

1 枚希望点，替盟友掷一枚优势骰

3 枚，与另一位玩家发起一场接力掷骰

还可以动用经历给掷骰加值、激活职业的希望特性

点数在所有人之间流动

您的希望点，会变成队友骰子里的那一枚优势

玩家与主持之间，玩家与玩家之间，这些点数一直在流动

是的而且 🤝

「是的，而且」是即兴戏剧的老规矩：接住对方给的一切，再往上添一笔

匕首之心把这条规矩交给了骰子

骰面决定接法

希望骰更高——是的，而且：您如愿，还能再添彩

恐惧骰更高——是的，但是：事情照成，代价登场

两种都是前进，只是语气不同

故事是叠出来的积木

这个游戏的世界，一次又一次叙述互相叠起来的积木

您搭一句，桌上其他人搭一句，越搭越高

再厚的模组也预测不了下一句是谁说的

长成的样子，没有人提前见过

成果藏在细节里

积木的颗粒很小：一句台词、一个手势、一次角色塑造的小决定，都在往上摞

最后的故事不属于任何一个人，是桌上所有人共同努力的成果

💡 想要进阶？

进阶从来都不是技术，而是思维

IP 战役设计 📖

基础：用现成的战役框架开局，世界、势力、危机都是配好的

进阶：把心爱的作品搬上桌——这场战役的心跳，从您自己的热爱里跳出来

先问：您舍不得放下的是什么

那部作品里让您念念不忘的东西，一个人、一句话、一种透不过气的氛围，就是这场战役的心跳

设定、名字、地点都可以放下

只要那口气还在，原著就是您取之不尽的源头

把心跳带进第 0 场

第 0 场替这颗心跳发问：这样的世界里，什么势力在角力，什么危机正在逼近

答案全桌一起定，之后每一场，都从答案里长出来

跑到最后，连读过原著的玩家也觉得——这是属于这一桌自己的故事

角色画风设计 🎨

基础：在五个模块里各选一项，拼成一张能玩的卡

进阶：每组选项都按他会怎么选来填，填完的卡一看就知道是谁的

画风长在选择里

卡面说得清他的本领，说不清他遇到同一件事时，永远的那一种选择

他怎么说话，有什么习惯的小动作，危险来了第一反应偏向谁

这些都从同一个人身上长出来，才是画风

有了画风，角色可以被预期

决定来了，您第一感觉就知道他会怎么做，翻卡只是确认

桌上其他人也认识了他，知道往哪里给他留位置、怎么接住他

模块给他合法性，画风给他署名

全新画风思维 🖌️

基础：掷骰赢了，这一幕怎么成功，由您来描述

进阶：描述的时候，说他是怎么做到的，不照着卡上的通用效果念

卡片是素材，角色是成品

卡上印的是通用效果，谁拿来都一样

他怎么出手、怎么收尾、怎么落地——那是只有他会有的画面

每次成功，先想一句：他会怎么做到

答案在您心里，书里没有

随时都在创作

骰子决定赢了没有，您的话决定这一幕长成什么样子

叙述贴合您心里所想，这是规则交到您手里的一份自由

玩得久了，同一张卡在不同人手里，会变成完全不同的东西

一时说不细，先说他做了什么——桌上自然有人帮您接完

商议思维 💬

基础：主持提供保底，故事需要结果的时候，他总能给出一个

进阶：规则、细节、怎么发生，都可以摆上桌，全桌一起定

规则本来就留了一半给您

「与游戏主持人共同描述」是写进条款的话：倒下后局势怎么恶化、伤痕留下什么印记，一半由您来写

没写清楚的地方同理——这个经历用不用得上，这一骰要不要投、投了算什么

没有标准答案，只有这一桌的答案

把「更好玩」说出口

拿不准的时候，别等裁定，把想法摆上桌

大家一起定这件事怎么发生——「是的，而且」往上加一层，「是的，但是」事情照办、代价跟着来

这样定下来的东西，往往比一个人想的更好玩

积极沟通，积极发挥想象力——规则没写出来的部分，属于桌上每一个人

叙事积木思维 🧱

基础：每个人提出自己的叙事，说出自己想让什么发生

进阶：接住别人提出的叙事，在上面一层一层往上叠

别人搭的块，接住，指名它

有人随口添的细节，您在下一句话里点到它

它就成了全桌认可的事实，所有人都能在它上面继续搭

自己搭的块，留一个好接的面

说完一段，留一件悬着的事，身边的人接得上，积木才叠得起来

已经立在桌上的不拆——接住再往上搭，往往长出比原计划更好的路

眼里装着桌上已经有什么，手里随时准备递出下一块——搭到最后，没有哪一层只属于一个人
