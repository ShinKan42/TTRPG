🗡️ 职业选择

约 10994 字大约 37 分钟

❓ 常见问题

新人必看

想扮演动漫、影视、游戏里的角色，还是自己原创一个 OC？

选错职业了怎么办？

法术太多看不过来？

——先看这里。

我想扮演动漫、影视、游戏里的角色 / 自己原创一个 OC，怎么选职业？

这是 TRPG 最好玩的部分——去扮演你想成为的人。

你喜欢动漫、影视、游戏里的角色，想亲身体验他的故事？

或者脑子里有一个自己的 OC，想让他活过来？

这就是 D&D 最核心的玩法。

方法很简单：

  1. 先找 DM 聊。告诉他你想扮演什么样的角色——一个画面、一段故事、一种感觉都行。

DM 帮你把"感觉"翻译成职业和子职的组合，这是最快的方式。

  1. 再翻这页找方向。下面的核心简介帮你看每个职业的"手感"。

锁定两三个候选后，和 DM 确认细节。

几个方向举例：

角色意象推荐方向理由
用刀剑的武术家武僧气驱动连击，灵巧高速
跟魔鬼签约的力量型魔契师宗主加祈唤，契约换力
拳头说话的街头斗士拳斗士锐气加拳斗骰，越挫越勇
背后中箭的狙击手游侠偏好远程加战法分离
拿镰刀的死神战士/邪狱使武器精通切换加暗影主题

不必追求机制 100% 还原。

D&D 是 TRPG 不是 MOBA。

角色在战斗和社交中做出"像他"的选择，剩下的用扮演补。

选错职业了怎么办？

和 DM 聊。

大部分 DM 允许新人在前几场团后换职业——角色还没成型。

换一个不会破坏战役。

不要因为"选都选了"硬玩一个你不喜欢的角色。

菜刀职业在社交/探索场景里没事做怎么办？

这是真实困境，不是你的问题。

战斗外没有检定支持时，你的工具是角色的性格。

主动开口说话、主动做决定、主动跟 NPC 建立关系。

规则不给你骰子，但你仍然可以在故事里站出来。

施法者法术太多了看不过来？

先别翻全部。

想清楚你的角色是一个什么样的人——一个从书塔里出来的法师？

一个跟魔鬼做交易的人？

从角色概念出发，挑几个顺手的法术就够了。

深度玩家才需要翻完整法术列表。

多职业是什么？什么时候能做？

多职业是同时拥有两个职业的特性。

2024 PHB 规则下，角色等级 2 即可多职业（需满足对应属性要求）。

不建议新人首角色多职业——先玩明白一个职业，再考虑混搭。

这页没提到的子职和扩展内容呢？

D&D 有大量扩展书提供额外子职、专长、种族。

本页覆盖 2024 PHB 全部子职，外加主流扩展书的热门子职。

看到书上或资料站里本页没提的选项——自己查资料，确认机制后再选。

💭 核心简介

每个职业都有一个改变不了的核心机制底盘——

子职可以在这个底盘上转向，但底盘本身不变。

先看哪个底盘的玩法手感对味，再看子职怎么调方向。

战士组 ⚔️

野蛮人：面板强劲 →

狂暴提供面板优势。活用抗性、擒抱、摔绊、运动检定，直接创造机会。

战士：战术弹性 →

用 武器精通 切换不同武器应对局面。用 专长 模块化搭建打法。

武僧：一气多用 →

用 气 驱动连击和高速移动，短休回复。同一池子灵活用于攻击、防御、控场。

圣武士：誓言引导 →

誓言在扮演中决定你的底线和选择方向。

战斗中用 强令决斗、寻获坐骑 等专属法术创造战术机会。

专家组 🎯

吟游诗人：多才多艺 →

诗人激励 让队友关键判断更有把握。

多面手 让未训技能也有稳定表现。

法表涵盖治疗与各类功能性法术。

游侠：战法分离 →

面板足够应付战斗，法术位全留给功能。

技能多一项，六边形什么都稍强。

游荡者：灵巧操作 →

灵巧动作 提供丰富走位选择，技能专精 让拿手绝活稳得离谱。

偷袭骰 不止打伤害，还能换出多种额外效果。

法师组 🔮

术士：法术塑形 →

术法点 提供更多法术使用次数，超魔法 强化每个法术效果。

魔契师：祈唤组合 →

祈唤 自由组合，既有强大常驻也有战术选项。

法术位短休回复，施法节奏快。

法师：法术智斗 →

根据不同情景选择不同法术，用智斗在局上做设置。

神术组 ⛪

牧师：领域引导 →

领域 决定战斗路线和领域法术。

神术表每天可换准备。

队伍缺什么补什么。

德鲁伊：荒野形态 →

荒野形态 提供多种形态应对各类局面。自然法术控场治疗兼顾。

结社 决定专攻路线。

奇械师 ⚙️

奇械师：道具大师 →

靠制作和附魔道具应对各类问题。

半施法搭配工具专精，提前准备决定上限。

合作内容职业 🤝

注意

⚠️ 以下职业来自第三方合作出版物，非 D&D 官方核心职业。需 DM 批准才能使用。

血猎手 ⚙️：以血换力 →

鲜血秘法 激活血仪和血咒，消耗生命值换取额外伤害和战场控制。

邪狱使 ⚙️：炼狱特工 →

禁令 标记敌人制造弱点，缄印 积累额外伤害。九狱精英特工的全能工具箱。

铳士 ⚙️：风险射击 →

风险骰 驱动射击战技，消耗骰子施展弹道花招。火药加胆识的赌徒型战士。

拳斗士 ⚙️：街头韧劲 →

锐气 驱动拳脚连击和耐力回复，拳斗骰 为打击附加额外伤害。

🎯 灵魂问卷

不用全部看完。读到一条让你觉得「对，我角色就该这样的」——那就是你的职业。

🟢 简单上手 · 🟡 中等深度 · 🔴 复杂操作

🟢 简单上手

动作如潮：所有人还在计划。

你已经动了——砍倒面前的，转身解决第二个。

一回合干完别人两回合的事。

这是你的角色吗？

→ 战士

武器精通：敌人换了三波，你的武器也换了三种。

每次你都有刚好克制当前对手的打法。

这是你的角色吗？

→ 战士

偷袭：你一直在等。

等你出手的那个角度——没有甲片挡着的那个角度。

等到了，一刀就够了。

这是你的角色吗？

→ 游荡者

灵巧动作：他们五个人围着你。

你没穿重甲——但你从他们中间穿了过去，一个擦伤都没有。

整片战场在你脚下像平地。

这是你的角色吗？

→ 游荡者

🟡 中等深度

狂暴：你一把抓住最前面那个，连人带甲摔在地上。

后面的人愣了一秒——这一秒就够了。

这是你的角色吗？

→ 野蛮人

伤害抗性：对手一刀砍在你身上，你没事。

你咧嘴笑了一下——根本不痛。

然后你回手把他拍在了地上。

这是你的角色吗？

→ 野蛮人

誓言坚守：所有人都觉得该撤退了。

你知道他们是对的。

但你选了留——因为你发过誓。

这是你的角色吗？

→ 圣武士

强令决斗：你指向最强的那个敌人。

一道光锁住了他——他只能跟你打。

你把最危险的对决揽到了自己身上。

这是你的角色吗？

→ 圣武士

荒野追猎：你追踪猎物追了三天。

在它最放松的那一瞬间，你出手了。

一箭就够了。

这是你的角色吗？

→ 游侠

功能法术：你的箭解决战斗。

但这次需要的不是箭——你需要让整支队伍无声无息穿过敌营。

或者追踪两公里外的人。

你把法术位全留给了这种时刻。

这是你的角色吗？

→ 游侠

神术兜底：全队要倒了。

治疗用完了，所有人都觉得没希望了。

你一步上前，用最后的手段把所有人拉了回来。

这是你的角色吗？

→ 牧师

法术调度：你每天坐下来准备法术的时候，想的不是「今天要打什么」。

想的是「队伍今天可能会缺什么」。

这是你的角色吗？

→ 牧师

法术准备：你坐下来准备今天的法术。

你不知道会遇到什么——所以每一种你都备了一手。

蛛行术、侦测魔法、防护善恶……万一用上了呢。

这是你的角色吗？

→ 法师

法术智斗：你面对一个问题，翻开法术书——答案在里面。

不是用刀解决，是用脑子。

你总有那把刚刚好的钥匙。

这是你的角色吗？

→ 法师

🔴 复杂操作

诗人激励：局势要崩了。

你一句话让全队重新振作，一个动作让队友打出了关键一击。

这是你的角色吗？

→ 吟游诗人

法表功能：你既不是专职治疗也不是专职施法。

但你什么法术都有一点——队伍缺什么，你就掏出什么。

这是你的角色吗？

→ 吟游诗人

术法点：你的一天比别人的长。

当他们的法术位用光了，你从体内又换出了几发——别人见底了，你还有。

这是你的角色吗？

→ 术士

超魔法：同一个法术，别人只能打一个目标。

你让它同时命中了两个——只因为你想。

你的法术不是固定输出，是你的可调武器。

这是你的角色吗？

→ 术士

荒野形态：所有人都以为你只是个施法者。

你变成了一头熊冲进敌阵，又变回人形放出治疗——没人料到你能这样做。

这是你的角色吗？

→ 德鲁伊

自然法术：你伸手一按——地面裂开，藤蔓缠住了追兵。

整支队伍安全撤走了。

自然听你的。

这是你的角色吗？

→ 德鲁伊

一气多用：你用气做了三件事——打了面前的敌人，躲开了背后的攻击。

把倒地的队友拉了起来。

这是你的角色吗？

→ 武僧

高速移动：你一回合移动了别人三倍的距离。

穿过整个战场打了最远的那个，又跑回来守住队友。

你的速度就是你的武器。

这是你的角色吗？

→ 武僧

祈唤常驻：你走进一间暗室，不用点灯——黑暗对你来说跟白天一样。

你捡起桌上的信，远古文字写的，你直接读懂了。

从签契约那天起，这些就常驻在你身上。

这是你的角色吗？

→ 魔契师

短休回复：别人的法术位打空了，得等一整晚。

你坐下来歇了一个小时，站起来——又能放了。

这是你的角色吗？

→ 魔契师

道具大师：队伍被困在一扇打不开的门前。

你从包里掏出一个你上个月做的小道具——刚好能解决这个问题。

这是你的角色吗？

→ 奇械师

附魔灌注：你的剑不是普通铁器——你在上面刻了符文，打出去附带闪电。

你的盾不是普通铁盾——你注入了魔力，它能弹开法术。

你让普通装备变成魔法装备。

这是你的角色吗？

→ 奇械师

🔧 进阶玩法

选好职业了？深入了解它的进阶机制。

菜刀职业的战斗外困境

战士、野蛮人、武僧——这些职业的机制工具箱几乎全在战斗里。

社交团、政治团、解谜团里，规则不给你掷骰子的能力。

你的工具是角色的性格和你的扮演。

选之前想清楚：这个人在没有检定支持的场景里，能不能站出来。

施法者的入场费

法术是你角色的一部分。

如果你对角色有清晰的画面——选法术很简单，法术列表自然帮你筛选。

但如果角色概念还模糊，你得反过来翻整本法术列表找灵感。

这是一件需要耐心和精力的事。

战士组 ⚔️

战士

动作如潮：每短休一次额外完整动作。

决定爆发时机——第一回合开还是留着补刀，影响整场节奏判断。

武器精通切换：可选多种 武器精通，不同武器对应不同效果（推击/横扫/穿刺等）。

根据敌人类型换武器，每次都有克制手段。

专长搭建：战士特长比其他职业多。每个 专长 是独立模块，决定打法方向。

不是子职一次性定死，是逐步搭建。

野蛮人

狂暴物理优势：狂暴期间 力量检定 优势——不只是打伤害。

擒抱、摔绊、运动检定全部碾压。用身体直接创造机会。

伤害抗性：狂暴期间 钝击/穿刺/挥砍 减半。

面板硬度翻倍，可以硬吃别人吃不了的伤害。

狂暴资源管理：狂暴次数有限，每次开关是资源判断。

提前结束战斗省一次狂暴，拖延战斗可能断狂暴裸奔。

武僧

气池分配：同一个 气 池子用于攻击（疾风连击）、控制（震慑拳）、位移（脱离/冲刺）。

每回合都在做资源分配判断。

高速移动：移动速度随等级增长，无甲移动 提供额外速度。

免费 脱离/冲刺 不触发借机攻击，走位成本极低。

短休节奏：气 短休全回。

施法节奏和其他职业不同——短休后满状态，鼓励队伍提高短休频率。

圣武士

至圣斩：把 法术位 转化为额外 光耀伤害。

决定何时倾泻（首领战）何时保留（续航），是核心资源判断。
