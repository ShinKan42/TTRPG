💭 核心简介

每个职业都有一个改变不了的核心机制底盘——

子职可以在这个底盘上转向，但底盘本身不变。

先看哪个底盘的玩法手感对味，再看子职怎么调方向。

战士组 ⚔️

野蛮人：面板强劲 →

通过狂暴提供的面板优势，活用抗性、擒抱、摔绊、运动等方式直接创造机会。

战士：战术弹性 →

用武器精通切换组合不同武器应对局面，用专长模块化搭建自己的打法。

武僧：一气多用 →

用气驱动连击和高速移动，短休回复，同一池灵活用于攻击、防御、控场。

圣武士：誓言引导 →

誓言在扮演中决定你的底线和选择方向。

战斗中用强令决斗、寻获坐骑等专属法术创造战术机会。

专家组 🎯

吟游诗人：多才多艺 →

诗人激励让队友关键判断更有把握。

多面手让未训技能也有稳定表现。

法表涵盖治疗与各类功能性法术。

游侠：战法分离 →

面板足够应付战斗，法术位全留给功能。

技能多一项、六边形什么都稍强。

游荡者：灵巧操作 →

灵巧动作提供丰富走位选择，技能专精让拿手绝活稳得离谱。

偷袭骰不止打伤害，还能换出多种额外效果。

法师组 🔮

术士：法术炮台 →

术法点提供更多法术使用次数，超魔法强化每个法术效果。

魔契师：祈唤组合 →

祈唤自由组合既有强大常驻也有战术选项。

法术位短休回复施法节奏快。

法师：法术智斗 →

根据不同的情景选择不同的法术，用智斗在局上做设置。

神术组 ⛪

牧师：领域引导 →

领域决定战斗路线和领域法术。

神术表每天可换准备。

队伍缺什么补什么。

德鲁伊：荒野形态 →

荒野形态提供多种形态应对各类局面，自然法术控场治疗兼顾。

结社决定专攻路线。

奇械师 ⚙️

奇械师：道具大师 →

靠制作和附魔道具应对各类问题，半施法搭配工具专精，提前准备决定上限。

🎯 灵魂问卷

不用全部看完。读到一条让你觉得「对，我角色就该这样的」——那就是你的职业。

🟢 简单上手

你不需要花哨的东西。你给我一个目标，我正面解决它。干净利落。

这是你的角色吗？

→ 战士

敌人换了三波，你的武器也换了三种。每次你都有刚好克制当前对手的打法。

这是你的角色吗？

→ 战士

没有人在意你——直到你从暗处现身，一击命中要害，战斗结束了。

这是你的角色吗？

→ 游荡者

门锁着。陷阱拦着。卫兵守着。你一个一个处理掉了——没人发现你进去过。

这是你的角色吗？

→ 游荡者

🟡 中等深度

战斗开始了。你没想策略——你看到最强的那个，怒吼一声冲了上去。谁来谁倒，谁也拦不住。

这是你的角色吗？

→ 野蛮人

对手一刀砍在你身上，你没事。你咧嘴笑了一下——根本不痛。然后你回手把他拍在了地上。

这是你的角色吗？

→ 野蛮人

所有人都觉得该撤退了。你没有退。你的誓言不允许你退。

这是你的角色吗？

→ 圣武士

你说了一句「以我的名义」——然后你真的做到了。

这是你的角色吗？

→ 圣武士

你追踪猎物追了三天。在它最放松的那一瞬间，你出手了。一箭就够了。

这是你的角色吗？

→ 游侠

你在野外比在城里自在。你能读脚印、能预测天气、能在没有补给的情况下活一个月。

这是你的角色吗？

→ 游侠

全队要倒了。治疗用完了，所有人都觉得没希望了。你一步上前，用最后的手段把所有人拉了回来。

这是你的角色吗？

→ 牧师

你每天坐下来准备法术的时候，想的不是「今天要打什么」——想的是「队伍今天可能会缺什么」。

这是你的角色吗？

→ 牧师

你坐下来准备今天的法术。你不知道会遇到什么——所以每一种你都备了一手。蛛行术、侦测魔法、防护善恶……万一用上了呢。

这是你的角色吗？

→ 法师

所有人都卡住了。你从记忆里翻出一个你几个月前读过、从没用过的法术——刚好是答案。

这是你的角色吗？

→ 法师

🔴 复杂操作

局势要崩了。你一句话让全队重新振作，一个动作让队友打出了关键一击。

这是你的角色吗？

→ 吟游诗人

你什么都会一点。队友打不开的锁你去开、说不通的人你去谈、认不出的东西你去认。

这是你的角色吗？

→ 吟游诗人

同样的法术，你比别人放得更多、更强。而且你还能再来一次。

这是你的角色吗？

→ 术士

你从来没学过这个法术。但它就在你的血液里——天生就会。别人要学的，你生来就会。

这是你的角色吗？

→ 术士

所有人都以为你只是个施法者。你变成了一头熊冲进敌阵，又变回人形放出治疗——没人料到你能这样做。

这是你的角色吗？

→ 德鲁伊

你不需要城市。森林就是你的家。你听得懂鸟在说什么，知道哪条河里有鱼。

这是你的角色吗？

→ 德鲁伊

你用气做了三件事——打了面前的敌人，躲开了背后的攻击，把倒地的队友拉了起来。一气多用。

这是你的角色吗？

→ 武僧

你没穿铠甲，没拿武器。空着手走进战场——出来的时候，你赢了。

这是你的角色吗？

→ 武僧

你看得穿黑暗。读得懂任何文字。不需要睡眠，不需要呼吸——从你签下契约那天起，这些能力就没有离开过。

这是你的角色吗？

→ 魔契师

你的力量不是学来的——是换来的。你知道代价，但你接受了。

这是你的角色吗？

→ 魔契师

队伍被困在一扇打不开的门前。你从包里掏出一个你上个月做的小道具——刚好能解决这个问题。

这是你的角色吗？

→ 奇械师

你拿起一块废铁、几根线、一个下午——做出了一个能改写局面的东西。

这是你的角色吗？

→ 奇械师
