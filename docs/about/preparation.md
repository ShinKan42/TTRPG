<a id="ax-跑团是什么"></a>
## 🎬 **跑团是什么？**

:::

跑团是一群人围坐一张桌，用语言和骰子经历一个故事的游戏。

::: card

像一群人一起拍电影——你是主演，我是导演兼编剧，故事由 ==你的选择== 决定结局。

:::

它的一切发生在 ==对话== 里：

::: center

> 你说出你的角色想做什么\
> 我告诉你世界怎样回应\
> 输赢不定的事，掷骰子裁决

:::

你是故事的主角，我演 ==你之外的一切==——你遇到的每个人（NPC）、每一件事，都在我这边应答。

:::: card

#### 🎲 跑团五件事

::: card

##### 🗺️ 主持人是你的导游

- 提供场景、扮演 NPC、裁决规则
- 目标是帮助你的角色迎接挑战、获得成长

:::

::: card

##### 🔧 规则是工具，不是枷锁

- 只要大家 ==玩得开心==，规则可以随时调整甚至忽略
- 重点是 ==创意、想象力和合作==，不是死记硬背条文

:::

::: card

##### ✍️ 故事是大家一起写的

- 你可以随时提出「我想加入 XX」「我不希望出现 XX」
- 故事会因为 ==角色的每一个决定== 改变走向

:::

::: card

##### 👤 角色是你自己的投影

- 设计角色时，想想 ==自己最在乎什么、最害怕什么==
- 只有你 ==真心在乎这个角色==，游戏才能让你投入

:::

::: card

##### 🔔 安全第一，快乐第二

- 任何时候觉得不舒服，==打断铃== 随时喊停
- 冲突是角色成长的机会，不是玩家之间的对立

:::

<a id="ax-流程"></a>
## ⏱️ **单次跑团流程**

**全程约 8-10 小时**（包含车卡、用餐时间）

:::

:::: card

#### 📅 单次跑团时间线

::: card

##### 🕐 预热阶段（1-2 小时）
- 角色创建（车卡）
- 原则说明与期望对齐
- 故事引入

:::

::: card

##### 🎭 游玩阶段（6-8 小时）
- 每个情景 1-2 小时：探索、扮演、悬疑、讨论、战斗
- 临近离场建议 ==提前 1-2 小时== 告知商议

:::

::: card

##### 📝 复盘阶段
- 剧情回顾
- 答疑解惑
- 反馈微调

:::

::::

::: tip 日程提醒
跑团是长时间沉浸体验，请预留充足时间，做好往返、就餐等安排

<a id="ax-清单"></a>
## 🧳 **新手准备清单**

**记住这 5 点，就能轻松开始**

:::

:::: card

::: center

### 💭 **1. 心理准备：命题的舞台**

:::

- 跑团像 ==自由的第二人生模拟==，没有固定路线
- 情感体验是核心：选择 ==你会在乎、会动情== 的角色
- ==打断铃== 或安全词随时可暂停，安全第一

::::

:::: card

::: center

### 💬 **2. 沟通期望：让我了解你**

:::

- **喜欢什么**——角色塑造、社交政治、逻辑解谜、战斗挑战？
- **不想遇到什么**——提前说明雷区，我会全力避开
- **想加入什么**——大胆提出元素，==Rule of Cool==：够酷就可能实现

::::

:::: card

::: center

### ✏️ **3. 角色设计：先人物后数据**

:::

1. 最 ==在乎/害怕== 什么？
2. 用一个词/一句话描述 ==人生命题==
3. 希望面临什么样的 ==挑战==？
4. ==惯用什么==面对困难？

已经有玩了很久的 ==原创角色（OC）==，直接带来。

没有的话，拿你最喜欢的角色当底子，捏一个这个世界的版本。

::: center

> **数据规则交给我**，你专注思考**角色的人生**

:::

::::

:::: card

::: center

### 🤝 **4. 团队共识：在场一致原则**

:::

- 只要 ==大家都同意、玩得开心==，规则可调整、故事可回退
- 冲突是角色成长机会，不是玩家对立
- ==游戏一定能进行下去==，且尽力使其值得玩味，死亡不一定是终点

::::

:::: card

::: center

### 🎒 **5. 实际准备：旅程的奢侈**

:::

- 预留完整时间（8-10 小时）
- 保持开放、创意的心态
- 准备好享受属于这群人的独特故事

## ⚖️ **是 & 不是**

:::

先说清楚：每一组对比 ==两种都是真玩法==，都有人带得很好——区别不在好坏，在你要哪种。

::: center

<a id="ax-剧情"></a>
### 📕 **剧情**

:::

:::: card-grid

::: card

#### ✅ 这张桌是

==没有写好的故事==。

开团前，连我也不知道这场团会走向哪里。

要什么剧情，就得我们 ==所有人一起争取出来==。

:::

::: card

#### ⚪ 不是那样的

走进一个主持人备好的故事，精彩处早有安排，像一场好戏。

你能影响细节，但故事的起承转合，开团前就写好了。

:::

::::

::: center

<a id="ax-裁决"></a>
### 📜 **裁决**

:::

:::: card-grid

::: card

#### ✅ 这张桌是

==按道理判==，合理就发生——想做就 ==直接做==，不用先问「可不可以」。

规则没覆盖的地方当场议定，议定了下一场还算数。

想要的角色能力，只要有 ==代价==，当场 ==DIY 一条规则==——==规则轻一点，位置让给角色==。

:::

::: card

#### ⚪ 不是那样的

按规则书判，白纸黑字。

条文没写的不轻易发生——每张桌跑出来，都是同一场冒险。

:::

::::

::: center

<a id="ax-世界"></a>
### 🌍 **世界**

:::

:::: card-grid

::: card

#### ✅ 这张桌是

你没看见的地方，==人和事照样在发酵==。

你做过的事、说过的话，世界都 ==记得==，会长成后面的故事。

失败也是世界动了一下：==门没撬开，但声响有人听见了==。

:::

::: card

#### ⚪ 不是那样的

世界在你需要的时候醒来。

剧情没走到的地方，不必惦记。

:::

::::

::: center

<a id="ax-角色"></a>
### 🎯 **角色**

:::

:::: card-grid

::: card

#### ✅ 这张桌是

==你的角色是主线==——你和我的 NPC 都按各自的动机行动，==模组围着你们改==。

:::

::: card

#### ⚪ 不是那样的

模组的剧情是主线，你的角色跟着剧情走。

你在既定的章节里做选择，体验作者写好的冒险。

:::

::::

::: center

<a id="ax-善恶"></a>
### ☯️ **善恶**

:::

:::: card-grid

::: card

#### ✅ 这张桌是

我不审你的角色是善是恶——世界里的人会按各自的道理回应他：==有人怕他，有人记他的账==，有人找上门。

我盯的只有一件：==桌上的人玩得舒不舒服==。

:::

::: card

#### ⚪ 不是那样的

角色是善是恶，先过主持人这一关——谈不拢，这个角色就上不了桌。

这么筛有它的道理：队伍得能合作，难关才推得顺。

:::

::::

::: center

<a id="ax-资料"></a>
### 🗂️ **资料**

:::

:::: card-grid

::: card

#### ✅ 这张桌是

模组在我手里是原料——每一团都在改，==你读过也猜不到这桌会发生什么==。

看不看模组、看多少，==你自己定==——和角色走什么命运一样，我不替你拿主意。

看了有看的玩法：==提前把他揣摩深，资料吃透，角色反而立得准==。

到了桌上，决定怎么做的时候，只认 ==你的角色知道什么==。

:::

::: card

#### ⚪ 不是那样的

看不看，==由桌规定死==：有的桌禁读，保惊喜——==第一次见的反应才真==。

有的桌按页发料，角色该知道什么，==由桌替角色安排==。

两种都是负责任的做法——区别只在这份选择 ==握在你手里，还是他手里==。

:::

::::

::: center

<a id="ax-强弱"></a>
### 💪 **强弱**

:::

:::: card-grid

::: card

#### ✅ 这张桌是

==强弱在这桌不是问题==：强有强的戏，弱有弱的戏——受难与脆弱，反而更有戏。

想演强者，我们一起把他建强，把强度 ==玩痛快==。

痛快之后，我们一起去碰他软下来的地方：==他害怕什么、在乎什么、愿意拿什么去换==。

:::

::: card

#### ⚪ 不是那样的

主持人盯着队伍平衡——谁太强就削，谁太弱就扶，强度对齐了才好出团。

这份公平让每个人都有打点、每场战斗都算得清——角色被调来调去，最后桌上站着的，就不是他了。

:::

::::

::: center

<a id="ax-巧劲"></a>

### 🪄 **巧劲**

:::

:::: card-grid

::: card

#### ✅ 这张桌是

强度不止一把尺——==看着没伤害的本事，用对位置比剑还狠==。

幻术、侦查、把守卫说动——这些 ==不上战报的招==，在这桌都是真功夫。

同一条法术，有人只读出伤害数字，你读得出 ==人心、破绽、退路==——读出什么，就能玩出什么。

:::

::: card

#### ⚪ 不是那样的

强度有现成的 ==阶梯==：什么强什么弱，查表一目了然。

站上阶梯上层，==数值撑着你走==——出团有底气，队伍好搭。

这份确定让配置好谈、节奏好算——只是偏门的巧思，==排不进那张表==。

:::

::::

::: center

<a id="ax-内心"></a>
### 🪞 **内心**

:::

:::: card-grid

::: card

#### ✅ 这张桌是

==面具里只有你==——他怎么想、信什么、怎么变，==你说了算==。

我会 ==试着主动==：递进风雨、抛出难题，去碰他心里在乎的事。

碰多深、这一步走不走，==我们最好先沟通==。

:::

::: card

#### ⚪ 不是那样的

主持人替你的角色写心事、安排顿悟——戏很满，起伏都踩在点上。

连角色的感动都替他安排好，你只要跟着走。

<a id="ax-细则"></a>
## 🃏 **带团细则**

**核心承诺**：追求角色独特的故事，期待你的角色用自己的方式，开创不一样的展开

:::

::: card

#### 📚 **故事第一，规则第二**
- 关注 ==发生了什么==，而非规则条框
- 每场战斗都有故事意义，**不会为难度而难度**
- 我是 ==共同完成故事== 的伙伴，不是对手

:::

::: card

#### ⭐ **角色驱动**
- 符合角色特点时，协助完成 ==高光时刻==
- 无法塑造独特故事时，**增加合理阻力，挑战角色**
- 长团中 ==挖掘情感痛点==，定制个人故事线

:::

::: card

#### 🚀 **你的选择优先**
- 模组改造为 ==开放世界模拟==
- 相比既定叙事，更鼓励创造自己的路径
- ==Rule of Cool==：够酷、够扮演、大家想要，就值得实现

:::

::: card

#### 🛡️ **选择自由，责任明确**
- 玩家选择之外的原因导致游戏无法继续，是 ==我的责任==
- 角色可以 ==自由选择、承担后果==
- 失败也可以是故事——死亡也可能是复活旅途的开始

:::

::: card

#### 💎 **资源丰富，策略多样**
- 倾向于给予 ==过量资源==
- 相应提升难度
- 目的是 ==丰富策略选择==

:::

#### **🎭 角色扮演的本质**

跑团是自行创作角色、代入情感进行扮演的游戏。

尽管我会尊重你的决定与期望，仍可能碰上激起情感的情境——这是游戏魅力的一部分。

也正因此需要提前沟通排除介意的内容。

---

#### **🆓 高自由度的体现**

与电子游戏（CRPG）不同，跑团（TTRPG）**没有程序固定的规则与故事**。

作为人类主持，我能即时根据你的想法，运用**游戏策划、编剧能力**创造全新反馈。

---

#### **🎨 OC 创作的绝佳场域**

这正是跑团非常适合 OC（原创角色）创作的原因——创造并体验独特角色本就是游戏初衷。

---

#### **🤖 为什么不是 AI 带团？**

AI 确有**即时演算**能力，但目前：

**上下文记忆整合**仍欠缺。

回答缺乏足够**选择空间与弹性**。

**博弈设计与情感调动**能力不足。

---

#### **⚙️ 规则与模组的搭配**

【规则】=【玩法】，【模组】=【故事】。

只要主题适配即可**相互搭配**——用喜欢的规则跑喜欢的故事。
