## **📜 总则**

### 发牌与持有

- 由 **DM 发牌**：角色做出特别有风味的事情、完成一次角色塑造的小成就时发放。
玩家==可以自荐==，桌上一句商量，==决定权在 DM==。
- **每名玩家至多持有 2 张**。
手上满员时，==先打掉或兑换一张，才能领新的==。
- 两副牌分工：==本页塔罗牌用于日常共创==。
**万事万象无常牌**==在命运重大转折时抽取==，见另页。

### 打出（一条主路 · 三条兑换）

持牌期间随时可打出，==打出即消耗==该牌。  
卡面上的三个层次只是**参考**，不是剧本：

:::: card

::: table

| 层次 | 是什么 | 怎么用 |
|------|--------|--------|
| **牌义** | 这张牌讲的核心是什么 | 想效果时的出发点 |
| **叙事触发** | 一个现成的塑造创意 | 想借这张牌演一段好戏，从这里起笔 |
| **机械锚定** | 一份照单即领的保底 | 不想发挥时，直接领走条款里那份好处 |

:::

::::

在此之上，你可以围绕牌面在当前场景**自由提出想要的任何效果**。  
与 DM 商量落地。  
能做到什么程度，==由 DM 掌握分寸==。  
懒得发挥时，走一条兑换路作保底——把牌折成**经验**、**装备**或**财宝点**；  
兑换基准由 DM 依当前系统的物价定夺。

## **🎲 在 DND 还可以如何使用**

打出的三条保底兑换路，在 DND 5R 桌按下列数值执行：

:::: card

::: table

| 路径 | 内容 |
|------|------|
| **兑换经验**（大额保底） | 当前 tier 品阶装备价值 **× 2** 折算 XP |
| **自选装备**（实物） | 从物品表任选一件**当前 tier 品阶**的装备入手<br>（神器无定价，不在此列） |
| **兑换财宝点**（小额保底） | 当前 tier 品阶装备价值 **× ½** 折算财宝点 |

## **🔮 大阿卡那（22 张）**

大牌与小牌==机械强度持平==；  
大牌的叙事触发更开阔，能在更大范围内改写场面。

卡末的「DND 塔罗参考」里，「鸦阁塔罗卡」出自《斯特拉德的诅咒》。  
「龙与地下城塔罗牌」是官方授权的独立产品——两副牌各自不同。  
对应关系是==象征交叉参考==，不是严格等位。

| 层 | 内容 |
|------|------|
| 象征 | **忧虑**的剑一把没落——人半夜坐起来，先数头顶那九把。 |
| 叙事触发 | 你的角色**当面去碰一件一直躲着的事**——当面把最坏的可能摆上桌、当面开口问那句不敢问的、当面推那扇不敢推的门；碰过之后，就再没法当它不存在了。 |
| 机械锚定 | 你可以挑一桩正悬着的心事问 DM——**会不会来、几时来、来时多重，当场给你称出个准数**。 |
