## **🌍 这是一家什么公司**

:::

::: card

**表面**

- 俄亥俄州合法注册的通讯社
- 唯一办公室：克利夫兰一栋破旧商用楼三层
- 主编 Tony Patel 从不露面——只出现在邮件和 Skype 里，礼貌、优雅、英式口音
- 底薪寒酸，猛料奖金丰厚：一条能卖动的独家通常五万美元起

:::

::: card

**业内名声**

- **脏活承包商**——大媒体想挖脏故事不想脏手，雇 GNS 当白手套
- **出了名的不怕死**——别人不敢去的地方、不敢惹的人，你们都敢

:::

::: tip 什么是通讯社／stringer

通讯社自己不发报——稿子卖给各大电视网。stringer（特约供稿人）就是没有编制的本地供稿人：按篇结账、无保险无底薪，稿子卖不掉这个月就没饭吃。GNS 卖的是小报商品——桃色、名人、犯罪，「煽情」是卖点不是缺陷。

:::

## **🧠 残缺者规则（全员适用）**

:::

::: card

- 起始理智 **−2D10**
- 幸运 **+3D10**（上限 99）
- 技能点 **+EDU ×2**（常规 ×4 之上再加两倍——什么都干过一阵）

这不是数值补偿，是类型片契约：还能接到活的记者全是伤痕累累的老油条，但个个运气反常地好，而且什么都干过一阵。
