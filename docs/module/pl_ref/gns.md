::: tip 什么是通讯社／stringer

通讯社自己不发报——稿子卖给各大电视网。stringer（特约供稿人）＝没有编制的本地供稿人，按篇结账、无保险无底薪，稿子卖不掉这个月就没饭吃。GNS 卖的是小报商品：桃色、名人、犯罪——「煽情」是卖点不是缺陷。

:::

## 🧠 残缺者规则（全员适用）

- 起始理智 **−2D10**
- 幸运 **+3D10**（上限 99）
- 技能点 **EDU ×6**

这不是数值补偿，是类型片契约：还能接到活的记者全是伤痕累累的老油条，但个个运气反常地好，而且什么都干过一阵。
