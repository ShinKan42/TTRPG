---

::: tip 规则自由搭配

模组与规则可以自由组合——==任何模组都可以换用不同大类下的规则来跑==，比如用`匕首之心`或`FATE`体验 DND 模组的故事

每张模组卡只标注**起源规则**（模组原生为哪套规则所写）

想换套规则来跑、了解各规则的特点，详见：[快速选择 ⚡](/module/)

:::

## **📚 短团集**

:::

---

::: note 什么是短团集

由多个短团组成的、统一主题的模组集，每次独立，方便拼车的同时保持故事连贯

可拆开单跑，也可串联成长线

:::
