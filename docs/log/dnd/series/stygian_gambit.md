#### **🎯 委托与入场**

:::

**黄金宝库的邀请** 📜：

四名受雇的陌生人——往忆、正义小姐、走地鸡、白夜——接到组织委托。委托人维地利海现身：提夫林，三龙牌前冠军，胸前别一朵凋谢的玫瑰。她被赌场老板昆汀卷走五千金和冠军雕像，要他们把雕像偷回来。

**冥河摆渡** ⛴️：

登上摆渡船。灰斗篷的船夫一言不发，镰刀在船边划水。船上各色赌客——做饮料生意的三龙牌老手惠普薯、披甲带乌鸦的老伯。白夜和惠普薯搭上线，留了传信术的联系方式。

**码头收械** 🗝️：

赌场门口收走武器法器。全队凑了四百金贿赂门卫，换回一张门禁卡，私藏的装备也保住了。

#### **🕳️ 潜入**

:::

**洗衣房** 🧺：

潜进洗衣房偷员工服。走地鸡和白夜动手，徒手放倒了洗衣阿姨——==人哋只系一个洗衫嘅咋==。四套员工服到手，一张员工卡顺走。

**动物剧场** 🎪：

换上员工服应聘动物剧场。往忆展示火焰戏法通过初试，进后台见到一只遍体鳞伤的狮子和三只蜥蜴。正义小姐用疗伤术治好了狮子，狮子却死活不肯出笼跳火圈——应聘失败，但那头狮子记住了他们。

#### **⚔️ 安保室鏖战**

:::

**安保室之战** 🍚：

安保室三名安保正在吃饭，被发现，战斗爆发。走地鸡弯刀不破甲，白夜偷袭全落空，往忆三个法术位打到只剩一个——四个新手奈何不了三个吃饭的保安。棘刺魔鬼降临，全桌共识「打唔赢」，果断转向：撤，放火，跳水。这一仗的「打不动」，逼出了今晚最亮的一把火。

**棘刺魔鬼降临** 😈：

安保叫来救兵——一只浑身棘刺的魔鬼飞上高空，还有更多敌人赶来。全桌共识：打唔赢。

**狮子王救场** 🦁：

千钧一发，有人想起后台那头狮子——试跳失败后那扇门一直掩着没关死，狮子自己走出来了，在外面扑向安保，给队伍拖住了回合，众人趁乱脱身。谜底揭开——==其实佢系狮子王==。

#### **🚪 落单与脱身**

:::

**牢房引力** 🔒：

混乱中白夜被冲散，困在牢房区。他强行开锁，撞上一只棘刺魔鬼——四对一的引力对抗，输赢见分晓，白夜被拿下关了起来。

**卡尼亚契约** ✒️：

脱身后的白夜和走地鸡在酒吧遇到梅赛德斯银行的骨魔——灰蓝色皮肤，自带寒气。骨魔开价：死后五十年劳务换帮助。白夜拒绝了：二十五年太长。

**赌桌回血** 🎲：

走地鸡和白夜在「生死攸关」赌桌连本带利赢了一笔，凑齐了后面的行动资金。

#### **🤝 结盟与计划**

:::

**水疗区的阿伯** 🧖：

水疗区排队一小时，遇上船上的老伯——加雷斯，久经沙场的人类战士，浑身伤疤，肩上停着乌鸦，自称信托姆。往忆洞悉发现他==完全不像一个合格的信仰者==。谈判后结盟：他帮队伍拖住昆汀的手下，队伍带他找到赌场老板。

**双重保险** 🗺️：

计划敲定——Plan A 报名三龙牌大赛赢走大奖雕像；Plan B 炼金壶装油、酒瓶分装、火焰箭点燃放火。白夜找冥河摆渡人谈妥皮划艇，走佬路线备好。

#### **🏆 大赛与走佬**

:::

**三龙牌大赛** 🐉：

五人牌桌，两个自己人放水。NPC 选手牌力全凡人，往忆一路碾压——==等于我哋噉就赢咗个大奖啦==。冠军奖杯到手，雕像落袋。

**放火** 🔥：

入夜八点，帷幕拉开。油瓶早已藏进会场干草堆——火焰箭命中，==嘣==，火起，全场大乱。

**并排跳水** 🌊：

四个人并排走向码头，转身，齐齐跳进冥河。皮划艇上，BGM 都想好了。

**收货** 📦：

维地利海拿到雕像，满意收货。往忆当场问了一句：可不可以加入黄金宝库——试用期通过。

### **🪙 十金币买路**

:::

员工通道口，吧员拦着去路。

睡眠术先上——他睫毛都没抖，抵抗了。

往忆出主意：调酒灌醉他。
话音未落自己先反应过来——吧员，最**识饮酒**的那种人。
方案卒。

轮到钱出场。
白夜掏出十金币递过去：==十金就可以啊==，通融一下，我们过去一下。

吧员的话匣子打开了——
问应聘、问部门、问上头是谁，
问了一个世纪那么久。
金币递在半空，他只顾着问，就是伸手接。

——==好明显佢唔系嗰种好容易分贿赂嘅人==。

白夜收起金币。
**不等了。**

直接往右走。
身后两个人也不装了，大步流星跟着冲。
吧员愣在原地——喊住这个、顾不上那个，
眼前的都穿着员工服，见过的就是同事。

白夜低着头，跟着人流，就这么进去了。

一句话点破：==搞咁多嘢，其实直接过就系啦==。

:::: details 围殴洗衣阿姨 👊

行动前的最后一课：徒手。
擒抱、推撞、致命与非致命的分别——
往忆秒选：==啊我的善良的嘛==。
非致命，谢谢。

昏暗的洗衣房。
走地鸡和白夜，对一位洗衫阿姨。

**打晕佢要啊**——计划是这样定的。
**人哋洗衫嗻喎，有必要偷衫**——良心也是这样挣扎的。

动手。
一拳过去——**一点**。
阿姨：四点血。

第二拳，16 对 12，命中。
阿姨倒了。

场外一声叹息：==人哋只系一个，洗衫嘅咋==。
回应只有一句：==洗？衫阿姨==。

「好了，就这么简单一件事。」
四套员工服、一张员工卡，顺手带走。

走地鸡算账：**好亏啊，400蚊一件衫**——
早知道带两件武器，一拳就解决。

### **🍚 三个吃饭的保安**

:::

安保室里，三个保安正在吃饭。
门一开，碗筷未放，先攻投起。

**开拖。**

走地鸡弯刀劈下——皮甲纹丝不动。
白夜偷袭——没破。
再来——还是没破。

往忆的法术位一个一个数着用：
魔法飞弹、火焰箭、睡眠术，
打到只剩最后一个。

白夜还挨了队友一箭。
四个新手围攻三个吃饭的保安，
一时之间，谁也奈何不了谁。

**这仗，硬拼不划算。**

保安摇人——
一只浑身棘刺的魔鬼从天而降，
飞上高空，远程打不着，近战够不上。

打唔赢——全桌零点五秒达成共识。
**撤。换路子。**

正是这局"打不动"，
逼出了今晚最亮的一把火。

:::: details 正义小姐与狮子 🦁

动物剧场的后台，干草和麝香味里，
一只狮子摊着，满身鞭痕。

「佢唔听话，唔食嘢唔饮水，唔肯表演。」
训兽师抱怨：今晚火圈点着，几个钟后就开演，老细要说法。

「==我帮佢放个疗伤术得唔得啊==。」
这句话是正义小姐问的。
阿斯莫的治愈之手，不需要法器——==冇法器唔需要==。

手落下去，狮子站起来了。

铁链和颈圈拖过来——
==我觉得唔需要用铁链，放佢出嚟得啦，有咩事我哋嚟解决==。

门开了。
狮子走到门边，停住。
**喐都唔喐。**

转头来望，又缩回去。
催眠曲吹过，指挥棒挥过，
横竖就是不出来。

应聘，黄了。

---

战场上传来咆哮。
那扇掩着的门后，狮子自己走出来了，扑向安保——
==哇狮子加油狮子加油狮子==。

它咬住一个，拖住一轮又一轮。
有人担心：==话唔定佢会打死个狮子就会走==。

然后谜底揭开——
**啱啱畀个身份嘅狮子啊，其实佢系狮子王。**

白夜秒懂：==佢老板都唔使关起身，点解狮子要关起身噉狮子咯==。

被关进铁笼养伤的，从来就不是一只普通狮子。
所以鞭痕，所以绝食，所以不跳火圈。
它只是在等一个走出笼子的理由——
正义小姐把它的伤治好的那一刻，它已经记住了。

### **🔥 一个半钟的功课**

:::

大赛前，一个半钟。
桌上摊开的不是牌，是**计划**。

目标：雕像到手之后，怎么让全场没人顾得上追。

「==走，我可以放火==。」
话音落，没人反对——==就放火==。

工具清点，一件一件过：

炼金壶，往忆的，==600毫升嘅油==装满。
直接掟壶进去？省了——==我去酒吧攞个空酒瓶，然后倒油入去==，
一排酒瓶，分装，泼得开，烧得匀。

点燃方式：火焰箭。
不到火球术那一步——==唔咪再用那个火焰箭==就好。

难题一个一个来：
==由会场到个码头有段路嘅，会有人嚟嘅，听到嘣一声，你走唔出嚟嘅==。
——那就掐时序：油先藏，==点燃烛火掉落==，人先散位，冠军先落袋。

白夜那边，皮划艇已经在冥河上等着。

一个半钟，功课做齐。

:::: details 并排齐 🚤

八点，帷幕拉开。
油瓶早就藏进干草堆。

火焰箭出手——
==加完肯定命中啦。加完呢个唔使计伤害啦，直接嘣==。

**嘣。**

火光冲起来，现场一片混乱。
混乱里还有人在骂：又系嗰条扑街，嗰个风流哥——
往忆补刀：==时尚单品==。

今晚的注脚——
**==打唔赢就放火佢吖嘛==。**

雕像在前袋，慢慢行出去。
==走了走了走了开船走佬==。

码头边，四个人站成一排。
==仲要bgm响起==——转身。

==我哋4个人并排齐==。

**跳水。**
一个接一个，扎进冥河。
皮划艇上，好帅好帅，今晚不回家。
