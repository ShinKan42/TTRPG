<a id="什么是lancer"></a>
### **什么是 Lancer？ 🤖**

Lancer（《枪骑兵》）是一部 ==科幻机甲角色扮演规则==

故事发生在联盟历 5016 年：人类横渡星海，在银河建起乌托邦「联盟」

而你就是 ==枪骑兵==——本身已万中无一的机甲驾驶员中，人中龙凤

::: tip 一句话概括

扮演驾驶员，驾驶机甲

==在叙事与战术之间，写下属于你的故事==

:::

::::

---

:::: card

<a id="驾驶员与机甲"></a>
### **驾驶员与机甲 🧑‍✈️**

你的角色由两个元素组成：

**驾驶员**——任务之外谈判、探索、社交的「人」

**机甲**——战斗中主宰战场的钢铁巨人

两者==密不可分==：驾驶员的技艺，决定机甲的潜能

构筑时 ==驾驶员先于机甲==，第一步永远是先想「人」

::: info 背景一分钟

联盟以三支支柱维系银河：霎闸（星际航行）、万物网（信息网络）、吗哪（统一货币）

五大制造商向中核区之外出售武器与装甲——枪骑兵受雇于各方，活跃在危机四伏的星海

:::

## **📖 游戏怎么运转？**

---

:::: card

<a id="叙事与机战"></a>
### **叙事与机战 ⚖️**

Lancer 的玩法分两层，切换通常相当自然：

::: table

| | 叙事扮演 | 机甲战斗 |
|:---|:---|:---|
| 节奏 | 自然自发，时间自由流动 | 回合制，方格地图上逐格行动 |
| 规则 | 简单判定，专注故事与角色 | 完整战术规则，接近版图游戏 |
| 掷骰 | 技能检定 | 技能检定＋攻击＋豁免 |

:::

---

哪层多、哪层少，==由你的桌自己定==

纯讲故事或纯战术对撞，都是合法玩法——两组规则都在书里等着

::: tip 双层是特色不是负担

叙事层专注故事和角色，机战层专注规则和战术

偏好哪种，==都不妨碍享受这游戏==

:::

::::

---

:::: card

<a id="任务休整期场景"></a>
### **任务·休整期·场景 🗺️**

一局 Lancer 由三种节奏单元组成：

**任务**——有特定目标的一次行动：破坏、潜入、疏散、抵抗进攻

**休整期**——任务之间的叙事空间：推进剧情、推进计划、推进个人故事

**场景**——有起点和终点的连续对话或行动

---

任务开始前有 ==准备时间==：定目标、定利害、定装备

休整期可长可短，数日数月皆可

::: warning 记住场景的边界

==许多角色与机甲能力，在场景结束时失效或重置==

镜头聚焦在玩家身上，这就是一个场景

焦点移走，场景就该收了

:::

<a id="你需要准备什么"></a>
### **你需要准备什么 🎒**

**骰子**——一颗 d20，数颗 d6

**人数**——==3 到 6 人最佳==（2 人或 6 人以上也可玩）

**GM**——其中一人主持：带动故事、扮演 NPC、仲裁规则

**地图**——方格或六角格战斗地图，机战层使用

**工具**——官方免费构筑器 ==COMP/CON==，强烈推荐

---

规则书里的骰式写法很直白：

1d20 就是掷一颗二十面骰，2d6 就是掷两颗六面骰

遇到 1d3 时，掷 1d6 再除二取整即可

<a id="掷骰与加值"></a>
## **🎲 掷骰与加值**

---

:::: card

<a id="三种掷骰"></a>
### **三种掷骰 🎯**

::: table

| 掷骰 | 公式 | 成功条件 |
|:---|:---|:---|
| 技能检定 | 1d20 ＋ 加值 | 总和 ≥ 10 |
| 攻击 | 1d20 ＋ 加值 | 总和 ≥ 目标防御 |
| 豁免 | 1d20 ＋ 加值 | 总和 ≥ 攻击方定下的目标值 |

:::

---

技能检定是叙事层的主力：撞门、解密、奉承门卫，都掷它

==10+ 即成功==，目标值固定，GM 不能改

但 GM 可以宣告行动「困难」或「危险」，给你加 `难度`

---

机战层里，攻击命中造成伤害

==骰出 20+ 是会心一击==，伤害更多或触发额外效果

豁免用来躲闪负面效果：骇进、闪光弹、爆炸

::: info 对抗检定与选择失败

对抗检定：双方各掷，==高者胜==

平局时，发起检定的一方胜

另外，你==永远可以主动选择失败==——有时失败才让故事更好看

:::

::::

---

:::: card

<a id="准度与难度"></a>
### **准度与难度 🎰**

准度与难度是乱局中得到的临时修正：

**每点准度**——骰数 +1d6

**每点难度**——骰数 −1d6

**互相抵销**——1 点准度对 1 点难度，正好归零

---

掷出多颗准度骰时，==只取单个最大值==，不累加

所以准度与难度的影响，==永远不会超过 ±6==

::: tip 算个例子

2 点准度的攻击：掷 2d6 取大——骰出 3 和 4，就是 +4 而不是 +7

2 准度对 1 难度：抵销后剩 1d6

:::

---

数值加值是另一族，来源有三：

**触发**——驾驶员的天赋与经验

**机甲能力**——你操作机甲的本事

**毅力**——见下一节

==每次掷骰，只受益于一个数值加值==——很多时候没有加值，裸掷 1d20

::::

---

:::: card

<a id="毅力"></a>
### **毅力 🔥**

毅力是驾驶员的 ==决心与求生意志==，老练驾驶员的标志

::: table

| 项目 | 内容 |
|:---|:---|
| 数值 | 牌照等级 ÷ 2（四舍五入） |
| 改善 | 攻击加值、生命值、驾驶员与机甲的豁免目标 |

:::

---

危急关头，新晋驾驶员无法和千锤百炼的老手相比

这 1 到 3 点的差距，就是 ==经验的分量==

<a id="黄金法则"></a>
## **⚖️ 黄金法则**

---

::: card

**一、特例胜于通例**

一般规则管平常局面，特定规则覆盖一般规则

例：掩护通常让攻击更难命中——但带「引导」标签的武器==无视掩护==

因为引导是特定规则，==它说了算==

:::

::: card

**二、无条件四舍五入**

一切除法结果，==向最接近的整数取整==，没有向下取整或向上取整之分

牌照等级 3 的毅力就是 2（3÷2=1.5 → 2）

:::
