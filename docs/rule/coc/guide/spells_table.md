::: center
## **⚡ 用法**

:::

法术不是调查员的超能力——==每一次施放都在蚕食理智==

学会法术的途径只有阅读神话典籍或他人传授

`KP` 应记录每名调查员知晓的法术

分类解读（请神/联络/召唤的区别）、深层魔法、法术变体 → 40 周年版第十二章

::: center
## **⚡ 法术全表**

:::

共 ==60== 个法术，按类别分组；同类外按原文字母序

::: tip

多数法术需与目标进行 ==`POW` 对抗检定==（比成功等级，平局值高者胜）

攻击性法术多可被 `闪避` 或还击

:::

:::

::: table

| 法术 | 消耗 | 施法用时 |
|---|---|---|
