## **🎓 怎么读职业表**

:::: card

每个职业给出三样东西：

- **本职技能**（≤8 项）——车卡时优先加点的技能
- **信用评级范围**——财产与社会地位的区间
- **本职技能点公式**——决定您有多少点可分配

`[洛式]` = 洛夫克拉夫特故事中的经典职业，适合 1920s

`[现代]` = 仅现代背景可用

==职业决定的是技能倾向，不是强度==——COC 没有 DND 式的职业平衡

## **🧮 本职技能点公式**

:::: card

::: table

| 公式 | 定位 | 职业数 |
|---|---|---|
| `EDU`×4 | 学术型 | 12 |
| `EDU`×2＋`DEX` 或 `STR`×2 | 行动型 | 9 |
| `EDU`×2＋`POW` 或 `DEX`×2 / `DEX` 或 `POW`×2 | 感性型 | 2 |
| `EDU`×2＋`APP`×2 | 魅力型 | 2 |
| `EDU`×2＋`APP` 或 `POW`×2 | 信念型 | 1（狂热者） |
| `EDU`×2＋`DEX`×2 | 技术型 | 1（飞行员） |
| `EDU`×2＋`APP`、`DEX` 或 `STR`×2 | 街头型 | 1（流浪者） |

:::

兴趣技能点 ==智力 `INT`×2==，与职业无关，可加任意技能（克苏鲁神话除外）

==信用评级用本职技能点购买==，范围由职业决定
