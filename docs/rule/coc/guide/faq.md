### **没读过克苏鲁原著，能玩吗？**

:::

==完全能玩==

游戏的大部分乐趣，就在于 ==亲自发现== 秘密、解开守秘人 `KP` 设计的谜题

神话的内容会在游戏中逐渐展开

==没读过原著== 的玩家，反而和调查员 ==共享同一种未知==

::: center
### **我该知道多少？角色知识 vs 玩家知识**

:::

自己读过洛夫克拉夫特全集，不代表您的调查员是 ==人形神话百科==

==角色只应知道自己知识结构之内的事==

这么做是为了 ==更加有趣==——未知的恐惧才是恐惧

::: center
### **调查员疯了/死了，怎么办？**

:::

==这是 COC 的常态，不是意外==

- 新调查员可以从 关系人 中诞生（前角色日记的继承人）
- 游戏中遇到的 `NPC` 也可能 转正 成为调查员
- 老调查员的 ==朋友、亲人== 是天然的接班人

在车卡时写下重要的家庭成员——就是给故事留的 后手

### **检定失败了一定失败吗？**

:::

非战斗检定可以 ==孤注一掷==（推骰）：

换一个更好的方法重掷一次——但 ==失败的后果会更糟==

`KP` 会先告诉您后果，您再决定掷不掷

:::: card


::: center
### **理智检定可以孤注一掷吗？**

:::

==不可以==

理智检定也 ==不能花幸运值==、不能上奖励骰

面对恐怖，没有第二次机会——==这就是 COC==

### **战斗打不过怎么办？**

:::

==跑==

- 追逐规则就是为此设计的：速度检定、地点、险境
- ==撤退是智慧==，不是耻辱
- 活着的调查员才能揭开真相

::: center
### **为什么大家都说“别用枪”？**

:::

不是“别用”，是 ==别倚赖==：

- 强大的异界存在 ==无法被火器伤及==，射了也白射
- 枪声会引来 ==警察和法律==——在现实映像的世界里，开枪是有后果的
- 但在 ==该用== 的时刻——面对邪教徒、深潜者、疯狗——枪就是保命的东西

==千万小心，枪对您也一样致命==

### **克苏鲁神话技能要不要学？**

:::

==双刃剑==：

- 学了：识别神话生物、推断弱点、可能学会法术
- 代价：每 1 点神话知识，==最大理智永久 −1==

==知道得越多，能承受的越少==

这是您调查员的故事里，最重的抉择之一

### **太恐怖了玩不下去怎么办？**

:::

==开团前说清楚==

每个人不想在游戏里见到的东西，应当在 Session 0 就讲明

`KP` 会避开或调整——==恐怖的目的是刺激，不是折磨==

### **COC 有赢家吗？**

:::

==没有通常意义的赢家和输家==

- 胜利 = 活着完成调查、阻止阴谋
- 失败 = 目标未竟——但 ==可以再试==

==总要有人站出来，为什么不是您？==
