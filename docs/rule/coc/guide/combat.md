::: center
### **敏捷定次序 🏃**

:::

所有参战者按 ==敏捷 `DEX`从高到低== 行动

敏捷相同——战斗技能较高者优先

---

战斗轮是 ==弹性时间单位==：

“足够让每个人都进行一次重要的行动”

比起精确计时，==给每个人平等的机会== 更重要

::: center
### **您回合能做的事 📋**

:::

- 用格斗/射击技能 ==发动一次攻击==
- 施展一次 ==战技==（缴械、击倒、擒抱）
- ==脱离== 战斗
- ==施放== 一个法术
- 其他消耗时间、可能需要检定的行动（撬锁、急救……）

---

可以 ==延迟== 回合，等别人行动之后再动

战斗中 ==无法孤注一掷==——失误只能下回合弥补

::: center
### **回合内移动 🏃**

:::

一轮能走多远由移动速度 `MOV` 决定（车卡时按力量/敏捷/体型判定，见[车卡指南](/rule/coc/guide/character_creation#📈-属性)）：

::: table

| 移动方式 | 一轮距离 | 说明 |
|---|---|---|
| 谨慎移动 | `MOV` 米 | 边走边留意四周——普通人一轮 7-9 米 |
| 全速奔跑 | ==`MOV` × 5 米== | 追逐战的核心数值；==很快疲劳==，代价由 `KP` 裁定 |

:::

**边移动边开枪**（敏捷次序怎么算）：

::: table

| 情形 | 敏捷次序与射击 |
|---|---|
| 枪已装填、==先射后动== | 敏捷按 ==`DEX`＋50== 算——扣扳机快过挥刀 |
| ==先动后射==（一轮内） | 移动 `MOV` 米内可照常射击，用未调整的敏捷次序 |
| 跑满 ==`MOV` × 5== | 只能奔跑中射击，攻击检定吃 ==1 惩罚骰==；要跑很远才能就位时，`KP` 可==延后==其行动次序 |

:::

==跑起来也更难被打中==——全速移动的目标（`MOV` 8+），射击者吃 1 惩罚骰

::: tip

**突袭不会被次序惩罚**：若 `KP` 不给突袭机会直接进战斗轮，声明突袭者可能因敏捷次序落到最后——规则书明言这不符合叙述逻辑，`KP` 应优先给突袭机会

### **先声明意图，再掷骰 🗣️**

:::

“你的角色要做什么？”——守秘人 `KP` 总是这样问

==用动作描述代替术语==，您描述的内容 ==决定== 检定的种类

::: tip **示例**

- “我一拳打向守卫，然后跑向敞开的门”——斗殴检定
- “我举起霰弹枪，把它打成碎片”——霰弹枪检定
- “我抓住他，把他摔在地上”——斗殴对抗检定

:::

:::: card


::: center
### **攻击 vs 闪避/还击 🛡️**

:::

被攻击时二选一，基础逻辑相同：都是对抗检定，==更高成功等级== 获胜

差异全表：

::: table

| | 闪避 | 还击 |
|---|---|---|
| 用什么掷 | 闪避技能 vs 攻击方格斗 | 格斗技能 vs 攻击方格斗 |
| 赢了会怎样 | 挡下攻击，无伤害 | 挡下攻击，==反手对攻击方造成武器伤害== |
| 平局 | ==防御方== 胜 | ==攻击方== 胜 |
| 每轮次数 | ==不限==（每次攻击只挡一次） | ==一次== |
| 能否对枪械 | 不能——子弹看不见 | 不能 |
| 对投掷物（飞刀） | 能闪避（同近战） | 贴近到敏捷 `DEX`/20 米内才能 |
| 对弓箭/枪械 | 不能——只能 ==找掩护== | 不能 |

:::

---

==双方都失败==：无人受伤，形势可能恶化

==子弹无法被闪避==——它飞得太快，肉眼看不见，找掩体吧

对抗检定==不能孤注一掷==

::: center
### **极限成功：贯穿与重击 💥**

:::

攻击掷出 ==极难成功==（≤ 技能 1/5）时：

- ==钝器==（拳脚、棍棒）：伤害取 ==最大值== + 伤害加值最大值
- ==贯穿武器==（利刃、子弹）：最大伤害之外，==再掷一次完整武器伤害==

::: tip **示例：手枪极难成功**

1D10 伤害直接变 ==10==，再 ==追加掷一次 1D10==——两枪的量一枪打出来

:::

==每位角色每轮的聚光灯时刻，就是打出卓越一击的机会==

::: center
### **战技：不只是伤害 🤼**

:::

目的不是造成伤害时——用 ==格斗（斗殴）== 检定，对方可选闪避或还击

成功后能达成什么（目标要描述清楚）：

- ==缴械夺物==：击落或夺走对方武器、手里那本书
- ==制造劣势==：把对方压倒在地——他下次行动 ==+1 惩罚骰==，或同伴与他对抗时 ==+1 奖励骰==（`KP` 选）
- ==脱离压制==：被擒抱、锁喉时，用自己的回合掷战技挣脱；挣不脱就被持续拘束，直到对方松手或你受重伤
- ==位移==：把人撞下悬崖、推出窗外、推倒在地

符合情节时 `KP` 可判伤害——从二楼被推下去显然会受伤

---

==体格差距== 有代价：

- 施术者体格每比对方小 1 点，承受 ==1 个惩罚骰==（至多 2 个）
- 对方体格大 ==3 点以上==，战技直接无效——体格碾压

被攻击时也可以用战技 ==代替还击==：对抗方式相同，赢了不造成伤害，改为应用战技效果

:::

::: center
### **射击规则 🎯**

:::

射击需掷对应 ==枪械技能== 检定

- 就绪的枪械，行动次序视为 ==`DEX` + 50==
- 手枪每轮射 2-3 次——第 2 发起每次射击带 ==1 个惩罚骰==
- 目标在 ==极近射程==（`DEX`/5 码内）——获得 ==1 个奖励骰==
- 被射击时可以 ==找掩护==：掷闪避，成功则枪手这次射击 ==+1 惩罚骰==——代价是==失去下次攻击机会==（本轮已攻击过则失去下轮的；再次攻击前只能闪避）

### **寡不敌众 ⚔️**

人数差距悬殊时，多方对器械攻击获得 ==1 个奖励骰==

用枪械无法获得此奖励——近身混战才吃人数

::: center
### **生命值与重伤 💉**

:::

生命值 `HP` = (体型 `SIZ` + 体质 `CON`) ÷ 10——通常 10-12 点

- 单次伤害 ≥ 最大 `HP` 的一半：==重伤==，掷 `CON`，失败即昏迷
- `HP` 归 0：==濒死==，每轮结束掷 `CON`，失败即死；需成功的急救才能脱离
- 单次伤害 ≥ 最大 `HP`：==立即死亡==

COC 的 `HP` 尺度：手枪 1D10、霰弹枪 4D6（近程）

==两枪放倒一个正常人，这就是设计的本意==

::: center
### **护甲与减伤 🦺**

:::

==伤害先减护甲值，剩下的才扣生命值==。护甲不影响是否命中，只减少最终吃到的伤害

护甲来自三种东西：

- ==天生护甲==——深潜者的皮革粗鳞、大象的厚皮
- ==穿在身上的护甲==——防弹背心、头盔
- ==障碍物==——你和攻击者之间的桌子、砖墙，哪怕一块破铁板也算

**护甲值范例（40 周年版原书表）**

::: table

| 护甲 | 护甲值 |
|---|:-:|
| 厚重皮夹克 | 1 |
| 一战标准钢盔 | 2 |
| 3 厘米厚硬木 | 3 |
| 现代美军头盔 | 5 |
| 重型凯芙拉防弹背心 | 8 |
| 军用防暴服 | 12 |
| 4 厘米厚防弹玻璃 | 15 |
| 3 厘米厚钢板 | 19 |
| 大号沙包 | 20 |

:::

==护甲挡不住==的：法术攻击、毒素、溺水——这些照常全额结算

**只护住一部分身体怎么算**（头盔只护头、背心只护躯干）

::: table

| 情形 | 怎么算 |
|---|---|
| 拳脚混战、摔出窗外这类通用伤害 | 直接减护甲值，不再判断打中哪里 |
| 枪击这类单次特定攻击 | 被攻击者掷==幸运检定==：成功＝打中护甲区域，减护甲值；失败＝打中没护甲的地方，全额结算 |
| 头和躯干都有护甲 | 幸运检定 ==+1 奖励骰== |
| 全身护甲，或有天生护甲 | ==免掷骰==，护甲永远生效 |
| 敌人瞄准护甲缝隙（张开的嘴、眼睛） | 守秘人 `KP` 提高难度等级或加惩罚骰 |

:::

**霰弹枪：护甲从每一颗骰子上分别扣**

- 霰弹枪的伤害是好几颗六面骰，护甲值要在==每一颗骰==上单独扣一遍，不是从总数里扣一次
- 算例：霰弹枪伤害 4D6，目标穿厚重皮夹克（护甲 1 点）
  - 四颗骰掷出 4、3、6、2
  - 每颗各减 1：(4−1)＋(3−1)＋(6−1)＋(2−1)＝3＋2＋5＋1＝==11 点==实际伤害
  - 若只从总伤减一次（15−1＝14 点），会多算 3 点——弹丸越多，护甲越顶用

**躲在掩体后面挨枪**

- 射击者吃 ==1 颗惩罚骰==（目标被部分遮蔽），伤害按掩体的护甲值减
- 算例（原书范例）：哈维朝躲在桌后的怪物开枪——1D10 伤害掷出 7，减桌子 2 点护甲，实伤 ==5==

::: table

| 常见掩体 | 护甲值 |
|---|:-:|
| 木栅栏 | 1 |
| 普通桌子 | 2 |
| 低矮砖墙 | 10 |

:::

护甲值范例表里的沙包、钢板、防弹玻璃拿来做掩体同样有效

购买防弹背心等装备 → [装备速查](/rule/coc/guide/equipment_table)；贯穿武器对护甲的完整规则 → [武器速查](/rule/coc/guide/weapons_table)

::: center
### **恢复节奏 🛏️**

:::

- ==轻伤==（没勾过重伤框）：每天恢复 ==1 点==
- ==重伤==（勾了重伤框）：游戏内==每周==结束掷一次 ==恢复检定==（`CON`）——成功 +1D3，极难成功 +2D3，失败本周不恢复
  - 卧床+有医护照料：恢复检定 ==+1 奖励骰==（医护的医学检定成功再 +1）
  - 恶劣环境无法休息：==+1 惩罚骰==
  - 解除重伤标记的两条路：恢复检定==极难成功==，或 `HP` 回到 ==最大值一半以上==
  - 恢复检定==大失败==：留下永久创伤（`KP` 定：跛脚/失明/截肢……写进背景）
- ==急救==：伤后 1 小时内，成功 +1 点（每人每次受伤只能接受一次成功的急救和医学治疗）
- ==医学==：需 1 小时+装备，成功 +1D3 并可擦除濒死标记

## **☠️ 环境伤害**

:::

不止武器能伤人——溺水、坠落、毒物、火灾，KP 用 ==伤害等级== 快速判定


::: center
### **伤害等级速查**

:::

::: table

| 伤情 | 伤害 | 典型示例 |
|---|---|---|
| 轻度 | 1D3 | 拳打脚踢、头槌、弱酸、坠落到淤泥地（每 3 米） |
| 中度 | 1D6 | 坠落到草地（每 3 米）、棍棒、强酸、呛水、火把火焰 |
| 重度 | 1D10 | `.38` 子弹、坠落到水泥地（每 3 米）、斧头、燃烧的房间、距手雷 6-9 米、弱毒剂 |
| 致命 | 2D10 | 被时速 50 公里的汽车撞、距手雷 3-6 米、强毒剂 |
| 终结 | 4D10 | 被超速汽车撞、距手雷 3 米内、致命毒剂 |
| 血肉横飞 | 8D10 | 高速迎面撞击、被火车撞 |

:::

每种伤害针对「一次事件」或「一轮」——此后每轮继续暴露就继续受伤


::: center
### **四类环境规则**

:::

::: tip **窒息与溺水**

每轮一次 体质 检定；一旦失败，此后==每轮都受伤==，直到死亡或恢复呼吸

剧烈消耗体力的场景（挣扎、激流）需 困难成功

`HP` 归零=死亡，==无视重伤规则==

:::

:::: tip **坠落**

按落点材质查表：

::: table

| 落点材质 | 坠落伤害 |
|---|:-:|
| 淤泥 | 1D3（每 3 米） |
| 草地 | 1D6 |
| 水泥 | 1D10 |

:::

成功的 跳跃 检定=做好准备，==伤害减半==

::::

::: tip **中毒**

体质 检定 定生死：极限成功=伤害减半；大成功=KP 可裁定完全摆脱效果

多剂摄入=体质 检定 吃 惩罚骰

副作用由 `KP` 裁定：呕吐、痉挛、瘫痪、视力损害……可加 惩罚骰 或提高难度

:::

::: tip **燃烧**

火焰按来源定级：火把 1D6、燃烧的房间或火焰喷射器 1D10

每轮暴露每轮伤；衣物可燃时伤害持续

:::

### **可选：命中部位（取代幸运检定） 🎯**

:::

| 1D20 | 部位 |

| 4-6 | 左腿 |

### **可选：先攻检定 🎲**

:::

不按 敏捷 高低排次序，改为每人掷 敏捷 检定：极限成功先动 → 困难成功 → 常规成功 → 失败者垫底

- 同等级比 敏捷，再同比战斗技能
- 先攻 大成功=首次行动 奖励骰；大失败=失去第一次攻击（武器掉落/被绊倒）
- 已备好枪械者掷 先攻 时得 奖励骰
- 中途拔枪=重新掷一次带 奖励骰 的 敏捷，好则顶替原位

## **🏃 追逐**

:::

---

:::: card


::: center
### **第一步：速度检定 🏁**

:::

追逐建立前，每人掷一次速度检定（步行 `CON`，开车 汽车驾驶）：

- 成功——`MOV` 不变
- ==极难成功==——`MOV` +1
- 失败——`MOV` −1

比较调整后 `MOV`：

- 逃离者更快——==追逐结束==，`KP` 简述您怎么甩掉的
- 追逐者够快——==追逐建立==，切入最紧张的时刻

::::

---

:::: card


::: center
### **地点与行动点 🗺️**

:::

追逐被切成一串 ==地点==：旋转门、大堂、楼梯、走廊、厨房……

- `KP` 把追逐者放在逃离者 ==身后两个地点==
- 每轮每人有 ==行动点==：默认 1 点；`MOV` 每比最慢者高 1 点，+1 行动点
- 两个地点之间可能横着 ==险境==：急转弯、湿滑地面、台阶、围观人群——通过需掷检定，失败摔伤或减速

::::

---

:::: card


::: center
### **追逐轮中能做的事 📋**

:::

按敏捷次序行动，每轮可以：

- ==前进==（花费行动点）
- ==攻击==（格斗/射击/驾驶撞击）
- ==施放法术==
- ==处理险境==

追逐中 ==无法孤注一掷==

==逃出生天的故事，和战胜敌人的故事一样精彩==

::: center
### **加速：猛踩油门 🏎️**

:::

花费 1 行动点移动载具时可以==加速移动==：

- 移动 1 地点——正常，无风险
- 移动 2-3 地点——过险境 检定 吃 惩罚骰
- 移动 4-5 地点——过险境 检定 吃 惩罚骰 且难度==提高一级==

加速到 4-5 地点时能看清的前路地点数：

::: table

| 环境 | 能看清的地点数 |
|---|:-:|
| 城市 | `1D3` |
| 郊区 | `1D6` |
| 直路 | `1D10` |

:::

加速决定==不可撤销==：要么走完全部距离，要么险境 检定 失败立即停下结算后果


::: center
### **突发险境 🎲**

:::

追逐轮任意时刻，`KP` 或玩家可要求==团体幸运检定==：

- 通过——突发险境按要求方的意愿出现在指定位置
- 失败——遭遇 `KP` 放置的突发险境

双方轮流要求——一方提过，须等另一方也提过才能再提

追逐拖长时 `KP` 可提高险境难度


::: center
### **多人追逐 👥**

:::

多人同时追逃唯一不同在==起始阶段==：

1. 确定誰追谁；逃离者分头跑=拆成多场追逐分别处理
2. 每人掷速度 检定（步行 体质/开车 汽车驾驶）定 `MOV`
3. 全员按速度排序，分列追逐者/逃离者两类
4. 太慢的自动出局：追逐者追不上=出局；逃离者甩开两个地点=脱险

步行险境范例：矮墙、闩住的窗、河流、拥挤街道、窄巷、屋顶、螺旋阶梯

汽车险境范例：交通堵塞、U 形弯、道路施工、十字路口、悬崖窄路、迎面来车、纸板箱堆
