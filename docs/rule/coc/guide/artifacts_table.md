## **⚡ 用法**

:::

外星种族与邪教留下的 ==科技与附魔物品==——模组奖励、线索、或致命陷阱

按使用者分类速查；效果细节见原书第十三章

## **👽 米-戈造物**

:::

::: table

| 造物 | 效果 |
|---|---|
| 网状生化装甲 | 绿色黏液编织的网状护甲——钝击/火焰/电击提供 8 点护甲；人类穿戴每次脱下受 1 点伤害 |
| 大脑收容筒 | 储存摘除的大脑——金属圆筒维持生存，可接感觉装置；筒中大脑每月 `INT` `检定`，成功回想处境掉 1D3 `理智值` |
| 地震采矿机 | 边长 6 米的立方体机器——把地下地层拖上地面，可下探 6-8 公里 |
| 电气枪 | 黑色金属块武器——蓝色电火花 1D10 伤害；人类应急改造后 1D6 只有 1-2 才能发射 |
| 寒雾喷射器 | 扭曲金属管喷射锥状寒雾——每轮 1D10 伤害；暖衣减 1 点 |

:::
