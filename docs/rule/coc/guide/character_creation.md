## **📋 流程**

::::

---

:::: card


::::: center
### **车卡六步 ⚡**

:::::

1. 与守秘人 `KP` 沟通：时代、地点、前提设定
2. 选一种属性生成方式，分配 8 项属性
3. 按年龄做调整，算出派生数值
4. 选职业，记录 8 项本职技能
5. 分配技能点，再选兴趣技能
6. 写背景，填姓名、性别、年龄，最后定装备

::: tip

**先想「人」，再想「数据」**

数据规则交给 `KP`，您专注思考角色的 ==人生==

:::

::::

---

:::: card


::::: center
### **EXCEL 车卡（国内实况） 💻**

:::::

国内网团普遍用现成 EXCEL 人物卡（如 CY 系列），流程已经自动化：

1. 顶部下拉选 ==时代==（1920s / 现代……对应模组）
2. 填属性——表内 F9 ==自动掷骰==，或手填购点结果
3. 年龄调整、半值/五分之一值、伤害加值 `DB`、体格全部==自动计算==
4. 填 ==职业序号==，本职技能点按公式自动算出
5. 技能表里分配点数（本职技能有星标；带手枪记得点射击）
6. 武器栏从下拉选——年代与故障值自动校验
7. 填背景故事，对照现金资产表记账，交 ==`KP` 审核==

网卡（网团用）与打印卡（面团用）内容相同；不会填的地方空着，`KP` 会带你过

## **📈 属性**

::::

---

:::: card


::::: center
### **八项属性 💪**

:::::

::: table

| 属性 | 缩写 | 是什么 |
|---|---|---|
| 力量 | `STR` | 物理力量与负重 |
| 体质 | `CON` | 健康与强壮 |
| 体型 | `SIZ` | 身高体重的复合值 |
| 敏捷 | `DEX` | 反应速度与身手 |
| 外貌 | `APP` | 外在吸引力与人格魅力 |
| 智力 | `INT` | 聪慧与逻辑推理 |
| 意志 | `POW` | 意志力与心理稳定 |
| 教育 | `EDU` | 正式教育与社会经验 |

:::

属性标尺：==50=普通人==，90=顶尖（你见过最强的），99=人类极限（奥运级）


::::: center
### **属性牵动什么 🔗**

:::::

::: table

| 属性 | 建卡时牵动 |
|---|---|
| `EDU` | 职业技能点公式、母语起始值 |
| `INT` | 兴趣技能点（`INT`×2） |
| `POW` | 理智 `SAN` 起始、魔法 `MP` |
| `SIZ`+`CON` | 生命 `HP` |
| `STR`+`SIZ` | 伤害加值、体格 |
| `DEX` | 战斗先攻、`MOV` 判定 |

:::

属性本身也能掷检定：==力量==推门、==敏捷==保持平衡、==智力==解谜（灵感检定）、==教育==回忆知识（知识检定）

50 以下不是废人——低属性反而是角色的真实感来源，见下方心态框

::::: center
### **属性生成：四种方式 🎲**

:::::

::: table

| 方式 | 怎么做 | 特点 |
|---|---|---|
| **定值分配** | 把 `40/50/50/50/60/60/70/80` 填入 8 项 | 官方快速开始，新手最平滑，全员公平 |
| **标准掷骰** | `STR`/`CON`/`DEX`/`APP`/`POW` 掷 `3D6×5`；`SIZ`/`INT`/`EDU` 掷 `(2D6+6)×5` | 官方标准，随机感强，可能出现天生弱者 |
| **换位分配** | 掷出一组 8 个数，再自由决定放哪项 | 保留随机，允许摆位 |
| **购点** | 总和 ==≤500== 自由分配（国内村规） | 官方购点 460、单项 15–90 |

:::

用哪种 ==由 `KP` 定==——开团前问清楚。国内网团最常见购点 500 与定值分配两种

::::

::: tip

**接纳低属性**——与其拒绝低骰，不如把它变成角色：低敏捷也许是战争伤腿，低教育也许是街头长大

一到两项低属性会让调查员更像活人

:::

---

::: note

**半值与五分之一值**——属性旁顺手记下 50% 与 20% 值：力量 60 记作 60（30/12）

它们是检定的 ==困难== 与 ==极难== 成功线，见[常用骰法](/rule/coc/guide/quick_roll)

EXCEL 卡自动计算；纸质卡建议分配完技能点后统一填写

:::

## **🎂 年龄调整**

::::

---

:::: card


::::: center
### **按年龄微调 📅**

:::::

年龄任选 15–90 岁（超出由 `KP` 判断），按下表调整（==不累加==，只看所在档）：

::: table

| 年龄 | 调整 |
|---|---|
| 15–19 | `STR` 与 `SIZ` 合计 −5；`EDU` −5；幸运掷两次取高 |
| 20–39 | `EDU` 做 1 次成长判定 |
| 40–49 | `STR`/`CON`/`DEX` 任选合计 −5；`APP` −5；`EDU` 2 次成长判定 |
| 50–59 | `STR`/`CON`/`DEX` 任选合计 −10；`APP` −10；`EDU` 3 次 |
| 60–69 | `STR`/`CON`/`DEX` 任选合计 −20；`APP` −15；`EDU` 4 次 |
| 70–79 | `STR`/`CON`/`DEX` 任选合计 −40；`APP` −20；`EDU` 4 次 |
| 80–89 | `STR`/`CON`/`DEX` 任选合计 −80；`APP` −25；`EDU` 4 次 |

:::

`EDU` 成长判定：掷 1D100，==大于==当前 `EDU` 则 +1D10（上限 99）

年长的调查员：知识更厚，身体更沉

::::

---

:::: card


::::: center
### **移动速度 MOV 🏃**

:::::

::: table

| 条件 | `MOV` |
|---|---|
| `DEX` 与 `STR` 皆小于 `SIZ` | 7 |
| `STR` 或 `DEX` ≥ `SIZ`（或三项相等） | 8 |
| `DEX` 与 `STR` 皆大于 `SIZ` | 9 |

:::

年龄修正：40+ 减 1，50+ 减 2，60+ 减 3，70+ 减 4，80+ 减 5

一轮最多移动 ==`MOV` × 5 米==——追逐战的核心数值

### **自动计算 🖩**

:::::

::: table

| 派生 | 算法 |
|---|---|
| 生命 `HP` | (`SIZ` + `CON`) ÷ 10，舍去小数 |
| 魔法 `MP` | `POW` × 1/5 |
| 理智 `SAN` | 起始 = `POW` |
| 伤害加值 `DB` | 查下方 `STR`+`SIZ` 表 |
| 体格 | 与 `DB` 同表 |
| 移动 `MOV` | 见上方表 |
| 幸运 | 掷 3D6 × 5 |

:::

::: note

**魔法值细则**：每小时恢复 1 点；耗尽后继续支出，==从生命值扣除==

理智会随遭遇波动，机制详见[理智与疯狂](/rule/coc/guide/sanity)

## **🗂️ 职业与技能**

::::

---

:::: card


::::: center
### **职业 = 调查工具箱 🧰**

:::::

职业决定您擅长从哪个角度切入谜题：

- **学术型**：教授、考古学家、文物学家——图书馆是主场
- **社会型**：记者、私家侦探、律师——人脉与话术开路
- **技术型**：医生、工程师——专业技能破局
- **格斗型**：警察、军人——硬实力保命

28 个范例职业全数据见[职业速查](/rule/coc/guide/jobs_table)，技能说明见[技能速查](/rule/coc/guide/skills_table)

任何职业都可以，==只需与 `KP` 沟通达成一致==

自创职业：选 8 个技能作本职技能 + 设定信用范围

::::

---

:::: card


::::: center
### **技能点分配 📊**

:::::

**职业技能**（8 项本职 + 信用评级）：

按职业公式算点数（如记者 = `EDU`×4），分配到本职技能与信用评级

点数==加在基础值上==，没分完的作废

**兴趣技能**（`INT` × 2 点）：

可加==任意技能==（包括本职），克苏鲁神话除外

::: danger

创建角色时 ==不能给克苏鲁神话加点==

调查员开局对神话一无所知——这是设定，也是保护

:::

::: tip

**别雨露均沾**——技能点摊薄到每个技能=什么都不精

先想清楚角色的看家本领，把大点点给它

:::


::::: center
### **专攻制技能 🎯**

:::::

格斗、射击、科学、生存、艺术和手艺等大技能==拆成多项专攻==，点数只能给专攻：

- 格斗（斗殴）、射击（手枪）、科学（药学）——==不能==直接把点加给「格斗」「科学」母项
- 职业给了「射击」但没指定专攻 → 您==自选==一项或多项专攻
- 专攻基础值各不相同：斗殴 25、手枪 20、弓 15……见[技能速查](/rule/coc/guide/skills_table)
- 没有对应专攻时，`KP` 可允许用相近专攻代掷，但==难度提高==

::: tip

**看家武器成对买**——格斗（斗殴）+射击（手枪）是多数调查员的标配

斗殴 50+ 可以自选一种武术流派，写进背景

:::

## **💰 信用评级**

::::

---

:::: card


::::: center
### **生活水平表 💵**

:::::

信用评级代表财产与社会地位

用==本职技能点购买==，范围由职业决定（见[职业速查](/rule/coc/guide/jobs_table)）

::: table

| 信用评级 | 生活水平 |
|---|---|
| 0 | 赤贫：身无分文，露宿街头 |
| 1–9 | 贫穷：最便宜的出租屋 |
| 10–49 | 标准：普通住宅，三餐无忧 |
| 50–89 | 小康：大宅佣人，头等舱 |
| 90–98 | 富裕：豪宅庄园，大量豪车 |
| 99 | 豪富：钱只是数字 |

:::

合理原因（如「家里有钱」）+ `KP` 同意，==可以超职业上限==

::::

::: note

**现金与资产**：现金随手可用；资产（房产/投资）要花时间变现。消费水平内的日常开销==不记账==

大笔支出（购车、置业、雇人）才对照现金资产表结算

装备列表见第 396 页起、武器表见[武器速查](/rule/coc/guide/weapons_table)

:::

---

:::: card


::::: center
### **游戏中怎么花钱 🛒**

:::::

**日常**：每天可花 ≤ 消费水平的钱，==免记账==——住平价旅馆、吃饭、打车都不用管

**大额**：单笔超过消费水平，从 ==现金== 全额扣

现金不够 → 动用 ==资产==：变卖古董、抵押、贷款都需要 ==时间==（KP 裁定，人在外地更久）

一天内多次小额消费，`KP` 可汇总对照消费水平，超出部分扣现金

---

**买完东西信用评级变吗**——日常生活不变

信用评级 `CR` 只在==幕间成长==时复查，变化规则：

::: table

| 境况 | 变化 |
|---|---|
| 升职 | `CR` +1D6 |
| 意外之财 | 每次 +1D10，直到符合新档次 |
| 降职/无薪假 | `CR` −1D10 |
| 变卖家产 | `CR` −1D10 |
| 失业 | 每次幕间 −2D10 |
| 破产 | `CR` −1D100，最低 0 |

:::

失业后找到新工作，`KP` 可让 `CR` 回到新工作档次

::::

---

:::: card


::::: center
### **有故事的车卡（可选规则） 🎭**

:::::

每名玩家经 `KP` 同意可选 ==一个== 经历包：

::: table

| 经历包 | 技能点 | `SAN` 代价 | 免疫范围 |
|---|---|---|---|
| 战场 | +70 | −1D10+5 | 尸体/重伤员 |
| 警务 | +60 | −1D10 | 尸体 |
| 罪犯 | +60 | −1D10 | 尸体/暴力残害人类 |
| 医务 | +60 | −1D10 | 尸体/重伤员 |
| 神话 | 神话 +1D10+5（`KP` 允许内） | 最大理智相应降低 | — |

:::

经历包用 ==`SAN` 和伤疤== 换 ==技能和免疫==——有过去的调查员，比白纸更耐吓

若经历包增加年龄：先分配 `EDU` 提升产生的技能点，再分配经历包点数


::::: center
### **自定义经历包 ✏️**

:::::

列表之外的人生也可以做包。与 `KP` 商定四件事：

- **经历**：一段有分量的过去（远洋水手、殡仪馆化妆师、战地记者……）
- **技能**：60–70 点，只放进这段经历教得会的技能
- **代价**：`SAN` 损失 1D10 起，加一条相关伤疤或恐惧症
- **免疫**：这段经历让人麻木的理智损失类型

参照官方包的幅度（60 点/1D10），别超战场包的 70 点

自定义的原则是 ==与官方等价==


::::: center
### **全部经历包 🗺️**

:::::

官方共五个：战场、警务、罪犯、医务、神话——上表即全量

每个包的完整技能列表见调查员手册「有故事的调查员」一节

## **📜 背景**

::::

---

:::: card


::::: center
### **背景条目 🧷**

:::::

背景不是作文，是 ==几句话或要点==。角色卡背面十大类，前六项建卡时填（==至少一条==，越多越生动）：

- **形象描述**：英俊、邋遢、书卷气……
- **思想与信念**：一句话人生观（"科学能解释一切"）
- **重要之人**：谁对角色意义重大（记得起名字）
- **意义非凡之地**：一个有分量的地方
- **宝贵之物**：随身携带的宝物
- **特质**：慷慨大方、赌徒、万人迷……

后四类（创伤疤痕/恐惧症躁狂/典籍法术/第三类接触）==游戏中==才会被填上

每条背景都可以掷 1D10 随机表找灵感（规则书第 43–45 页）

随机结果与概念冲突时可以重掷——但别不假思索就扔掉

::::

---

:::: card


::::: center
### **关键连接 ⭐**

:::::

纵观全部背景条目，选出 ==最重要的一条==，用星号标出——这就是关键连接

- 帮助调查员==恢复理智==的锚点
- `KP` 不能随便摧毁它：玩家至少要有==一次掷骰拯救的机会==
- 失去关键连接：理智检定，损失 1/1D6

关键连接是您给角色系上的保险绳——选那条您最不忍心失去的

::::

---

:::: card


::::: center
### **背景三作用 💡**

:::::

1. **扮演引导**——提示角色是谁、与世界有何联系
2. **恢复理智**——幕间成长时用背景条目自救回 `SAN`
3. **腐化映射**——疯狂或重伤时 `KP` 会增改背景条目

理智越损耗，曾经珍视的一切越无意义

写下的是开始：调查员的过去会在游戏中不断长出来

::::

:::: card


::::: center
### **留个接班人 🕯️**

:::::

写出重要的家庭成员——哥哥、妹妹、徒弟

一旦调查员死亡或疯狂，==他们可以接过接力棒==

这也是 COC 的传统：故事比任何单个角色都长

## **🗡️ 装备与武器**

::::

---

:::: card


::::: center
### **带什么出门 🎒**

:::::

- 符合==生活水平==的日常物品（衣着、行李、手表）不用另花钱——视为已拥有
- 值得记录的==特殊物品==才写上卡：相机、指南针、医疗箱、武器
- 大额购置对照现金资产表，从现金/资产里扣


::::: center
### **武器校验 🔫**

:::::

- 武器有==年代栏==——1920s 团带不了沙漠之鹰，对照[武器速查](/rule/coc/guide/weapons_table)的年代列
- 带枪就要有对应==射击技能==（手枪/步霰……），格斗武器对应格斗技能
- 除士兵等职业，武器技能点通常来自==兴趣技能==——想带枪，车卡时就留好点

武器在 COC 里是保命底牌，不是解决问题的首选——用之前想想枪声会引来什么

### **网团与骰娘 🤖**

:::::

网团检定靠群里的骰娘（骰子机器人）代掷，常用指令：

::: table

| 指令 | 作用 |
|---|---|
| `.rd` | 掷 1–100 随机数 |
| `.r1d8` | 掷任意面数骰 |
| `.ra 侦查 60` | 技能检定：掷出 ≤60 即成功 |
| `.bot on/off` | 开关骰娘（管理员） |
| `.dismiss` | 请骰娘退群 |

:::

==善待骰子==：不踢群不刷屏不辱骂——恶意使用会进塔骰共享黑名单，全体系骰子拒接

面团则用实体骰：两个十面骰拼 `D100`，一个十位一个个位
