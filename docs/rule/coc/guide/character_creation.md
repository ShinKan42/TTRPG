### **八项属性 💪**

| 属性 | 缩写 | 是什么 |
|---|---|---|
| 力量 | STR | 物理力量和负重能力 |
| 体质 | CON | 健康和强壮程度 |
| 体型 | SIZ | 身高和体重的复合值 |
| 敏捷 | DEX | 反应速度和身手 |
| 外表 | APP | 魅力和外貌 |
| 智力 | INT | 聪慧程度和逻辑推理 |
| 意志 | POW | 意志力和心理稳定 |
| 教育 | EDU | 正式教育与社会经验 |

---

快速开始规则分配法：把 `40/50/50/50/60/60/70/80` 填入 8 项属性

（完整规则有掷骰法与购买法，以 KP 说明为准）

## **🧮 派生数值**

::::

---

::: card

### **自动计算 🖩**

属性定了，这些跟着算出来：

| 派生 | 算法 |
|---|---|
| 生命 HP | (SIZ + CON) ÷ 10，舍去小数 |
| 魔法 MP | POW × 1/5 |
| 理智 SAN | = POW（起始），上限 99 − 克苏鲁神话 |
| 伤害加值 DB / 体格 | 查 STR+SIZ 对照表 |
| 幸运 | 掷 3D6 × 5 |

---

伤害加值表（节选）：

| STR+SIZ | 伤害加值 | 体格 |
|---|---|---|
| 2-64 | −2 | −2 |
| 65-84 | −1 | −1 |
| 85-124 | 0 | 0 |
| 125-164 | +1D4 | +1 |
| 165-204 | +1D6 | +2 |

## **🗂️ 职业**

::::

---

::: card

### **职业 = 调查工具箱 🧰**

职业决定您擅长从哪个角度切入谜题：

- **学术型**：教授、考古学家、文物学家——图书馆是主场
- **社会型**：记者、私家侦探、律师——人脉与话术开路
- **技术型**：医生、工程师——专业技能破局
- **格斗型**：警察、军人——硬实力保命

---

任何您感兴趣的职业都可以，==只需与 KP 沟通达成一致==

自创职业：选 8 个技能作为本职技能 + 设定信用范围

:::

---

::: card

### **技能点分配 📊**

**职业技能**（8 项 + 信用等级）：

将 `1个70% / 2个60% / 3个50% / 3个40%` 填入

---

**兴趣技能**（4 项）：

选 4 个非本职技能，=基础值 + 20%=

---

==创建角色时不能给克苏鲁神话加点==

调查员开局对神话一无所知——这是设定，也是保护

:::

### **有故事的车卡 🎭**（可选规则）

每名玩家经 KP 同意可选 ==一个== 经历包：

| 经历包 | 效果概要 |
|---|---|
| 战场经历包 | 技能+70 点；SAN −1D10+5；对尸体/重伤员理智损失免疫 |
| 警务经历包 | 技能+60 点；SAN −1D10；对尸体理智损失免疫 |
| 罪犯经历包 | 技能+60 点；SAN −1D10；对尸体/暴力残害免疫 |
| 医务经历包 | 技能+60 点；SAN −1D10；对尸体/重伤员免疫 |
| 神话经历包 | 克苏鲁神话 +1D10+5；最大理智相应降低 |

---

经历包用 ==SAN 和伤疤== 换 ==技能和免疫==

有过去的调查员，比白纸更耐吓

## **📜 背景**

::::

---

::: card

### **信条 · 信念 · 重要之人 🧷**

背景不是作文，是 =几句话或要点=：

- ==信条==：一句话的人生观（“科学能解释一切”）
- ==重要之人==：谁对角色意义重大——危险，也是羁绊
- ==意义非凡之地==：一个有分量的地方
- ==珍贵之物==：随身携带的宝物
- ==背景包==：比如“手枪从不离身”

---

背景条目越 =挂得住=，故事就越咬得住您

KP 拿这些当钩子，把您拉进故事

:::

---

::: card

### **背景深化技巧 💡**

看看您的属性和技能：他们擅长什么？==为什么==？

- 射击高——是乡下长大跟着父亲打猎，还是进城后买了手枪？
- 精通机械——是职业需要，还是热情的业余发明家？

---

考虑教育：EDU 代表什么水平？大学期间是社团成员吗？

EDU 偏低——是什么让他没能继续学业？

---

==不要设定过多==——太多背景会限制临场发挥

角色会在游戏中逐渐丰富，给他们留出自由活动的空间

:::

---

::: card

### **留个接班人 🕯️**

写出重要的家庭成员——哥哥、妹妹、徒弟

一旦调查员死亡或疯狂，=他们可以接过接力棒=

这也是 COC 的传统：故事比任何单个角色都长

:::
