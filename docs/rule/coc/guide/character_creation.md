## **📋 流程**

::::

---

::: card

### **⚡ 车卡六步**

1. 与 KP 沟通：时代、地点、前提设定
2. 分配 8 项属性，写下半值与五分之一值
3. 算出派生数值
4. 选职业，记录 8 项本职技能
5. 分配技能点，再选 4 项兴趣技能
6. 写背景，填姓名、性别、年龄

:::

::: tip

**先想「人」，再想「数据」**

数据规则交给 KP，您专注思考角色的 ==人生==

:::

### **💪 八项属性**

::: table

| 属性 | 缩写 | 是什么 |
|---|---|---|
| 力量 | STR | 物理力量与负重 |
| 体质 | CON | 健康与强壮 |
| 体型 | SIZ | 身高体重的复合值 |
| 敏捷 | DEX | 反应速度与身手 |
| 外表 | APP | 魅力与外貌 |
| 智力 | INT | 聪慧与逻辑推理 |
| 意志 | POW | 意志力与心理稳定 |
| 教育 | EDU | 正式教育与社会经验 |

:::

快速开始分配法：把 `40 / 50 / 50 / 50 / 60 / 60 / 70 / 80` 填入 8 项属性

完整规则另有掷骰法与购买法，以 KP 说明为准

::::

::: note

**半值与五分之一值**——属性旁顺手记下它的 50% 与 20% 值：力量 60 记作 60（30/12）

这两个数是检定的 ==困难== 与 ==极难== 成功线，详见[常用骰法](/rule/coc/guide/quick_roll)

:::

## **🧮 派生数值**

::::

---

:::: card

### **🖩 自动计算**

属性定了，这些跟着算出来：

::: table

| 派生 | 算法 |
|---|---|
| 生命 HP | (SIZ + CON) ÷ 10，舍去小数 |
| 魔法 MP | POW × 1/5 |
| 理智 SAN | 起始 = POW |
| 伤害加值 DB | 查下方 STR+SIZ 表 |
| 体格 | 与 DB 同表 |
| 幸运 | 掷 3D6 × 5 |

:::

::: note

**魔法值细则**：每小时恢复 1 点；耗尽后继续支出，==从生命值扣除==

理智会随遭遇波动，机制详见[理智与疯狂](/rule/coc/guide/sanity)

:::

## **🗂️ 职业与技能**

::::

---

:::: card

### **🧰 职业 = 调查工具箱**

职业决定您擅长从哪个角度切入谜题：

- **学术型**：教授、考古学家、文物学家——图书馆是主场
- **社会型**：记者、私家侦探、律师——人脉与话术开路
- **技术型**：医生、工程师——专业技能破局
- **格斗型**：警察、军人——硬实力保命

28 个范例职业全数据见[职业速查](/rule/coc/guide/jobs_table)，各技能说明见[技能速查](/rule/coc/guide/skills_table)

任何职业都可以，==只需与 KP 沟通达成一致==

自创职业：选 8 个技能作本职技能 + 设定信用范围

::::

---

:::: card

### **📊 技能点分配**

**职业技能**（8 项本职 + 信用评级）：

把 `1 个 70% / 2 个 60% / 3 个 50% / 3 个 40%` 填入——==直接填写，忽略基础值==

**兴趣技能**（4 项）：

选 4 个非本职技能，==基础值 + 20%==

::::

::: danger

创建角色时 ==不能给克苏鲁神话加点==

调查员开局对神话一无所知——这是设定，也是保护

:::

## **💰 信用评级**

::::

---

:::: card

### **💵 生活水平表**

信用评级代表财产与社会地位，范围由职业决定（见[职业速查](/rule/coc/guide/jobs_table)）

::: table

| 信用评级 | 生活水平 |
|---|---|
| 0 | 身无分文，流落街头 |
| 1–9 | 极端贫困，勉强果腹 |
| 10–49 | 中等水平，合理舒适 |
| 50–89 | 富裕，近乎奢侈 |
| 90–98 | 富有，极为奢侈 |
| 99 | 超级有钱，钱只是数字 |

:::

日常吃住行不记账，只有==大笔支出==（置业、购车、雇人）才动用信用评级

## **📜 背景**

::::

---

:::: card

### **🧷 信条 · 信念 · 重要之人**

背景不是作文，是 ==几句话或要点==：

- **信条**：一句话的人生观（"科学能解释一切"）
- **重要之人**：谁对角色意义重大
- **意义非凡之地**：一个有分量的地方
- **珍贵之物**：随身携带的宝物
- **背景包**：比如"手枪从不离身"

==两三条已经足够==——写满背景栏反而限制临场发挥

::::

---

:::: card

### **💡 背景深化技巧**

看看您的属性和技能：他们擅长什么？==为什么==？

- 射击高——乡下长大跟父亲打猎，还是进城买了手枪？
- 精通机械——职业需要，还是热情的业余发明家？

EDU 偏低——是什么让他没能继续学业？

::::

---

:::: card

### **🕯️ 留个接班人**

写出重要的家庭成员——哥哥、妹妹、徒弟

一旦调查员死亡或疯狂，==他们可以接过接力棒==

这也是 COC 的传统：故事比任何单个角色都长
