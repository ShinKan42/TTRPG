## **⚡ 用法**

读书三件套：涨 ==克苏鲁神话==、掉 ==`理智值`==、学法术——跑团核心循环的一环

全部 96 版本出自 40 周年版第十一章

同书不同版本数值不同——录入时按玩家拿到的那一版结算

::: tip

==略读==（数小时-数周，`KP` 定）：可能需 `阅读` `检定`，得 `CMI` 点神话技能；相信者按典籍 `理智值` 损失掷骰


==精读==（按周数）：无需 `检定`；神话技能未达本书 `神话等级` 得全 `CMF`，已达=只得 `CMI`


学法术需至少略读过；耗时通常 `2D6` 周（`KP` 定）


:::
