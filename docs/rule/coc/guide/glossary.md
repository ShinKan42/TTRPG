## **🎲 检定**

::::

::: table

| 中文 | 英文 | 是什么 |
|---|---|---|
| 百分比骰 | Percentile Dice (`D100`) | 两个十面骰拼 1–100 |
| 常规成功 | Regular Success | ≤ 技能值 |
| 困难成功 | Hard Success | ≤ 半值 |
| 极难成功 | Extreme Success | ≤ 五分之一值 |
| 大成功 | Critical | 掷出 01 |
| 大失败 | Fumble | 96–00 间的高值 |
| 奖励骰 | Bonus Dice | 掷两个十位取更好 |
| 惩罚骰 | Penalty Dice | 掷两个十位取更差 |
| 孤注一掷 | Push | 换方法重试，失败更糟 |
| 对抗检定 | Opposed Check | 双方各掷比成功等级 |
| 灵感检定 | Idea Roll | `INT` 检定，卡关时找线索 |
| 知识检定 | Know Roll | `EDU` 检定，回忆信息 |

:::

## **📜 背景**

::::

::: table

| 中文 | 英文 | 是什么 |
|---|---|---|
