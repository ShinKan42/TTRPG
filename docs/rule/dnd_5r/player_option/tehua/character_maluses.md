## **🎯 这是什么**

:::

::: card

**角色减益**（Maluses）是一套车卡可选规则，来自 [Pointy Hat](https://www.youtube.com/@ThePointyHat) 的社区设计（[原视频](https://www.youtube.com/watch?v=HMR5zL5oTLw)）。

它把角色背景里的弱点变成==真实机制==：==文盲==读不了字、==恐高==下不了崖、==谎撒不利索==——不是为了变强，是为了让角色的缺陷在桌上真实发生，让同行的人看见他背负着什么。

每条减益都是一道==可以设计剧情的开口==：一个"预期有一天克服它"的减益，就是一条等着的成长线。

:::

## **📜 使用守则**

:::

::: card

- **DM 同意制**：选减益前==必须先过 DM==，并和 DM 一起挑适合当前战役的那条。
- **必须会在桌上出现**：选下来的减益要在冒险里==真的冒头==，而不是写完就忘；
- 它也不该变成全桌冲突的永久来源。
- **克服预期要明说**：如果你选减益就是等着剧情里战胜它，把这个预期告诉 DM，DM 好在合适的时机安排机会。

==双版兼容==：2014 与 2024 车卡规则都能用。
武僧那条提到的「气点」只是措辞差异，两版实现完全相同。

:::

## **📋 通用减益**

:::

::::: card

- **烂谎精**：所有魅力（欺瞒）检定==带劣势==——可以是性格选择，也可以是天生不会撒谎。
- **笨手笨脚**：敏捷（巧手）与敏捷（隐匿）检定带劣势。
- **元素疤痕**：选一种伤害类型（火焰、冷冻、雷鸣、黯蚀等），你==无法造成==该类型的伤害。
- **宿敌纠缠**：对一类特定怪物（如野兽、淤泥怪）或一种特定怪物（如鬼婆）的攻击==带劣势==；
  - 也可以反过来——那种怪物对你的攻击==有优势==。
- **恐高**：身处高于 20 尺落差的边缘 5 尺内时，须通过感知豁免（DC 10 + 熟练加值），失败陷入恐慌状态；
  - 每过 10 分钟可重复豁免；
  - 离开高处自动解除。
  - 同伴若与你相熟，可用协助动作给你的豁免优势。
- **恐水**：潜入水下时速度降为 5 尺且==陷入恐慌状态==；
  - 须通过感知豁免（DC 10 + 熟练加值）摆脱，每过 10 分钟可重复；
  - 离开水域自动解除。
  - 同伴协助同上。
- **恐黑**：陷入完全黑暗（魔法或自然）时，须通过感知豁免（DC 10 + 熟练加值），失败陷入恐慌状态；
  - 每过 10 分钟可重复；
  - 离开黑暗自动解除。
  - 同伴协助同上。
- **强制伪装**：你必须维持伪装遮掩真身——要么每天消耗一项资源（生命值、职业特性次数等），要么每月付出一次昂贵代价（吞食特定植物、摄取一个生灵魂魄之类）；
  - 付出什么、多久一次，建卡时与 DM 商定。
- **脆弱之躯**：长休要==多休息两小时==（多数角色因此是十小时）；
  - 此外每次获得力竭时，力竭等级要多加一级。
- **文盲**：你==无法阅读==，包括用你自己会的语言；
  - 所有需要阅读的属性检定==自动失败==。
- **厄运缠身**：每次长休一次，DM 可以指定你的一项属性检定、豁免或攻击骰带劣势。
- **可靠的无能**：选一个你没有熟练项也没有专精的技能；
  - 做该技能的检定时，从结果里==扣掉你的熟练加值==。
- **怯场**：超过 5 个生物在看着你时，你的所有魅力检定==带劣势==。

## **🗡️ 职业专属**

:::

:::: center

::: table

| 职业 | 减益 | 效果 |
|---|---|---|
| 野蛮人 | 狂怒失智 | 用掉最后一次「狂暴」次数时，须过感知豁免（DC 10 + 熟练加值）：失败则攻击最近的生物——敌友不分——且无法自愿结束狂暴；每回合结束可重复豁免解除 |
| 吟游诗人 | 灵感枯竭 | 当前生命值低于上限一半时，无法给予他人「激励」 |
| 牧师 | 神圣敬畏 | 选一个「引导神力」效果；使用它时须过感知豁免（对抗你自己的法术豁免 DC），失败则震慑到你下回合结束 |
| 德鲁伊 | 水土不服 | 从大地结社子职的地形清单选一种；身处该地形时，感知（驯兽）、感知（生存）、智力（自然）检定全部带劣势 |
| 战士 | 极限反噬 | 用掉最后一次「动作如潮」时，须过体质豁免（DC 10 + 熟练加值）：失败则震慑到你下回合结束 |
| 武僧 | 耗命之术 | 选一个消耗气点的特性；每次使用它，失去等同所耗气点数的生命值 |
| 圣武士 | 殉道者义务 | 使用「圣疗」时须过魅力豁免（对抗你自己的法术豁免 DC）：失败则失去等同治疗量一半（向上取整）的生命值；或者——二选一——圣疗无法用来治疗你自己 |
| 游侠 | 兽群宿敌 | 选一种野兽（可以宽到「哺乳类」，也可以窄到「熊」，与 DM 商定）；与这类野兽互动的一切技能检定带劣势 |
| 游荡者 | 伏击依赖 | 偷袭目标的 5 尺内必须有目标的另一名敌人——即使你手握优势也不能单打独斗下手 |
| 术士 | 不稳魔力 | 每次长休结束时，由你或 DM 选定一个超魔选项；使用该超魔时，掷狂野魔法表 |
| 邪术师 | 代价高昂 | 选一个你拥有的神秘眷注；每次使用它，DM 可以让恩主开口索要回报——一个法术位、等同熟练加值的生命值，或一件与恩主目标相关的小差事 |
| 法师 | 偏科问题 | 选一个魔法学派；把该学派的法术抄进法术书要多花 1 小时、多花 50 金币 |
