#### **🗡️ 职业**

:::

==可选择的战斗与施法职业==

职业决定角色用什么方式面对世界——是挥舞武器的战士、钻研奥术的法师、托付信仰的牧师，还是别的什么。它决定了你每回合能做什么、擅长什么、在队伍里扮演什么位置：站在前排扛伤害，还是躲在后排施法，抑或游走在两者之间。子职是职业内部的==分岔路口==：同样是战士，走剑术大师还是走战术指挥官，桌上的体验是两回事，社区设计的子职往往把某个玩法推向官方没有的方向。官方职业玩腻了，这里能找到新的活法——本区块收录 kiwee 与不全书之外的社区职业与子职设计，职业池变宽，角色概念的落地选择随之变多。

#### **🧝 种族**

:::

==角色出生的种族与族系==

种族回答「你从哪里来」：它给角色一组与生俱来的特质——黑暗视觉、飞行、魔法感知、特殊血脉——这些能力从一级就改变你面对困境的方式。精灵能看穿黑暗，龙裔能吐出龙息，种族特质常常在关键时刻提供职业给不了的答案。

比数值更深一层的是==身份与视角==。一个兽人冒险者在人类城镇会被怎样看待？提夫林的角和瞳色带来什么目光？社区种族设计往往伴随成套的族系文化，给扮演提供抓手——角色的言行举止、他人的反应、与某些势力的天然亲疏，都从血统里长出来。

本区块收录社区自创或第三方资料的种族与族系扩展，含亚种与变体。给玩家的乐趣在于：==扮演非人视角==的机会变多，出身自带故事；给团的价值在于：世界的人种构成更丰富，NPC 也可以用这些族系来造。

#### **💪 专长**

:::

==升级时换取的特殊能力==

专长是==定制化==的入口。升级时放弃属性提升、换一个专长，等于把成长点投进一个具体的手艺：使双武器更狠、让法术更刁钻、在社交场上多一手。选专长是在回答「我的角色特别会做什么」——它把一个职业模板变成一个具体的人。

半专长与专长树给这条定制路提供了更多台阶：半专长给一点属性加成加一项小能力，门槛低、适配广；专长树则让某个方向越走越深。社区专长常常瞄准官方没覆盖的玩法缝隙——新的战斗风格、独特的施法变体、只在特定情境发光的能力。

本区块收录社区设计的专长与半专长。给玩家的乐趣在于：==角色构建的深度与个性==，找到那个「这就是我的角色会选的」专长；给团的价值在于：专长池宽了，角色之间的差异化更明显，没有两个队员长一个样。

#### **✨ 法术**

:::

==施法者可学的法术与整张扩展法表==

法术是 DND 里==最可玩的部分之一==：每个环级都是一层新的解决问题手段。一环的魔法飞弹和燃烧之手决定低级团怎么打；到了高环，传送、异界之门、时间停止，直接改写「什么问题算问题」。法术表就是施法角色的工具箱，工具箱里有什么，决定你遇到麻烦时脑子里冒出什么方案。

社区新增法术的乐趣在==填空白==：官方法术没覆盖的伤害类型、没想过的应用场景、更奇怪的效果形态——召唤一堵会走的墙、把声音变成武器、让某个法术出现完全不同的用法。新法术进桌面，往往带来「原来还能这么打」的时刻。

本区块收录社区新增法术与整张扩展法表，环级与职业列表随来源各异。给玩家的乐趣在于：==施法角色的新玩具==与构建新思路；给团的价值在于：法术解法变多，DM 设计遭遇时要考虑的变量也更丰富。

#### **🎒 物品**

:::

==角色可获得的装备、魔法物品与奇物==

物品是==桌上流转的实物==：一把带故事的剑、一瓶救命的药水、一件不知道会触发什么的奇物。武器护甲改数字，消耗品改节奏，而真正让团难忘的往往是那些==效果奇怪的魔法物品==——会说话的盾、注定招灾的骰子、用了就回不了头的契约卷轴。物品把冒险的奖励变成看得见摸得着的东西。

社区设计的物品扩展常常在官方列表的边缘发挥：更古怪的诅咒、更专门用途的工具、给非战斗角色准备的好东西。DM 把它们撒进战利品，玩家拿到手的每一件都可能是接下来几场戏的主角。

本区块收录社区设计的装备、魔法物品与奇物。给玩家的乐趣在于：==开箱与发现==，每件战利品都有想象空间；给团的价值在于：奖励形式更多样，物品可以自己长出剧情。

#### **🎭 ACG 角色**

:::

==把 ACG 人物做成可上车桌的玩家角色==

这个区块做一件很直接的事：把动画、漫画、游戏里的人物，==翻译==成能在 DND 桌上开的角色。不是贴皮套壳，而是把那个角色的能力、性格、成长命题拆开，用职业、种族、专长重新组装，让你在跑团里真的「成为」那个角色开一场冒险。

现收两个方向：[Madoka Magica](/rule/dnd_5r/player_option/acg/madoka_magica) 把魔法少女的契约与代价搬进桌面规则，[1999](/rule/dnd_5r/player_option/acg/1999) 处理神秘学爱好者的时代群像。两者都是==自制／二创==内容、非官方资料，玩法与设定细节以各自页面为准。

给玩家的乐趣在于：==用熟悉的角色进入陌生的冒险==——你比谁都懂这个人物会怎么选；给团的价值在于：预设好的角色命题自带扮演张力，适合想快速入戏的玩家。新内容一律进本区。
