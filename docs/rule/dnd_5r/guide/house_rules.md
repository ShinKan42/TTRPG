<a id="答案卡"></a>
### **答案卡 🃏**

:::

:::: card

OB（旁观）或暂时无法参与剧情时，向 DM ==申请领卡==——新玩家开场会先送 2 张

用法：按卡面文字与 DM 讨论，==修改当下的剧情==

卡面指向当下的行动，已经翻篇的事不回头改

改成什么样要过两关：世界推演说得通、角色动机立得住——DM 跟你一起商量

::: details 来源与核对

2026-08-09 黄金宝库之钥场 1 村规讲解段：OB 或无法参与剧情时可申请，新玩家送 2 张；按卡面文字与 DM 讨论修改剧情，须符合世界客观推演与动机；答案卡指向当下行动，非时光回溯

:::

<a id="命运币"></a>
### **命运币 🪙**

:::

:::: card

每人一枚，`长休`时恢复

- **声明**——说出这枚币用在哪次 `d20` 检定上
- **抛币**——抛硬币问 DM 一个是非题：答案 yes，该检定 ==+10==；答案 no，==-5==

赌输想翻本：烧掉 <Badge type="danger" text="1d20 + 职业等级" /> 点生命值，立刻重新获得硬币，可以继续赌

适合剧情关键节点——不想把结果单纯交给骰子的时刻

::: details 来源与核对

2026-08-09 黄金宝库之钥场 1 村规讲解段：命运币用于 d20 检定，yes +10 / no -5，长休恢复；继续赌须烧 1d20+职业等级生命值重新获得

<a id="塔罗牌"></a>
### **塔罗牌 🔮**

:::

:::: card

触发：做出==非常符合角色==的精彩桥段，由 DM 发牌——玩家也可以自荐

打出：按牌面共创一段符合牌义的场面，效果相当于加强版答案卡

不想发挥也行：把牌折成**经验**、**装备**或**财宝点**作保底

::: details 兑换与规则

塔罗牌的完整规则、牌组与 DND 桌兑换数值，见站内[塔罗牌页](/about/tarot)

<a id="铃铛"></a>
### **铃铛 🔔**

:::

:::: card

每人一个，三种用法：

- **打断**——想让场面停下来就按
- **玩家层沟通**——扮演内容让你不舒服（比如涉及 PvP 的玩法），按铃回到玩家层面商量
- **安全词**——桌上有你不想碰的要素，按铃快速跳过，==不需要解释==

铃铛随时可按

::: details 来源与核对

2026-08-09 黄金宝库之钥场 1 村规讲解段：铃铛三种作用——打断；玩家层沟通（PvP 玩法玩得不舒服时回到玩家层面讨论）；安全词（不想提起的要素快速跳过）

:::

<a id="黑白骰"></a>
### **黑白骰 🎲**

:::

:::: card

掷出 ==20==：获得**白骰**——之后任何 `d20` 检定都能用它，相当于自选时机多掷一次

掷出 ==1==：DM 收走一枚**黑骰**

你打出白骰时，DM 按事情的重要程度打出黑骰与你拼点——黑骰大于等于白骰，白骰作废

白骰与黑骰==每场清零==

::: details 来源与核对

2026-08-09 黄金宝库之钥场 1 村规讲解段：掷 20 得白骰可用于一切 d20；掷 1 得黑骰；白骰打出时 DM 按重要程度用黑骰拼点，大于等于则白骰作废

<a id="重击确认"></a>
### **重击确认 🎯**

:::

:::: card

`重击`（攻击掷出天然 20）后，==再投一次攻击检定==做确认

- **未命中**——正常 `重击`：伤害骰多投一次翻倍
- **命中**——伤害拉满：所有骰子取最大值，`调整值`同样翻倍
- **再次天然 20**——==一击必杀==

::: details 规则细节

村规沿用了 3R 的 `重击` 确认并进一步增强了 `重击`，完整判定见[战斗页 · 重击](./combat#重击)

<a id="财宝点"></a>
### **财宝点 💰**

:::

:::: card

团队财富的记账单位：战利品不再一件件数，==统一折算成财宝点==

- **兑换道具**——消耗财宝点，主动换取想要的东西
- **烧装备换经验**——装备按全价烧掉换成经验（按经验表升级，例：3 级升 4 级需要 1800 点）；按半价处理则是卖出

塔罗牌的保底兑换也能折成财宝点——当前 tier 装备价值的一半

::: details 来源与核对

腐化王朝团配置通用村规表：物品统一计价，烧装备换经验（升级按经验表，3→4 级=1800），全价烧=收藏经验，半价卖出；塔罗页兑换路：当前 tier 装备价值 ×½ 折算财宝点

:::

<a id="扎营物料"></a>
### **扎营物料 ⛺**

:::

:::: card

`长休`要消耗扎营物料：==3 磅，0.3 金币==

缺料的长休，恢复效果==减半==

长途模组动辄几十天路程，补给是要认真管的账

::: details 来源与核对

腐化王朝团配置通用村规表：扎营物料 3 磅 0.3gp；缺料长休恢复减半（模组含几十天路程，拟真补给）

<a id="村规怎么用"></a>
## **🤝 村规怎么用**

:::

:::: card

- **开场听讲**——DM 开场会讲一遍当团村规，对照本页即可
- **要用直接开口**——「我拿一张答案卡」「我抛个命运币」，说一声就用
- **不舒服就按铃**——扮演边界、不想碰的要素，铃铛就是干这个的
- **落点在商量**——每条村规的最终效果由 DM 现场裁定，拿不准就问
