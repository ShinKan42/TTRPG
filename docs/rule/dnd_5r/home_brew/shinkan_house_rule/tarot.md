## 总则

### 发牌与持有

- 由 **DM 发牌**：角色做出特别有风味的事情、完成一次角色塑造的小成就时发放。玩家可以自荐，桌上一句商量，决定权在 DM。
- **每名玩家至多持有 2 张**。手上满员时，先打掉或兑换一张，才能领新的。
- 两副牌分工：本页塔罗牌用于日常共创；**万事万象无常牌**在命运重大转折时抽取，见另页。

### 打出（一条主路 · 三条兑换）

持牌期间随时可打出，打出即消耗该牌。卡面上的三个层次只是**参考**，不是剧本：

| 层次 | 是什么 | 怎么用 |
|------|--------|--------|
| **牌义** | 这张牌讲的核心是什么 | 想效果时的出发点 |
| **叙事触发** | 一个现成的塑造创意 | 想借这张牌演一段好戏，从这里起笔 |
| **机械锚定** | 一份照单即领的保底 | 不想发挥时，直接领走条款里那份好处 |

在此之上，你可以围绕牌面在当前场景**自由提出想要的任何效果**，与 DM 商量落地；能做到什么程度，由 DM 掌握分寸。懒得发挥时，走任意一条兑换路作保底：

| 路径 | 内容 |
|------|------|
| **兑换经验**（大额保底） | 当前 tier 品阶装备价值 **× 2** 折算 XP |
| **自选装备**（实物） | 从物品表任选一件**当前 tier 品阶**的装备入手（神器无定价，不在此列） |
| **兑换财宝点**（小额保底） | 当前 tier 品阶装备价值 **× ½** 折算财宝点 |

每 **5 级**为一档，共四个 tier，按打出那一刻角色所处的档计算：

| Tier | 等级区间 | 品阶（自选装备档） | 物品价值 | 兑 XP（×2） | 兑财宝点（×½） |
|:----:|:--------:|:----:|---------:|------------:|---------------:|
| 1 | 1–5 | 非普通 | 400 gp | 800 | 200 |
| 2 | 6–10 | 珍稀 | 1,600 gp | 3,200 | 800 |
| 3 | 11–15 | 非常珍稀 | 6,400 gp | 12,800 | 3,200 |
| 4 | 16–20 | 传奇 | 25,600 gp | 51,200 | 12,800 |

## 大阿卡那（22 张）

大牌与小牌机械强度持平；大牌的叙事触发更开阔，能在更大范围内改写场面。

### 0 愚者

**牌义**：不顾风险而有所行动、活在当下、自发性

| 层 | 内容 |
|------|------|
| 象征 | 包袱敞着口，脚步已经跨出门——**活在当下**的人，行装从来没收好过。 |
| 叙事触发 | 你的角色**凭一时冲动做出行动**——不计算后果，跟着当下的感觉走。这件事在合理范围内出乎所有人的意料。 |
| 机械锚定 | 你可以宣布「**我其实带了 / 准备了 \_\_\_**」——在合理范围内，你确实带了。DM 原则上不拒绝。 |

### I 魔术师

**牌义**：新计划好时机、着手新事物

| 层 | 内容 |
|------|------|
| 象征 | 案上四件家什各就各位，术士抬手落指——着手**新事物**，正是好**时机**。 |
| 叙事触发 | 你的角色决定**在此刻启动一件新的事**——一个计划、一个方向、一种此前没有尝试过的方法。不是旧路线的延续，是一个真正的开端。 |
| 机械锚定 | 你获得**恰好需要的第一步**——一件此刻就用得上的工具、一条关键信息、或一个正好在场的帮手。由 DM 确定。 |

### II 女祭司

**牌义**：向内探索沉思、按兵不动、退缩反省、思考、可能性、直觉、精神

| 层 | 内容 |
|------|------|
| 象征 | 帷幕半掩，月轮落在她脚边——**直觉**是向内走的路，门外喧嚣至此止步。 |
| 叙事触发 | 你的角色**选择不行动**——在所有人急于推进的时刻，停下来，退一步，向内审视。这份静默让你察觉到行动中会错过的东西。 |
| 机械锚定 | 向 DM 提出**一个是非问题，获得真实回答**。 |

### III 女皇

**牌义**：家庭、稳定、务实、实现计划、亲近自然、家庭之爱

| 层 | 内容 |
|------|------|
| 象征 | 从内在的丰饶之地培养生命与联系。稳定是根基深扎后的从容生长——实现计划的土壤已经肥沃。滋养的代价是承担重量，像牧人背着过于沉重的羊群。 |
| 叙事触发 | 你的角色在当前场景中做出一个**滋养或巩固**的行为——照料伤病、修缮场所、为他人提供依靠、或在动荡中建立一方安定。这个行为会留下持久的影响。 |
| 机械锚定 | 一个 NPC 将你的队伍视为**家人**，愿意在力所能及的范围内提供长期支持——住所、食物、情报、或人手。由 DM 确定是谁。 |

### IV 皇帝

**牌义**：训练、自律、律法、务实、父亲

| 层 | 内容 |
|------|------|
| 象征 | 石座上的人连胡须都修剪整齐——**自律**立起的权威无需头衔。秩序是他的后盾，也会成为他的囚笼。 |
| 叙事触发 | 你的角色以**不可辩驳的正当理由**介入——援引律法、纪律、军事传统、或一个已被认可的正式身份，让在场者不得不按你的规矩行事。 |
| 机械锚定 | 场景中一项**规则或秩序暂时由你制定**——一支巡逻队的行进路线、一间酒馆的座次、一场谈判的议程。NPC 会配合，直到出现更强的干预。 |

### V 教皇

**牌义**：为自己负责、亲身经验、向正统俗例屈服、找到其他方式与可能

| 层 | 内容 |
|------|------|
| 象征 | 三重冠下的老者也磕破过膝盖——教条这条路，**亲身经验**过后才有资格谈背离。信仰未经考验就不属于你。 |
| 叙事触发 | 你的角色展现了**一种与众不同的做法**——不是因为叛逆，而是因为你找到了比常规更好的方式。这个做法让在场者重新审视自己习以为常的信条。 |
| 机械锚定 | 你获得关于当前局面的一项**传统知识或禁忌秘闻**——只有内部人士或资深者才知道的信息。由 DM 确定具体内容。 |

### VI 恋人

**牌义**：为爱做决定、学习决定、保留现有或安全进入新阶段

| 层 | 内容 |
|------|------|
| 象征 | 分岔路口两手空空——**选择**的代价是永恒的：选了这个就放开那个。最深的伤口往往来自你最信任的那只手。 |
| 叙事触发 | 你的角色面临（或主动制造）一个**必须做出选择的时刻**——两扇门、两个承诺、两条路。你选择的那条会打开，没选的那条将关闭。DM 根据你的选择呈现后果。 |
| 机械锚定 | 你获得一个**与你选择绑定的新关系或新通道**——一位盟友、一条联络线、或一处通行权。选择什么就得到对应的东西。 |

### VII 战车

**牌义**：训练有素的心智、控制对立的力量、理智控制矛盾、坚持、掌控

| 层 | 内容 |
|------|------|
| 象征 | 两匹反向的野兽拉动同一辆战车——胜者是谁的手在握缰绳。能让矛盾服从而行的**掌控**，出自长年的训练。 |
| 叙事触发 | 你的角色在当前冲突中展现出**训练有素的掌控力**——精确判断时机、协调矛盾力量、将混乱纳入秩序的能力。在场者看到的是一个不可撼动的意志。 |
| 机械锚定 | 你可以选择当前战场或场景中的**一项对立因素转为你所用**——一个敌人出现犹豫、一处障碍成为掩体、一股混乱力量转向有利方向。由 DM 确定具体表现。 |

### VIII 力量

**牌义**：内在力量、有能力面对和改变、勇气、学会从爱而不是控制里找到力量

| 层 | 内容 |
|------|------|
| 象征 | 少女合上狮子的血盆大口，手上没有缰绳——真正的**力量**让它自己低下头。勇气来自愿意伸出的那只手。 |
| 叙事触发 | 你的角色面对一个**本该恐惧或愤怒的事物**，选择不退缩也不以暴力回应——直面它，以耐心和善意接近。这个选择让局面发生意料之外的转变。 |
| 机械锚定 | 一头敌对生物或一个敌意存在**暂时停止对你的攻击行为**。不一定是友好的，但它此刻不把你当敌人。持续时间由 DM 确定。 |

### IX 隐者

**牌义**：省思、寂静、学习独处、内心探索、停下来思考

| 层 | 内容 |
|------|------|
| 象征 | 提灯人的光只够照亮脚下一级石阶——**寂静**里，答案自己沉淀出声音。灯不为照亮别人，是他向内走时的随身之物。 |
| 叙事触发 | 你的角色**主动脱离队伍或行动**，独自沉思。这段独处不是浪费——在静默中，你拼凑出了喧嚣中看不到的图景。 |
| 机械锚定 | 你从 DM 处获得**一个关于当前任务的隐藏线索**——一条此前没人注意到的联系、一个被忽略的细节、或一段从现有信息中推导出的推论。 |

### X 命运之轮

**牌义**：境遇的改变、无常变化、适应改变、塞翁失马；重复的模式、好好反省、迎接未来

| 层 | 内容 |
|------|------|
| 象征 | 轮子爬到顶的和跌下来的正在换位置——**无常**从不提前打招呼。塞翁失马，翻面的那一刻既是打击也是入场券。 |
| 叙事触发 | 你的角色**主动搅动一个僵滞的局面**——向按老轨道重复运转的事扔进一个你引入的变数。没人能保证结果，但你打破的是一个必输的循环。 |
| 机械锚定 | 变局落定的那一刻，**一样恰好易了主、落到你手里的东西**出现——一把钥匙、一枚徽记、一纸任命、一个空出的位置，由 DM 从当前局面挑一样落到实处。 |

### XI 正义

**牌义**：负起责任、种瓜得瓜、应得的、法律；不诚实、责备他人、窘况反复出现

| 层 | 内容 |
|------|------|
| 象征 | 天平两端放的不是善恶，是因果。种瓜得瓜从不体谅眼泪，也从不错付每一分耕耘——它只要求一件事：自己的账自己认，不逃。 |
| 叙事触发 | 你的角色**当众认下一项属于自己的后果**——不推诿不装傻，直面自己决定的代价；或当面要求欠账之人认账。 |
| 机械锚定 | 这份担当换来**制度性的回报**——一方权威正式承认你的立场、一笔应得的补偿、或一项落字为凭的保障。由 DM 确定。 |

### XII 倒吊人

**牌义**：顺从命运、顺势而为、投降、独立平静；无法自由、抗拒自我、受到拘束

| 层 | 内容 |
|------|------|
| 象征 | 吊在树上的人表情安详——他停下了挣扎，反倒第一个看清了整片林子。放下对抗的那个瞬间，他拿到了全局最稀缺的东西。 |
| 叙事触发 | 你的角色**主动放下抵抗**——在一处争锋里收手、退让、顺势而为，把本来要硬拼的一回合让出去。 |
| 机械锚定 | 作为退出者的你看见**局内人看不见的东西**——退路上浮出的通道、对全场态势一览无余的视野。由 DM 确定。 |

### XIII 死神

**牌义**：结束、去旧迎新、顺从改变、接纳改变；极度恐惧、单调重复对抗改变

| 层 | 内容 |
|------|------|
| 象征 | 黑旗下倒下的无人穿丧服——**结束**才是下一场的敲门声。这张牌从不指肉身：一段身份、一种活法、一个再也回不去的位置。 |
| 叙事触发 | 你的角色**亲手终结一样过时的东西**——一段关系、一种依赖、一套不再管用的做法——并公开告别它。 |
| 机械锚定 | 旧物烧尽处长出**新芽**——一项由这次终结直接解锁的新可能：新的道路开端、新的身份资格、新的力量来源，由 DM 按局面择一落实。 |

### XIV 节制

**牌义**：行动与感情融合、内心的平静、适当行为、自我和谐、尽力而为；自我分裂

| 层 | 内容 |
|------|------|
| 象征 | 一只脚踏在岸上一只踏在水里，两杯之间的水永远对流不尽——**调和**是持续的动作。快慢冷热，调到刚刚好的那一口。 |
| 叙事触发 | 你的角色出面充当**两个对立声音之间的调停者**——不站队，而是找出两条路都能走通的那条窄道。 |
| 机械锚定 | 调和达成后，对立双方**各自向你敞开一道门**——双方各欠你一分人情、各给你一份通行或许可。由 DM 确定。 |

### XV 恶魔

**牌义**：错以为别无选择；物质、契约、形式的制约；走向自由、觉醒

| 层 | 内容 |
|------|------|
| 象征 | 锁链松松垮垮地挂着，扣环却是一个个亲手扣上的——字据、人情、舍不得的一切，**制约**向来量身合身。 |
| 叙事触发 | 你的角色**主动签下一桩制约自己的约定**——立誓、效忠、应承一笔代价清楚的买卖。没人逼他，他自己走上前去扣上锁。 |
| 机械锚定 | **一道拴着他或同伴的旧辖制当场作废**——债务勾销、旧誓解除、把柄失效。由 DM 从当前局面中挑一件落实。 |

### XVI 高塔

**牌义**：无可避免地改变、虚假的结构、不合适的价值、丢掉旧东西；抱残守缺、被阻挠监禁的持续感

| 层 | 内容 |
|------|------|
| 象征 | 塔是被雷劈塌的，但裂缝早已爬满墙面——雷只是替所有人做了那个决定。轰然倒塌难看，可比住在危楼里体面。 |
| 叙事触发 | 你的角色**拆掉一座摇摇欲坠的假东西**——名不符实的权威、纸糊的计划、一层大家心照不宣维持的假象。哪怕眼下拆得很疼。 |
| 机械锚定 | 假象塌落的瞬间，它多年来**替谁遮着什么**随之露底——暗道、身影、埋着的物件，为何物由 DM 从局面中定。 |

### XVII 星星

**牌义**：创造力、可能性的信心、宁静、治疗、真正目的、重燃希望；失去创造力、失去目的

| 层 | 内容 |
|------|------|
| 象征 | 最黑的夜里最低的水池边，一颗星安静地亮着——它是岸边留下的一盏。**希望**指引方向，天亮前不会熄。 |
| 叙事触发 | 你的角色在最低谷为同伴**点灯**——说出愿景、拿出绝处逢生的新方案、或用自己的坚持给大家续上一口气。 |
| 机械锚定 | 你指定一名在场同伴，他的**一个快熄掉的念头重新烧起来**——那个他几乎放弃的目标由他亲口说出，从这一刻起他重新去做。 |

### XVIII 月亮

**牌义**：潜意识恐惧、面对噩梦恐惧、底层波涛汹涌；转向有形、找到平静

| 层 | 内容 |
|------|------|
| 象征 | 水面平静，底下的潮从不停歇——**恐惧**是一片人人绕行的水域。 |
| 叙事触发 | 你的角色**独自走向所有人都绕开的那个东西**——作祟的地界、讳莫如深的往事、梦里反复出现的场景。不为驱赶降服，只为见它一面。 |
