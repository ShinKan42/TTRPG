## **🥂 这是什么**

:::

::::: card

**为犯罪干杯**（Here's to Crime）是给 D&D 5e 的==劫案主题规则包==，来自创作者 Jimmy Meritt，设计思路承桌游《暗夜刀锋》的「行动」概念。

它把《十一罗汉》式的故事拆成==三个阶段==来跑——

- **计划**——全桌定行动风格，各自做一场筹备
- **行动**——正式动手，用`检定`、战斗与闪回闯过变数
- **得手**——全员接力完成收尾，全身而退

对 DM 它解决两件常事：策划环节容易拖沓无聊，执行环节容易沦为平铺直叙的地牢探险。

玩家在计划阶段的表现直接决定开局松紧，==闪回==机制则让「我早有准备」的高光时刻在桌上成立。

:::::

::::: center

::: card

原文《[Here's to Crime: A Guide to Capers and Heists](https://www.dmsguild.com/en/product/252431/here-s-to-crime-a-guide-to-capers-and-heists)》来自创作者 Jimmy Meritt（DMs Guild 出版）

本页为==中文机制重述==，供玩家与 DM 查阅

## **📜 计划阶段**

:::

::: tip **「目标」指谁**

在劫案语境里，「目标」指==预定的受害者或下手对象==。

行动风格与安保等级表里说的都是它。

:::

::::: card

动手之前，全桌先做两件事：定==行动风格==，再各自筹备。

这一阶段的对话本质是玩家在告诉你他们想玩什么样的劫案——请务必倾听。

::: center

### **行动风格 🎭**

:::

玩家从四种风格里定一种，风格同时决定行动阶段的`检定`属性：

:::: center

::: table

| 行动风格 | 达成手段 | `检定`属性 |
|---|---|---|
| 突袭 | 以暴力达成目标 | `力量` |
| 诈骗 | 用谎言与欺骗愚弄目标 | `感知` |
| 盗窃 | 以潜行完成劫案 | `敏捷` |
| 诱导目标 | 以社交操控达成目的 | `魅力` |

:::

::::

风格定下后，DM 只需问一个==概括性==的问题，别让桌面时间耗在细节上——

- **突袭**——目标是谁、想在哪里伏击？「我们在小巷里发动攻击」就够了
- **诈骗**——核心谎言是什么？「我要伪装成他们的保镖」
- **盗窃**——从哪里潜入、何时动手？别让玩家为东窗还是西窗争上四十分钟
- **诱导目标**——向目标开什么条件？「我们勒索他们，迫使他们打开保险箱」

::: center

### **筹备行动 🎬**

:::

每位玩家一次机会：==角色扮演或描述一个准备场景==，随后做一次`技能检定`，难度查目标的==安保等级==（见下文方案检定一节）。

规划口径保持宽泛：重点是==准备本身做了什么==，不必逐条定死实施方案——要给玩家留出给彼此制造惊喜的空间。

- **检定成功**——二选一：给行动阶段的==方案检定 +1 加值==，或获得一点 `英雄激励`
- **检定失败**——==没有任何负面后果==，规划的热情不该被打击
- **一人一次**——每位玩家只能尝试一次`检定`

计划阶段是玩家发挥创意的机会，==任何可能触发技能检定的行动都允许尝试==。

常见的筹备动作——

:::: center

::: table

| 技能 | 计划 |
|---|---|
| `运动` | 挖一条隧道 |
| `欺瞒` | 冒充他人身份 |
| `表演` | 受雇担任场地的娱乐表演者 |
| `巧手` | 前一天偷走守卫的钥匙 |
| `调查` | `调查`目标 |

:::

::::

:::::

::: tip **英雄激励是什么**

规则书标准资源 Inspiration，社区译文常作「灵感点」。

在本规则里它兼作==闪回的燃料==。

:::

## **🎭 行动阶段**

:::

::::: card

任务开场。

全桌先选出一名==门面==——团队的带头人，由他做一次==方案检定==，决定行动开局是顺是险。

随后 DM 连设三到五个变数，玩家用`技能检定`、战斗与闪回逐一化解。

::: center

### **方案检定 🎲**

:::

门面掷一枚 d20，合计三项——

- **属性调整值**——按行动风格取值（见行动风格表）
- **筹备加值**——计划阶段`检定`成功攒下的 +1
- **切入调整值**——按目标安保等级套用，==等级越高扣得越狠==

:::: center

::: table

| 安保等级 | 切入调整值 | 技能 DC | 目标示例 |
|---|---|---|---|
| 1 | -1 | 10 | 易受骗的贵族、商铺店面 |
| 2 | -2 | 15 | 防卫森严的银行、守卫严密的贵族宅邸 |
| 3 | -3 | 20 | 珊娜萨的老巢、克拉特之塔 |
| 4 | -4 | 25 | 奥喀斯之塔、地狱契约室 |

:::

::::

技能 DC 一列同时是==全行动各类技能检定==的基准难度——计划阶段的筹备`检定`、行动阶段的临场`检定`都查它。

::: center

### **开局四档 🎰**

:::

方案检定的结果分四档，直接决定开场怎么切——

:::: center

::: table

| `检定`结果 | 开局 |
|---|---|
| 1-5 | ==大失败==——出了重大变故，正式行动前必须先解决一个与方案无关的突发难题 |
| 6-14 | ==轻微变故==——照既定方案开场，第一次`技能检定`具 `劣势` |
| 15-20 | ==顺利==——如预期展开，第一次`技能检定`具 `优势` |
| 21+ | ==大成功==——第一个挑战被轻松化解，由玩家自行描述是怎么轻松过的 |

:::

::::

- **大失败长什么样**——队伍计划用「诱导目标」在晚宴上策反目标家族的一位成员；大失败意味着晚宴的入场门槛比预想高得多，现在他们要么从后门潜入（盗窃），要么伪造请柬（诈骗），要么杀出一条路（突袭）

::: center

### **执行行动 ⚔️**

:::

行动跑起来后，DM 的活是设 ==3 到 5 个变数==挡在团队与目标之间。

三条口味准则——

- **有来有往**——其中一个变数必须与计划阶段的某次`检定`==挂钩==：当时结下的因果，此刻让玩家能==完全绕过==这个变数（比如筹备时说服结交的内部盟友，正好帮团队化解困境），换来行事高明的成就感
- **主次分明**——大部分变数贴合选定的行动风格，再掺一两个别的来源：选「突袭」就大约三场战斗、一次潜行、一场欺骗遭遇；选「盗窃」就三次潜行、一场战斗、一次社交
- **节奏在手**——这不是死板的公式，行动的节奏由 DM 把握

变数口味示例——

:::: center

::: table

| 行动风格 | 变数示例 |
|---|---|
| 突袭 | 有平民在场 |
| 盗窃 | 另一伙人同时也在下手 |
| 诱导目标 | 敌对派系握着目标的把柄 |
| 诈骗 | 目标身边有位精明朋友盯着局势 |

:::

::::

执行期间的`技能检定` DC 同样查==安保等级表==。

::: center

### **使用闪回 ⏪**

:::

撞上棘手的`技能检定`时，玩家可以消耗一点 `英雄激励`==闪回到前一天==，描述角色当时如何为这一刻做了准备——机制效果是==把眼前要求的检定换成自己选的另一项==。

- **闪回实战**——布莱恩的角色遇上一台上了锁的保险箱，`敏捷` 不高、心里没底；他消耗一点 `英雄激励` 闪回，描述昨天请保险箱设计师吃过晚饭、套出了密码。现在改用 `游说` `检定`开箱，`敏捷` `检定`免了
- **事实不改写**——三名守卫已经闯进房间，就不能闪回「我昨晚把他们全放倒了」；能补写的是==事先安排的手段==，比如「我提前在那条走廊装了绊索」，于是改骰 `隐匿` 绕开战斗
- **初次从宽**——玩家头几回用这机制时判定不妨宽松，计划显得天马行空也无妨，==只要动作能触发技能检定就尽管答应==

- **法术过检**——由 DM 裁量，消耗 `法术位` 的`法术`可以==自动通过==一次`技能检定`——消耗了资源才换得到

::: center

### **收尾技能挑战 🏁**

:::

最后一段——团队逼近目标，请玩家构思怎么收尾，随后进入一场==团队技能挑战==。

依次问每位玩家——最后一步怎么完成？怎么帮团队不留痕迹地`撤离`？可以描述==当下的动作==，也可以描述==提前一天的准备==，自由度给到最大。

玩家自行描述行动内容，并说明要用哪项`技能检定`。

记分规则——

- **DC 起点**——查安保等级表；行动阶段每成功克服一个挑战，DC ==降低 1 点==（方案检定大成功免掉的那个挑战也计入减少，大失败额外多出来的挑战不计入）
- **攒成功**——每过一次`检定`记一笔，==先攒满 5 次成功==，行动圆满完成：描述目标终于意识到自己被耍了、但为时已晚
- **记失败**——每败一次记一笔，==累计 3 次失败==，行动宣告失败：设定相应的后果

## **🎲 上桌使用**

:::

::::: card

- **人数基准**——各表按 4-5 人队伍设计；队伍特别大就把切入减值调得更狠（筹备阶段本就会多出更多`检定`）
- **硬核档**——想要更艰难的氛围，把所有`技能检定`的 DC ==+5==
- **目标随手定**——给任何目标套上 1-4 档安保等级即可；单场劫案能用，战役里的穿插行动也能用
- **先听玩家**——风格对话是玩家在告诉你他们想玩什么样的游戏
- **计划要兑现**——执行时保持即兴与灵活，让计划阶段的成果==真的改变叙事走向==，再掺入意想不到的变数
