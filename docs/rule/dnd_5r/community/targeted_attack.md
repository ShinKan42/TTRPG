## **🎯 这是什么**

**瞄准攻击**（Targeted Attack）

来自 ==XP to Level 3== 视频的社区战斗扩展规则

让 ==指定部位== 精确打击成为合法战术——打瞎眼睛、打断腿、击飞武器，各有各的打法

:::::

::: card

原视频来自 YouTube 频道 [XP to Level 3](https://www.youtube.com/@XptoLevel3)：《[Your Combat Could Be Wayyyyy More Dynamic](https://youtu.be/CODp7mA9zmg)》

本页将规则译为中文，供玩家与 DM 查阅

:::

## **📜 基本规则**

::::

::: card

- 消耗你的 **动作** 和 ==附赠动作==，发起一次瞄准攻击
- 瞄准攻击 ==不享受== `额外攻击` 特性的好处
- 选择一个目标部位，把该部位的 **攻击调整值** 计入你的攻击掷骰总值
- 命中时，应用该部位的 **命中效果**
- 目标已处于 **重伤** 状态、或因这次攻击进入 **重伤** 状态时，额外应用 **重伤命中效果**
- 残废的肢体，在目标 ==恢复满生命值== 时治愈
- 暴击时，应用该部位的 **暴击效果**
- 替代规则：DM 可裁定，只有目标处于重伤状态时才应用暴击效果

:::

::: tip **编者注：重伤是什么**

原规则只写了 Bloodied 一词，未附定义

社区通行的口径是 ==最大生命值的一半或以下==，启用前与 DM 确认

:::

## **🎯 目标部位效果**

::::

七个部位，各自带一套调整值与三档效果：

::: table

| 目标 | 攻击调整值 | 伤害调整值 | 命中效果 | 重伤命中效果 | 暴击效果 |
|:---:|:---:|:---:|:---|:---|:---|
| 眼睛 | `-6` | `×(1d3+1)` | `目盲` 1 回合 | 眼睛残废 | 失去眼睛 |
| 头部 | `-4` | `×(1d2+1)` | 检定劣势 1 回合 | 头部残废 | 失去头部 |
| 手臂 | `-3` | `×(1d2)` | 攻击检定劣势 1 回合 | 手臂残废 | 失去手臂 |
| 物体 | `-3` | 目标受 `0` 伤害 | 无 | 物体击飞 | 物体摧毁 |
| 躯干 | `-1` | 无 | 无 | 躯干残废 | 内伤 |
| 腹股沟 | `-3` | `×(1d3)` | 无 | 剧痛 | 痛不欲生 |
| 腿部 | `-2` | `×(1d2)` | 不能 `疾走` 1 回合 | 腿部残废 | 失去腿部 |

:::

::: tip **怎么读这张表**

**攻击调整值**计入攻击掷骰——部位越致命，越难打中：眼睛 `-6` 最难，躯干 `-1` 最容易

**伤害调整值**与你的伤害相乘——`×(1d3+1)` 即掷 `1d3+1`，把结果乘上去

「物体」一排用于打敌人手里的武器、盾牌之类——==持用者本身不受伤害==

:::

## **🩹 残废与失去效果**

::::

**残废**是可恢复的（满血治愈），**失去**是永久的

### **残废效果**

::: table

| 效果 | 规则 |
|:---|:---|
| 眼睛残废 | 依赖视力的 `感知`（`察觉`）检定与远程攻击具有 `劣势`<br>所有眼睛残废，则 `目盲` |
| 头部残废 | 每回合开始时进行 <Badge type="warning" text="DC 16" /> `体质` 豁免<br>失败则本回合只能三选一：一个动作、一个附赠动作、或一次移动 |
| 手臂残废 | 每次使用手臂时，受到 `2d4` 伤害 |
| 物体击飞 | 物体被击飞 `1d6 × 5` 尺远 |
| 躯干残废 | 每次进行动作时，受到 `1d4-1` 伤害 |
| 剧痛 | 本回合只能三选一：一个动作、一个附赠动作、或一次移动 |
| 腿部残废 | 每移动 `10` 尺，受到 `1d4` 伤害 |

:::

### **失去效果**

::: table

| 效果 | 规则 |
|:---|:---|
| 失去眼睛 | 依赖视力的 `感知`（`察觉`）检定与远程攻击具有 `劣势`<br>所有眼睛失去，则 ==永久失明== |
| 失去头部 | 没有头部无法存活 |
| 失去手臂 | 无法双手同时持物<br>一次只能拿一个物体 |
| 物体摧毁 | 物体若可被摧毁，则被摧毁 |
| 内伤 | 每次进行动作时受到 `1d4-1` 伤害<br>每回合结束受到 `1d10` 伤害，直到完全治愈 |
| 痛不欲生 | `麻痹` `1d4` 轮<br>每回合结束受到 `1d10` 伤害，直到完全治愈 |
| 失去腿部 | 步行速度减半<br>为保持平衡的 `敏捷` 检定与豁免具有 `劣势`<br>必须用拐杖移动，`疾走` 则 `倒地` |

:::

## **🎲 上桌使用**

::::

::: card

- 这是 ==社区扩展规则==，不是官方规则——开团前与 DM 确认是否启用、启用哪几档（比如只开命中效果、不开暴击效果）
- 三档效果按代价分层：命中给短期状态，重伤给 ==残废==，暴击直接 ==失去部位==——按 DM 裁定的替代规则，暴击效果还可以再锁到重伤状态之后
- 打不打得中自己掂量：眼睛 `-6` 的代价换一回合 `目盲`，躯干 `-1` 稳但只有重伤后才有效果

:::
