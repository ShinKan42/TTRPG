## **🎯 这是什么**

**瞄准攻击**（Targeted Attack）

来自 [XP to Level 3](https://www.youtube.com/@XptoLevel3) 视频的社区战斗扩展规则

让 ==指定部位== 精确打击成为合法战术——打瞎眼睛、打断腿、击飞武器，各有各的打法

## **📜 基本规则**

:::::

::: card

- **适用范围**——==一切攻击检定==：武器攻击、徒手打击与法术攻击（`魔能爆`这类掷攻击骰的）都可发起瞄准；豁免型法术（`火球术`这类）没有攻击检定，不适用
- **动作代价**——消耗`动作`与`附赠动作`，发起一次瞄准攻击
- **无额外攻击**——不享受`额外攻击`特性的好处
- **部位调整**——选定目标部位，==该部位的攻击调整值计入攻击掷骰总值==
- **命中生效**——==命中时，应用该部位的命中效果==
- **浴血追加**——目标已`浴血`、或因这次攻击进入`浴血`时，额外应用`浴血`命中效果
- **残废治愈**——残废肢体在`生命值`恢复满值时治愈
- **暴击生效**——`暴击`时，应用该部位的`暴击`效果
- **替代规则**——DM 可裁定：仅当目标处于`浴血`状态时，才应用`暴击`效果

:::

::: tip **浴血（Bloodied）**

`生命值`降至 ==最大生命值的一半或以下== 时的状态

2024 版官方机制，站内 [战斗指南](/rule/dnd_5r/guide/combat) 已收录定义

:::

::: tip **多束法术·接瞄（站内补裁）**

- **法术接瞄**——一次施法需要掷多次攻击骰时（`魔能爆`的多束、`灼热射线`逐环加束这类），可指定其中任意几束为`接瞄束`，每束各选目标部位，相同不同皆可，未指定的束照常攻击
- **累计调整**——第 1 束`接瞄束`吃所选部位的攻击调整值，之后每多一束，其攻击调整值在该部位调整值的基础上==累计再 -2==（瞄眼三束就是 -6、-8、-10）
- **逐束结算**——`接瞄束`命中时各自应用所选部位的命中效果、`浴血`命中效果与`暴击`效果，伤害也按该部位的伤害调整值逐束计算，==各束互不相干==
- **暴击阀建议**——多骰瞄准会让`暴击`效果出现得更勤，建议同时启用基本规则里的`替代规则`，把`暴击`效果锁在目标`浴血`之后

:::

## **🎯 目标部位效果**

:::::

七个部位，各带一套调整值与三档效果：

::: table

| 目标 | 攻击调整值 | 伤害调整值 | 命中效果 | `浴血`命中效果 | `暴击`效果 |
|:---:|:---:|:---:|:---|:---|:---|
| 眼睛 | -6 | ×(1d3+1) | `目盲` 1 `回合` | 眼睛残废 | 失去眼睛 |
| 头部 | -4 | ×(1d2+1) | `检定` `劣势` 1 `回合` | 头部残废 | 失去头部 |
| 手臂 | -3 | ×(1d2) | `攻击检定` `劣势` 1 `回合` | 手臂残废 | 失去手臂 |
| 物体 | -3 | 目标受 0 伤害 | 无 | 物体击飞 | 物体摧毁 |
| 躯干 | -1 | 无 | 无 | 躯干残废 | 内伤 |
| 腹股沟 | -3 | ×(1d3) | 无 | 剧痛 | 痛不欲生 |
| 腿部 | -2 | ×(1d2) | 不能`疾走` 1 `回合` | 腿部残废 | 失去腿部 |

:::

::: tip **怎么读这张表**

- **攻击调整值**——要害越小越难命中：眼睛 -6 最难，躯干 -1 最容易
- **伤害调整值**——与你的伤害相乘：×(1d3+1) 即掷 1d3+1，把结果乘上去
- **物体行**——用于打敌人手里的武器、盾牌之类，==持用者本身不受伤害==

:::

## **🩹 残废与失去效果**

:::::

**残废**是==可恢复的==（满血治愈），**失去**是==永久的==

::::: center

### **残废效果 🩼**

:::::

:::: card

::: table

| 效果 | 规则 |
|:---|:---|
| 眼睛残废 | 依赖视力的`感知`（`察觉`）`检定`与远程攻击具有`劣势`<br>所有眼睛残废，则`目盲` |
| 头部残废 | 每`回合`开始时进行 <Badge type="warning" text="DC 16" /> `体质` `豁免`<br>失败则本`回合`三选一：一个`动作`、一个`附赠动作`、或一次移动 |
| 手臂残废 | 每次使用手臂时，受到 2d4 伤害 |
| 物体击飞 | 物体被击飞 1d6 × 5 尺远 |
| 躯干残废 | 每次进行`动作`时，受到 1d4-1 伤害 |
| 剧痛 | 本`回合`三选一：一个`动作`、一个`附赠动作`、或一次移动 |
| 腿部残废 | 每移动 10 尺，受到 1d4 伤害 |

:::

### **失去效果 ⚰️**

:::::

:::: card

::: table

| 效果 | 规则 |
|:---|:---|
| 失去眼睛 | 依赖视力的`感知`（`察觉`）`检定`与远程攻击具有`劣势`<br>所有眼睛失去，则 ==永久失明== |
| 失去头部 | 没了头便活不成的，就此死亡 |
| 失去手臂 | 无法双手同时持物<br>一次只能拿一个物体 |
| 物体摧毁 | 物体若可被摧毁，则被摧毁 |

| 失去腿部 | 步行`速度`减半<br>为保持平衡的`敏捷` `检定`与`豁免`具有`劣势`<br>必须用拐杖移动，`疾走` 则`倒地` |

## **🎲 上桌使用**

:::::

::: card

- **先对口径**——这是 ==社区扩展规则==，不是官方规则。开团前与 DM 确认是否启用、启用哪几档，法术能否瞄准、按哪条口径适用也一并要对
- **三档分层**——命中给短期状态，`浴血`给 ==残废==，`暴击`直接 ==失去部位==——按替代规则，`暴击`效果可再锁到`浴血`状态之后
- **代价自估**——眼睛 -6 换一`回合`的`目盲`；躯干 -1 稳，但只有`浴血`后才有效果

:::
