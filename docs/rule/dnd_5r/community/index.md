#### **[玩家选项总览 🎲](/rule/dnd_5r/player_option/)**

:::

==社区与第三方玩家选项的汇总入口==，覆盖职业、种族、专长、法术、物品、ACG 角色六大区块。

玩家选项是角色构建的全部原材料：职业决定角色怎么战斗与施法，种族给出血统特质与身份视角，专长提供定制化能力，法术扩充施法者的工具箱，物品带来桌上流转的装备与奇物，ACG 角色则把熟悉的二次元人物翻译成可上车桌的玩家角色。

官方内容已由 kiwee 与不全书两站覆盖，该汇总页只收==两者未收录的==社区与第三方设计——kiwee 与不全书已有的条目不重复纳入。收录状态与逐区块介绍见总览页本身。

:::

::::: card

::: center

#### **[瞄准攻击 🎯](/rule/dnd_5r/community/targeted_attack)**

:::

==指定部位精确打击==的社区战斗扩展规则，译自 XP to Level 3 频道的视频规则，本站整理为中文并默认启用其替代规则口径。

基础玩法是给攻击检定加上部位代价：选定目标部位，该部位的调整值计入攻击掷骰——打眼睛最难（-6）但命中可致目盲，打躯干最容易（-1）但只在目标浴血后见效。命中给短期状态，目标==浴血==时追加残废效果（残废可随满血治愈），暴击则造成失去部位的永久后果。

它改变桌上的部分在==战斗叙事与策略==两端：敌人不再是血条，而是有眼睛有腿有手中武器的具体身体——打瞎施法者、打断逃跑者的腿、击飞持盾者的武器都成了合法战术；同时七档部位调整值给了玩家一道自估代价的决策题，高风险高回报全在一念之间。页面含七部位效果总表、残废与失去两档效果表，以及上桌前与 DM 对口径的注意事项。
