#### **[瞄准攻击 🎯](/rule/dnd_5r/community/targeted_attack)**

:::

==指定部位精确打击==的社区战斗扩展规则，译自 XP to Level 3 频道的视频规则，本站整理为中文并默认启用其==替代规则==口径。

基础玩法是给攻击检定加上部位代价：

::: table

| 目标部位 | 攻击调整值 | 命中可换什么 |
|:---:|:---:|:---|
| 眼睛 | -6 | 目盲——最难打 |
| 躯干 | -1 | 无，浴血后才见效——最容易打 |
| 物体 | -3 | 击飞敌人手中的武器、盾牌 |
| 其余四档 | -2 ~ -4 | 头部、手臂、腿部、腹股沟各有一套效果 |

:::

七档部位共用的三档分层：

- 命中：给短期状态
- 浴血时：追加残废效果，残废可随满血治愈
- 暴击：造成失去部位的永久后果（替代规则口径下，暴击效果只在目标==浴血==后应用）

它改变桌上战斗的==叙事与策略==两端：

- 叙事上：敌人不再是血条，而是有眼睛有腿有手中武器的具体身体——打瞎施法者、打断逃跑者的腿、击飞持盾者的武器都成了合法战术
- 策略上：七档部位调整值是一道自估代价的决策题，高风险高回报全在一念之间

页面含七部位效果总表、残废与失去两档效果表，以及上桌前与 DM 对口径的注意事项。

#### **[战场动作 ⚔️](/rule/dnd_5r/community/battlefield_actions)**

:::

首领战专属的两阶段威胁机制，来自 Pointy Hat 频道，本站整理为==中文机制重述==。

核心循环是==预兆→化解→结算==：首领回合末亮出预告，全桌用一轮先攻的时间决定谁去拆招，下回合开始时结算成败。

伤害按首领 CR 查表现成表，DC 走常规公式，==零适配成本==挂到任意怪物上。

内置十个即用动作，按化解方式分两族——破坏专注族（打断施法、踩住法阵、躲进盲区）与走位移动族（散开躲顺劈、贴近飓风眼）。

它把「你打我一下我打你一下」的消耗战，变成每轮一次的全桌解谜。

页面含两阶段循环、CR 伤害表与 DC 公式、十动作完整条目，以及两处原文留白的现场自裁建议。

[查看详情 →](/rule/dnd_5r/community/battlefield_actions)
