#### **[三龙牌 🐉](/rule/dnd_5r/official/three_dragon_ante)**

:::

==D&D 世界里最受欢迎的酒馆卡牌赌博游戏==，官方出版物，可直接开桌。

三龙牌是嵌在 DND 世界观里的卡牌游戏，牌库由三类牌混成：

::: table

| 牌类 | 数量 | 说明 |
|:---|:---:|:---|
| 标准巨龙牌 | 70 张 | 分善恶两大阵营、十种龙色 |
| 凡人牌 | 15 张 | 与巨龙牌混编入同一牌库 |
| 传奇巨龙牌 | 15 张 | 各带独特能力，见下方能力层 |

:::

每轮斗牌人人下注、轮流打牌，三轮之后牌阵总点数最高的玩家拿走全部赌注，直到有人输光金币、金币最多者获胜。

它的玩法乐趣来自三层：

- ==赌博层==：前注牌同时翻开、点数定注，赌注越滚越大，弃牌还是跟进全看你对牌阵的判断
- ==能力层==：传奇巨龙各有本事，巴哈姆特在场时善恶同阵者无法赢牌，提亚马特能组五色牌阵，恶龙偷币、善龙抓牌，每一张都在改写局势
- ==桌游层==：规则轻、节奏快，几十分钟一局，特别适合酒馆场景——休息时间来一局，或者整场团以赌桌为舞台

与本站 DND 团结合有三种官方方式：

- 纯角色扮演：直接在 RP 里打一场
- 技能检定：快速判定赌局输赢
- 能力盘结合：PC 带着自己的角色能力上桌，特殊牌阵还能给能力盘充能

页面含完整规则整理、卡牌速查表与主题牌库变体。
