## **🎲 动作掷骰**

:::

:::: card

选择一个属性，添加额外骰子和调整值，掷骰对抗难度。

::: table

| 结果 | 效果 |
|---|---|
| **关键成功** | 获得 ==1 希望点==并清除 ==1 压力点==，伤害额外增加一个满骰 |
| 希望成功 | 获得 ==1 希望点== |
| 恐惧成功 | 游戏主持人获得 ==1 恐惧点== |
| 希望失败 | 会有其他后果发生，但你可以获得 ==1 希望点== |
| 恐惧失败 | 引发严重的后果或复杂情况。游戏主持人获得 ==1 恐惧点==。 |

:::

::::

详见[通用规则](/rule/dagger_heart/guide/general_rule)。

## **🔄 反应掷骰**

::: card

此外，其他角色不能在反应掷骰中帮助你。

## **❤️ 受到伤害**

:::

::: card

**伤害门槛**：将总伤害点数与你的伤害门槛进行比较，根据门槛标记相应数量的生命点：==3/2/1==

**使用护甲**：划掉一个可用的==护甲槽==来抵消部分（或全部）伤害，将该次伤害等级降低一级

:::

详见[通用规则 · 生命与伤害](/rule/dagger_heart/guide/general_rule#hp-damage)。

<a id="death-moves"></a>

::: center

## **💀 死亡行动**

:::

::: card

获得伤痕时，需要划掉一个==希望槽==使其永久失效。

**荣光就义**：进行一次行动（由游戏主持人裁定），自动关键成功，之后死亡。

**回避死亡**：陷入昏迷，直到被治疗或长休。

掷出希望骰，如果等于或小于角色等级，则获得一道==伤痕==。

**孤注一掷**：掷出你的二元骰。

如果希望结果，恢复/清除等同于希望骰数值的==生命点==或==压力点==（随意分配）。

如果恐惧结果，角色死亡。

如果关键成功，恢复/清除所有==生命点==和==压力点==。

:::

详见[通用规则 · 濒死](/rule/dagger_heart/guide/general_rule#dying)。

## **⚠️ 状态**

:::

:::: card

进行一次动作掷骰尝试解除临时状态，难度由游戏主持人设定。

::: table

| 状态 | 效果 |
|---|---|
| **隐藏** | 所有以你为目标的掷骰都具有劣势。一旦你可以被看见或者你进行攻击，将脱离隐藏状态。 |
| **脆弱** | 所有以你为目标的掷骰都具有优势 |
| **束缚** | 你无法移动，但仍然可以在当前位置执行动作 |
| **眩晕** | （催眠闪光）无法移动、进行动作或反应 |
| **惊惧** | （夜魇降临）目标获得==脆弱==状态。从游戏主持人处窃取等同于==惊惧==目标数量的恐惧点。 |
| **迷醉** | （心醉神迷）目标的注意力会固定在施法者身上 |
| **点燃** | （余烬之握）行动结束时额外受到 <Badge type="danger" text="2d6" /> 魔法伤害。 |
| **中毒** | 每次行动都会受到 <Badge type="danger" text="1d10" /> 点直接物理伤害。（无法使用护甲） |

:::

::::

详见[战斗规则](/rule/dagger_heart/guide/combat)。

## **⛺ 短休**

:::

::: card

约 ==1 小时==。

两次长休之间最多进行三次短休。

游戏主持人获得 <Badge type="danger" text="1d4" /> ==恐惧点==。

交换领域卡，然后选择下列两项行动（或选择同一项行动两次）。

**处理伤口**：你或盟友恢复等同于 <Badge type="danger" text="1d4" /> + 你的位阶的生命点。

**缓解压力**：清除等同于 <Badge type="danger" text="1d4" /> + 你的位阶压力点。

**修理护甲**：清除你或盟友等同于 <Badge type="danger" text="1d4" /> + 你的位阶的==护甲槽==标记。

**做好准备**：获得 ==1 希望点==。

如果你选择与其他队友一起准备，则每人获得 ==2 希望点==。

:::

详见[常用骰法 · 休整](/rule/dagger_heart/guide/quick_roll#rest)。

<a id="long-rest"></a>

::: center

## **🌙 长休**

:::

::: card

约 ==8 小时==。

游戏主持人获得 ==玩家数量== + <Badge type="danger" text="1d4" /> ==恐惧点==。

交换领域卡，然后选择下列两项行动（或选择同一项行动两次）。

**处理所有伤口**：你或盟友恢复所有==生命点==。

**缓解所有压力**：清除所有==压力点==。

**修理所有护甲**：你或盟友清除所有==护甲槽==标记。

**做好充分准备**：获得 ==1 希望点==。

如果你选择与其他队友一起准备，则每人获得 ==2 希望点==。

**推进长休项目**：建立或继续进行一个项目。

:::

详见[常用骰法 · 休整](/rule/dagger_heart/guide/quick_roll#rest)。

## **🔍 快速查阅**

:::

::: card

**优势与劣势**：掷骰结果加上/减去 ==d6==

**帮助盟友**：花费 ==1 希望点==，在别人的掷骰结果上加上 ==d6==

**团队动作掷骰**：指定一名领导，领导者像往常一样进行动作掷骰，而其他玩家则进行反应掷骰，每次成功的反应掷骰获得 ==+1== 加值，因每次失败的反应掷骰受到 ==-1== 减值。

**接力掷骰**：每场游戏一次，每个玩家可以花费 ==3 希望点==发起其角色与另一个角色之间的接力掷骰。

分别掷出伤害骰，然后将结果相加作为总伤害值。

若为希望结果，所有参与的角色获得 ==1 希望点==。

若为恐惧结果，每有一名参与的角色，游戏主持人获得 ==1 恐惧点==。

:::

详见[通用规则](/rule/dagger_heart/guide/general_rule)。
