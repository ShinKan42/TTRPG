<a id="常见问题"></a>

## **❓ 常见问题**

::: tip 新人必看

**种族和社群有什么区别？** 种族定==血统==，社群定==成长==
种族给 2 项特质，社群给 1 项特质——同一个种族，贵族出身和流浪长大是两个角色

**混血怎么取特质？** ==一族取第一条，另一族取第二条==
上下两个槽位各保一个——不能两条都来自上槽
血统可以写两族以上，特质仍然只从两族取

**纯血两条都要吗？** 纯血=两特质==全拿==，混血才做取舍
混血是组合你想要的，不是损失一半

**新手怎么快速定？** 先想清楚想演什么形象，再看[挑选问卷](#挑选问卷)的功能轴
不用记住 18 族，先找到你想要的那两三条特质

:::

## **💭 核心简介**

::: card

18 个种族全表如下，每张卡按源卡顺序==第一条（上槽）==、==第二条（下槽）==排列

:::

::: card

**人类**——灵巧的双手、圆圆的耳朵、超强耐力

==精力充沛==：建卡时多一个`压力槽`

==随机应变==：用`经历`的掷骰失败后，标 1 `压力点`重掷

:::

::: card

**矮人**——矮壮方正、肌肉结实、毛发浓密

==厚实皮肤==：受`轻度伤害`时，可标 2 `压力点`代替 1 `生命点`

==增强坚韧==：花 3 `希望点`，物理伤害减半

:::

::: card

**精灵**——高挑、尖耳、感官敏锐

==快速反应==：标 1 `压力点`，`反应掷骰`获`优势`

==天界冥想==：`休息`时进入冥想，多选一个`休整行动`

:::

::: card

**半身人**——体型矮小、毛茸茸的大脚

==幸运使者==：每场开始，全队各得 1 `希望点`

==内在罗盘==：`希望骰`掷出 1 时，重掷该骰

:::

::: card

**龙人**——无翼的龙类形态、元素吐息

==鳞片保护==：受`严重伤害`时，标 1 `压力点`少标 1 `生命点`

==元素吐息==：选一种元素，对`邻近`目标视为`本能`武器，按`熟练值`掷 <Badge type="danger" text="d8" /> 魔法伤害

:::

::: card

**仙灵**——昆虫特征、带翼的人形

==运气操控者==：每场一次，你或`近`距离自愿盟友`动作掷骰`后，花 3 `希望点`重掷`二元骰`

==翅膀==：可飞行；被攻击后标 1 `压力点`，该次`闪避` +2

:::

::: card

**械灵**——金属、木头、石头、陶土造的机械生命

==定制设计==：建卡时选一条贴合你创造目的的`经历`，永久 +1 加值

==高效休整==：`短休`时可改选`长休`的`休整行动`

:::

::: card

**猫族**——猫科人形、伸缩爪、竖瞳

==猫科本能==：`敏捷`掷骰时，花 2 `希望点`重掷`希望骰`

==伸缩猫爪==：`敏捷`掷骰抓挠`近战`目标，成功使其`脆弱`

:::

::: card

**羊蹄人**——类人山羊、弯角、分蹄

==跳跃==：像正常移动一样，跳到`近`距离内任意位置

==踢击==：`近战`攻击成功后标 1 `压力点`，额外 <Badge type="danger" text="2d6" /> 伤害并将自己或目标击退至`邻近`

:::

::: card

**费尔博格**——半牛半人、宽鼻、长垂耳

==冲撞==：`敏捷`掷骰从`远`冲入`近战`，标 1 `压力点`对近战内全体造成 <Badge type="danger" text="1d12" /> 物理伤害

==百折不挠==：本应标 1 `压力点`时掷 <Badge type="danger" text="d6" />，掷出 6 免标

:::

::: card

**龟人**——拟人乌龟、巨大甲壳

==龟甲==：`伤害阈值`获得等同`熟练值`的加值

==缩壳==：标 1 `压力点`缩入龟壳——物理伤害`抗性`，但`动作掷骰`有`劣势`且不能移动

:::

::: card

**蛙裔**——拟人青蛙、突眼、蹼状手足

==两栖==：天生能在水下呼吸和移动

==长舌==：`近`距离取物；标 1 `压力点`，把长舌当作`灵巧`近战武器，按`熟练值`掷 <Badge type="danger" text="d12" /> 伤害

:::

::: card

**猿族**——长肢、能抓握的脚

==天生攀爬者==：平衡与攀爬的`敏捷`掷骰有`优势`

==灵活==：建卡时`闪避`永久 +1

:::

::: card

**巨人**——高大、宽肩长臂、一到三只眼

==坚韧==：建卡时多一个`生命槽`

==长臂==：任何`近战`范围的武器与特性，视为`邻近`范围

:::

::: card

**哥布林**——矮小、大眼、薄膜状大耳

==稳健脚步==：`敏捷`掷骰忽略`劣势`

==危险感应==：每次`休息`一次，标 1 `压力点`强制敌人重掷对你或`邻近`盟友的攻击

:::

::: card

**兽人**——方正脸、野猪般的獠牙

==强壮==：剩 1 `生命点`时，对你的`攻击掷骰`有`劣势`

==獠牙==：`近战`攻击成功后花 1 `希望点`，额外 <Badge type="danger" text="1d6" /> 伤害

:::

::: card

**魔裔**——尖犬齿、尖耳、犄角

==无畏==：掷出`恐惧`结果时，标 2 `压力点`改为`希望`结果

==恐怖面容==：恐吓敌对生物的掷骰有`优势`

:::

::: card

**孢菌人**——人形蘑菇

==孢菌网络==：`本能`掷骰（12），用菌丝与任意距离的同族交换信息

==死亡连接==：触摸新死的尸体，标 1 `压力点`，提取一段与指定情绪相关的记忆

:::

## **🎯 挑选问卷**

::: card

**你想当队伍里最难倒下的那个？** 看矮人==厚实皮肤==、巨人==坚韧==、龟人==龟甲==、兽人==强壮==——四族各有一条挨打减损的特质

**你想天生带着武器？** 看龙人==元素吐息==、兽人==獠牙==、羊蹄人==踢击==、蛙裔==长舌==、猫族==伸缩猫爪==、费尔博格==冲撞==——近战都多一口伤害

**你想飞、想跳、想爬？** 看仙灵==翅膀==、羊蹄人==跳跃==、猿族==天生攀爬者==——移动维度直接打开

**你想让全队都沾光？** 看半身人==幸运使者==——每场开场全队各得 1 `希望点`

**你想掷骰更稳？** 看精灵==快速反应==、哥布林==稳健脚步==、半身人==内在罗盘==、费尔博格==百折不挠==——优势、免劣势、重掷各有其族

**两族的特质都想要？** ==混血==——一族取第一条、另一族取第二条（见[常见问题](#常见问题)）

:::
