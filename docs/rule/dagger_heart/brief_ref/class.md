## **❓ 常见问题**

:::

:::: card

**职业回答什么？**

`职业`回答==你擅长什么==。

战斗方式、起始数据、专属物品，都从职业来。

::::

:::: card

**职业和领域有什么关系？**

每个职业固定对应==两个领域==。

开局从中选一个，领一张初始`领域`卡。

::::

:::: card

**子职业怎么挑？**

每个职业==两条分支==，开局二选一。

分支调的是玩法手感，职业底盘不变。

::::

:::: card

**希望特性是什么？**

每个职业一条，==高光时刻==。

花 3 `希望点`点亮，是这个职业最帅的一刻。

## **💭 核心简介**

:::

::: tip 怎么挑

9 个职业按出手方式分三组：==冲在前面==、==走位巧活==、==满手法术==。

先挑一组的打法对味，再进职业卡里挑子职业。

只想查数据，去[职业速查](#📋-职业速查)。

:::

::: center

### **⚔️ 冲在前面**

:::

::::: card

:::: center

#### **战士**

::::

==绝不手软 No Mercy==： 花费 3 `希望点`，直到你下次休息前，你的`攻击掷骰`获得 +1 加值。

**职业物品**：爱人的画像或一块磨刀石

利用敌人的力量激励自己

:::

::::: card

:::: center

#### **游荡者**

::::

==闪身伎俩 Rogue’s Dodge==： 花费 3 `希望点`，直到下次攻击成功命中你之前，你的`闪避值`获得 +2 加值。

否则，此加值持续到你下次休息。

**职业物品**：一套伪造工具或一套钩绳

:::: card-grid

::: card

**黑夜行者**

操纵阴影使你穿行于环境

:::

::: card

**帮派豪杰**

你所到之处皆有人脉网络

:::

#### **游侠**

::::

==压制众敌 Hold Them Off==： 当你用武器攻击成功时，花费 3 `希望点`，可以使用相同的掷骰结果攻击此次攻击范围内额外的两个敌人。

**职业物品**：你第一次狩猎的战利品或一个看似损坏的指南针

::: card

#### **德鲁伊**

::::

==兽形进化 Evolution==： 花费 3 `希望点` 变形成野兽形态，而无需标记1`压力点`。

当你这样做时，选择一个`属性`获得+1加值，直到你解除野兽形态。

**职业物品**：一小袋石头和骨头，或是一个在泥土里找到的奇特坠饰

:::: card-grid

::: card

**元素结社**

体现自然元素的不同面貌

:::

::: card

**复兴结社**

使用强大的魔法治疗盟友

::::

**职业物品**：一枚低语宝珠或一件传家宝

**职业物品**：一本你正在尝试翻译的书，或一只无害的小型元素宠物
