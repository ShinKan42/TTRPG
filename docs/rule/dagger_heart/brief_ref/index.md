## **❓ 常见问题**

:::

:::: card

**车卡第一步从哪开始？**

从[种族](#种族)开始。

种族回答你是谁，社群回答你从哪来

先把这两个出身定下来，再定职业，然后到[领域](#领域)和[装备](#装备)收尾。

::::

:::: card

**种族和社群有什么区别？**

种族定==血统==，社群定==成长==。

同一个种族，贵族出身的精灵和流浪长大的精灵是两个完全不同的角色。

## **💭 核心简介**

:::

<a id="种族"></a>

### **🧝 种族**

::: card

==18 个种族==，每族 2 项特质
一条定身份来历，一条给看家本领

混血==一族取第一条、另一族取第二条==

**详细资料**：[种族页](/rule/dagger_heart/brief_ref/ancestry)

:::

<a id="社群"></a>

### **🏘️ 社群**

::: card

==9 个社群==，各自携带 1 项特质

社群回答你==从哪里来==。
在什么样的圈子里长大，就带什么样的烙印。

**详细资料**：[社群页](/rule/dagger_heart/brief_ref/community)

:::

<a id="职业"></a>

### **🗡️ 职业**

::: card

==9 个职业==，各带一条希望特性：花 3 希望点点亮的高光时刻。

==18 个子职==，每个职业二选一，能力分支从这里分岔

起始生命、闪避和专属物品都按职业给

**更多资料**：[灰机 wiki · 职业](https://daggerheart.huijiwiki.com/wiki/分类:职业)

:::

<a id="领域"></a>

### **📜 领域**

::: card

==9 个领域==，能力以卡牌搭载，从 1 级铺到 10 级

每个职业==配 2 个领域==，升级挑卡始终在这两域里挑

**更多资料**：[灰机 wiki · 领域卡](https://daggerheart.huijiwiki.com/wiki/领域卡)

:::

<a id="装备"></a>

### **🎒 装备**

::: card

武器==带特征标签==，标签写这把武器怎么用。

护甲加闪避修正，==挡不挡是主动选择==

装备按 ==Tier 1-4== 四档进阶

**更多资料**：[灰机 wiki · 装备](https://daggerheart.huijiwiki.com/wiki/装备)

:::
