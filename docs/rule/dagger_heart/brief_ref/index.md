<a id="常见问题"></a>

## **❓ 常见问题**

::: tip 新人必看

**车卡第一步从哪开始？** 从[种族](#种族)开始
种族回答你是谁，社群回答你从哪来，职业回答你擅长什么
按这个顺序走完出身三件套，再到[领域](#领域)和[装备](#装备)收尾

**种族和社群有什么区别？** 种族定==血统==，社群定==成长==
同一个种族，贵族出身的精灵和流浪长大的精灵是两个完全不同的角色

**这个区和新手指南什么关系？** 指南教==怎么玩==，资料区帮==选什么==
车卡时两边对照着用

**为什么有链接指向别的网站？** 站内资料逐块建设中
先直连灰机 wiki，==建成一域换一域==

## **💭 核心简介**

<a id="种族"></a>

### **🧝 种族**

::: card

==18 个种族==，每族 2 项特质
一条定身份来历，一条给看家本领

混血==一族取第一条、另一族取第二条==

**详细资料**：[种族页](/rule/dagger_heart/brief_ref/ancestry)

:::

<a id="社群"></a>

### **🏘️ 社群**

::: card

==9 个社群==，出身的文化那一半
每社群 1 项特质，定你的文化技能优势

种族之外的==第二出身维度==

**更多资料**：[灰机 wiki · 社群](https://daggerheart.huijiwiki.com/wiki/%E5%88%86%E7%B1%BB:%E7%A4%BE%E7%BE%A4)

:::

<a id="职业"></a>

### **🗡️ 职业**

::: card

==9 个职业==，各带一条希望特性——花 3 希望点点亮的高光时刻

==18 个子职==，每个职业二选一，能力分支从这里分岔

起始生命、闪避和专属物品都按职业给

**更多资料**：[灰机 wiki · 职业](https://daggerheart.huijiwiki.com/wiki/%E5%88%86%E7%B1%BB:%E8%81%8C%E4%B8%9A)

:::

<a id="领域"></a>

### **📜 领域**

::: card

==9 个领域==，能力以卡牌搭载，从 1 级铺到 10 级

每个职业==配 2 个领域==，升级挑卡始终在这两域里挑

**更多资料**：[灰机 wiki · 领域卡](https://daggerheart.huijiwiki.com/wiki/%E9%A2%86%E5%9F%9F%E5%8D%A1)

:::

<a id="装备"></a>

### **🎒 装备**

::: card

武器==带特征标签==——标签写这把武器怎么用

护甲加闪避修正，==挡不挡是主动选择==

装备按 ==Tier 1-4== 四档进阶

**更多资料**：[灰机 wiki · 装备](https://daggerheart.huijiwiki.com/wiki/%E8%A3%85%E5%A4%87)

:::
