## **💭 领域介绍**

:::: card

利刃是武器精通的领域。

无论是通过钢剑、弓箭，还是更专业的武器，追随此道的人都拥有斩断他人生命的能力。

利刃的使用者致力于获得主宰死亡的残暴力量。

**可选职业**：战士／守护者

**标准卡池**：21 张（1 级 3 张＋2-10 级各 2 张）

::::

## **🧭 典型构筑与场景**

::: tip **这域怎么玩**

输出、狂怒、生存三线都顺，按队伍缺位挑。

:::

:::: card

**稳定主输出**


==旋风猛袭==顺劈清场，怒意重击单点爆发，==勇士锐锋==把关键成功兑现成大伤害。


战士守护者的本职路线，输出节奏最稳。


::::

:::: card

**狂怒终结**


==狂怒出击==开状态扫场，==死亡收割==按希望点数发动，==猛攻强袭==保底重伤害阈值。


高资源高回报的终结流派，适合队伍有治疗兜底时。


::::

:::: card

**前排生存**


==卷土重来==降伤，==强化护甲==抬阈值，==蓬勃生命==一次性永久加槽。


既要站得住又要输出的坦战双修。


::::

## **🎯 选择推荐**

::: tip **怎么挑**

按构筑对号入座，低费泛用卡==先拿不亏==。

:::

### **旋风猛袭**

:::


**等级**：==1 级==（回想费用 ==0==）


**类型**：能力


成功攻击一个目标后，花费 ==1 希望点==顺劈邻近范围内所有其他目标。

==0 费==开局的群伤引擎。


**适合**：近战主 C 的第一张卡。


::::

:::: card

::: center

### **强化护甲**

:::


**等级**：==4 级==（回想费用 ==0==）


**类型**：能力


穿甲时所有==伤害阈值==获得 +2 加值，0 费白赚的坦度。


**适合**：守护者与甲流战士必拿。


::::

:::: card

::: center

### **蓬勃生命**

:::


**等级**：==5 级==（回想费用 ==0==）


**类型**：能力


拿卡时永久选择两项：压力槽、生命槽等。

一次性的==永久增益==，越早拿越赚。


**适合**：所有利刃角色的长线投资。


::::

:::: card

::: center

### **怒意重击**

:::


**等级**：==6 级==（回想费用 ==1==）


**类型**：能力


标记 1 压力点，伤害掷骰获得==力量两倍==加值，力量流的一击爆发。


**适合**：高力量构筑的核心伤害技。


::::

:::: card

::: center

### **猛攻强袭**

:::


**等级**：==10 级==（回想费用 ==3==）


**类型**：能力


成功用武器攻击时，伤害不低于目标的==重度伤害阈值==，十级收官刀刀入肉。


**适合**：主输出位的终局配置。

:::

**类型**：==能力==

#### **猛攻强袭 Onslaught**

:::

**回想费用**：==3==

**类型**：==能力==

当你成功使用武器进行攻击时，你造成的伤害不会低于目标的`重度伤害阈值`（目标总是至少**标记 2 生命点**）。

此外，当一个位于你武器射程内的生物对你的盟友造成伤害，且该攻击不包含你时，你可以**标记 1 压力点**，迫使其进行一次`反应掷骰`（15）。

如果失败，目标必须**标记 1 生命点**。
