<a id="community"></a>

### **社群 🏘️**

::: card

`社群`回答 ==你从哪里来==——社会出身与文化烙印的维度

9 个社群，各自携带 1 项特质，决定你的文化技能优势

贵族精灵与流浪精灵，是两个完全不同的角色

[社群全表 · 灰机百科](https://daggerheart.huijiwiki.com/wiki/%E5%88%86%E7%B1%BB:%E7%A4%BE%E7%BE%A4)

<a id="experience"></a>

### **经历 📖**

::: card

`经历`回答 ==你经历过什么==——没有清单，由你自己书写

- 写下 2 条，以短语形式——"当过海盗""在灯塔长大"
- 游玩中花费 <Badge type="danger" text="1 希望点" /> 运用 1 条，向掷骰添加经历加值（初始 +2）

:::

::: tip 经历的选法

越 ==具体、实际、常用== 越好

"当过海盗"能用在操帆、威吓、酒馆斗殴——想擅长的场面，就写进经历里

:::

### **属性 📈**

==`属性`==根据以下数值任意排序分配：

<Badge type="danger" text="+2、+1、+1、0、0、−1" />

::: table

| 属性 | 擅长 |
|:----|:----|
| `敏捷` | 冲刺、跳跃、机动 |
| `力量` | 举起、猛击、擒抱 |
| `灵巧` | 控制、隐藏、修补 |
| `本能` | 感知、察觉、导航 |
| `风度` | 魅力、表演、欺骗 |
| `知识` | 回忆、分析、理解 |

:::

<a id="domain"></a>

### **领域 📜**

::: card

`领域`可以视为各种可选的特殊能力与法术，以 ==卡牌== 的形式搭载于角色

1. **初始==`领域`==卡**——从职业对应的`领域`中，选择共 2 张 1 级`领域`卡
2. **升级得卡**——每升 1 级，选择 1 张 ≤ 当次等级的==`领域`==卡
3. **激活手牌`配置`**——同时只能激活 5 张==`领域`==卡，多余的放入`宝库`

:::

::: tip 车卡速算

卡牌总数 = 等级数 + 1——从 1 级排起：1 级 2 张，2、3、4 级各 1 张……

:::

::: card

**`宝库`换牌**

- ==`休整`==时，与`宝库`自由换牌
- 非==`休整`==时，消耗 <Badge type="danger" text="= 宝库对应领域卡回想费用" /> 点`压力点`，立刻换入 1 张
- 升级时，新获得的==`领域`==卡可与手牌中的 1 张更换

==`回想费用`==——印在每张卡右上角（闪电符号旁）的数字

:::

::: tip 自定义领域

职业有其固定对应的 2 个==`领域`==

不妨与主持人讨论自选 2 个`领域`，拓展构筑空间

[领域卡全表 · 灰机百科](https://daggerheart.huijiwiki.com/wiki/%E9%A2%86%E5%9F%9F%E5%8D%A1)

:::

<a id="vitals"></a>

### **数据 🧮**

起始数值均随职业卡而来：

::: table

| 项目 | 起始值 |
|:----|:----|
| 生命点 | 5–7（随职业） |
| 压力 | 6（全职业） |
| 闪避 | 9–12（随职业） |

:::

::: tip 成长上限

生命点与压力点可随升级提升上限——==两者最高都是 12 点==

:::
