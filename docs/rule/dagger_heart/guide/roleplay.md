## **🧭 属性与经历**

::::

::: card

描述你想做什么时，从六项`属性`中挑最贴切的一项作为调整值

| 属性 | 擅长 |
|:----|:----|
| `敏捷` | 冲刺、跳跃、机动 |
| `力量` | 举起、猛击、擒抱 |
| `灵巧` | 控制、隐藏、修补 |
| `本能` | 感知、察觉、导航 |
| `知识` | 回忆、分析、理解 |
| `风度` | 魅力、表演、欺骗 |

:::

::: card

`经历`是你过去活过的人生——海盗、教团孤儿、皇家剑术学徒

花费 <Badge type="danger" text="1 希望点" /> 运用一项经历，向掷骰添加经历加值（+1 或 +2）

==只要说得通，任何属性的动作都能用上任何经历==

:::

## **🎯 难度**

::::

::: card

游戏主持人设定难度等级，你的掷骰总数与之相比

| 总数达到 | 难度体感 |
|:----|:----|
| 5 | 非常容易 |
| 10 | 容易 |
| 15 | 一般 |
| 20 | 困难 |
| 25 | 非常困难 |
| 30 | 几乎不可能 |

:::

::: tip

掷骰前与游戏主持人一起确认此次行动的 ==风险与收益==——让每一次掷骰都至关重要

:::

## **🌊 压力**

::::

::: card

`压力`标记在角色卡上——恐惧、动摇、伤痛的具象刻度

压力点未清除时持续存在，压力满格时角色 ==身心俱疲==，急需喘息

:::

::: card

关键成功可清除 <Badge type="danger" text="1 压力点" />

短休时选择 *缓解压力* 清除 1d4 + 位阶点

==承受压力，或支付压力==——有时标记一个压力点，能换来把盟友拉出危险的一步

:::

## **💡 希望点**

::::

::: card

掷出希望结果时，获得 1 希望点——==失败的希望也是希望==

希望点可以用来：

- *帮助一位盟友*——掷 d6 优势骰加入盟友掷骰
- *运用一项经历*——为掷骰添加经历加值
- *激活希望特性*——职业卡上的高光时刻
- *发起接力掷骰*——与另一角色共同行动的火花

:::

::: tip

希望点是你在故事里的储蓄——==花在让你心跳的时刻==，比攒着更有价值

:::
