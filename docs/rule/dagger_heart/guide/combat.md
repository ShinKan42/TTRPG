## **⚔️ 战斗的本质**

:::

:::: card

匕首之心的战斗 ==没有先攻顺序、没有回合圈、没有固定行动次数==

每场交锋以即时叙事展开，和非战斗场景同一套规则

桌面注意力聚在谁身上，谁就站在聚光灯下——想动就说，镜头跟着话走

低风险行动自动成功，英勇或高风险的行动才需要[动作掷骰](./quick_roll#action-roll)

战斗不被机制锁死——玩家随时可以选择 ==逃离敌手、与敌人达成临时休战==，暴力之外的解法始终敞开

## **⏱️ 战斗的流转**

:::

:::: card

<a id="flow"></a>

一场战斗就是聚光灯在玩家与游戏主持人之间来回

---

### **玩家出手与连动**

<a id="player-turn"></a>

您描述行动、进行动作掷骰

希望成功——您继续持有聚光灯，随时可以再动

==失败、恐惧结果、或游戏主持人花费恐惧点打断==——聚光灯移交给游戏主持人

---

### **主持接管与交还**

<a id="gm-turn"></a>

游戏主持人执行一次行动：聚焦一个敌人、让局势急转直下、或推进环境威胁

行动完成后，聚光灯 ==自动交还玩家==——「你们要怎么办？」

::: tip 主持人行动的五个时机

玩家掷出恐惧结果 · 玩家掷骰失败 · 玩家做了会带来后果的事 · 玩家给出绝佳机会 · 玩家看向你等待下文

:::

::: tip 聚焦在主持人手里时

玩家角色不能使用需要花费资源或进行掷骰的特性——除非该行动明确允许，例如反应掷骰或打断攻击/伤害掷骰的特性

:::

## **😈 聚焦敌人**

:::

:::: card

### **敌人的四种动作**

<a id="enemy-actions"></a>

游戏主持人聚焦一个敌人时，敌人通常执行下列之一：

::: table

| 动作 | 说明 |
|:----|:----|
| 移动至近距离范围并攻击 | 一次普通攻击 |
| 移动至近距离范围并使用敌人动作 | 敌人的特殊能力 |
| 清除一个状态或临时效果 | 挣脱缠绕、重整姿态 |
| 冲刺到战场其他位置 | 移动至远距离或极远范围 |

:::

---

### **恐惧点经济**

<a id="fear-economy"></a>

恐惧点是游戏主持人的战斗资源，==上限 12 点==，开局时等于玩家角色数量

玩家的每个恐惧结果都在为它充能

花费 <Badge type="danger" text="1 恐惧点" />，可以：

- *打断玩家*——在玩家连续行动之间插入一次主持人行动
- *追加行动*——在主持人轮里再执行一个额外行动
- *聚焦额外敌人*——每 1 点聚焦一个
- *使用敌人的恐惧特性*——按敌人卡标注的花费
- *使用环境的恐惧特性*——按环境卡标注的花费
- *借用敌人经历*——将一个敌人的经历加值加入掷骰

已花费恐惧点聚焦额外敌人后，再想用该敌人的恐惧特性，==需要额外再花==

场景越重要，可花的恐惧点越多——日常场景 0-1 点，高潮场景可花到 6-12 点

## **🎲 敌人掷骰——d20 制**

:::

:::: card

### **敌人攻击掷骰**

<a id="enemy-roll"></a>

敌人攻击时，游戏主持人掷 ==一个 d20==，加上敌人卡的攻击调整值，与目标的`闪避值`比较

达到或超过——命中，按敌人卡掷伤害；低于——落空，请玩家描述角色如何躲开

优势或劣势——额外掷一个 d20，==取最高或最低==

==d20 掷出 20==——关键成功：自动命中，且伤害加上全部伤害骰的最大值（与玩家重击同构）

---

### **敌人不做动作掷骰**

敌人几乎能做玩家能做的一切——撬锁、攀崖、谈判

行为存在失败可能时，优先给玩家一次`反应掷骰`或回应机会——==故事焦点始终在玩家手里==

戏剧性或高难度任务确需主持人掷骰时——花费 <Badge type="danger" text="1 恐惧点" />，掷 d20 加上敌人相关经历加值，与难度比较

---

### **敌人反应掷骰**

玩家的行动迫使敌人回应时，游戏主持人掷 ==一个 d20== 与难度比较

可花费 <Badge type="danger" text="1 恐惧点" /> 加入敌人经历加值

判定敌人有明显弱点（迟缓、怕火）时，可直接施加惩罚减值

---

### **敌人经历**

<a id="enemy-exp"></a>

花费 <Badge type="danger" text="1 恐惧点" />，可将敌人的经历加值用在三处：

- 玩家对它掷骰时——==提高该次掷骰的难度==
- 它攻击时——加入攻击掷骰
- 它做反应掷骰时——加入掷骰

经历留到戏剧性时刻再用，比每次都加更有分量

## **🃏 敌人卡速读**

:::

:::: card

### **卡面字段**

敌人没有`闪避值`——==所有针对敌人的掷骰，难度取敌人卡的难度值==

::: table

| 字段 | 读法 |
|:----|:----|
| 位阶 | 1-4 档，对应队伍位阶；跨档使用需调数 |
| 类型 | 在冲突中的角色定位（见下表） |
| 难度 | 玩家对它掷骰的难度基准 |
| 阈值 | 写作「8/14」——重度 8、严重 14 |
| 生命点 / 压力点 | 与玩家同规运作 |
| 攻击调整值 | 加在它的 d20 攻击掷骰上 |
| 普通攻击 | 名称 · 范围 · 伤害，聚焦时永远可用 |
| 经历 | 花 1 恐惧点启用（见上节） |
| 动机与战术 | 叙事建议——逃走、获利、烟雾弹，供即兴取材 |

:::

### **敌人类型**

<a id="enemy-types"></a>

::: table

| 类型 | 定位 |
|:----|:----|
| 斗士 | 强韧且攻击力大 |
| 集群 | 多只同种生物协同行动，半血后伤害变化 |
| 头目 | 指挥并召唤其他敌人 |
| 杂兵 | 一击即溃，数量多时危险——溢出伤害连锁击倒 |
| 远程 | 近身脆弱，远处高伤 |
| 潜伏 | 机动伏击 |
| 社交 | 以对话应对冲突 |
| 独狼 | 单独对抗整队 |
| 标准 | 派系中的普通一员 |
| 辅助 | 增强盟友、扰乱对手 |

:::

### **特性的三种触发**

<a id="traits"></a>

- *动作*——==必须被聚焦==才能使用；部分要求标记敌人的压力点或花费恐惧点
- *反应*——触发条件满足时立即生效，==无需花费恐惧点打断==
- *被动*——所述情况下始终生效

敌人的压力单独追踪——标记满了，不能挪用别的敌人的压力

特殊形态：

- *恐惧特性*——花恐惧点启动的强大效果，留给最具冲击力的场合
- *召唤特性*——把新敌人拉进战场，出现在指定范围内
- *聚焦特性*——免恐惧点立即聚焦多个其他敌人

::: details 可选工具：聚焦追踪器

偏好战术或明确回合制的团队，可以给每名角色 3 个动作指示物

聚焦中每次动作掷骰或重要动作消耗 1 个

所有人用尽后一起重置——数字可按团队口味增减

:::

## **🏞️ 环境卡速读**

:::

:::: card

环境 = 场景中除玩家与敌人外的一切——物理空间、背景角色、自然力量

环境卡不限战斗：舞会的暗流、废墟的危机，随时可用

---

### **卡面字段**

::: table

| 字段 | 读法 |
|:----|:----|
| 位阶 | 考验的队伍位阶，跨档用换算表调整 |
| 类型 | 探索 · 社交 · 险境 · 事件 |
| 趋向 | 环境对身处其中者的叙事推力——河流要把你冲走，赌场要使你迷失 |
| 难度 | 直接对抗环境要素的动作掷骰基准 |
| 潜在敌人 | 建议出现 的敌人，可自由替换 |
| 特性 | 同敌人特性三型：动作 / 反应 / 被动 |

:::

环境同样可以拥有 ==恐惧特性==——花恐惧点启动的场景级大效果

框架为启发创意而生——调整、改造、无视，都合法

::: details 不同位阶的环境数据换算

| 环境数据 | 位阶1 | 位阶2 | 位阶3 | 位阶4 |
|:----|:----|:----|:----|:----|
| 伤害骰 | 1d6+1 到 1d8+3 | 2d6+3 到 2d10+2 | 3d8+3 到 3d10+1 | 4d8+3 到 4d10+10 |
| 难度 | 11 | 14 | 17 | 20 |

:::

## **🏃 战斗中的移动**

:::

:::: card

距离档位与体感见[基础规则 · 距离](./general_rule#distance)

---

### **动作中移动（近距离内）**

<a id="move-action"></a>

进行动作掷骰时，可以把 ==移动到近距离范围内== 作为动作的一部分

该位置必须是角色叙事上能合理轻松到达的地方

---

### **远距离移动（作为主要行动）**

<a id="move-far"></a>

想移动到远距离或极远范围、或到达不易抵达的区域（攀爬、游泳、跳跃）——需成功进行一次 `敏捷` 掷骰

失败时可能只移动了部分距离、敌人抢先行动、或被完全阻止

---

### **敌人的移动**

<a id="move-enemy"></a>

敌人被聚焦行动时，游戏主持人可将其移动到 ==近距离范围内的任意位置==，作为动作的一部分

移动到远距离或极远范围会消耗敌人的整个行动，但 ==无需掷骰==

## **🛡️ 掩护、视线与黑暗**

:::

:::: card

### **掩护**

<a id="cover"></a>

躲在路障、树干等掩体后——敌人对你的攻击掷骰具有 ==劣势==

完全躲在坚固建筑（如墙壁）后面——==通常无法成为目标==，但仍可能受爆炸等区域性效果波及

---

### **视线**

<a id="sight"></a>

有些效果要求目标在你的视线内——能看到目标即有视线

游戏主持人可裁定效果无法穿过玻璃窗等透明物体

---

### **黑暗**

<a id="dark"></a>

黑暗让行动更具挑战——游戏主持人通过 ==提高难度或施加劣势== 来体现

## **🔄 优势与劣势**

:::

:::: card

`优势`：掷骰结果中 ==增加== 一个 d6

`劣势`：掷骰结果中 ==减去== 一个 d6

---

### **抵消规则**

<a id="cancel-out"></a>

优势与劣势应用于同一掷骰时 ==总是相互抵消==——不可能同时掷出优势骰与劣势骰

两个优势来源对一个劣势来源：抵消一个，==净剩一个优势==

---

### **多来源优势**

多个来源的优势，只将 ==最高的结果== 加到掷骰中

---

### **NPC 的特例**

<a id="npc-d20"></a>

敌人获得优势或劣势时，游戏主持人改掷一个 d20，优势取最高、劣势取最低（详见[敌人掷骰](#enemy-roll)）
