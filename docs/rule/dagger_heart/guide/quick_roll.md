<a id="action-roll"></a>

## **🎲 动作掷骰**

:::

::: card

描述你想做什么，与游戏主持人一起确认是否需要掷骰

确认后，选择适用的调整值——==`属性`== 与 `经历`

==二元骰（希望骰 + 恐惧骰）== 同时投出，结果相加，外加调整值

告诉游戏主持人总数，以及 ==哪一颗骰子点数更高==

:::

:::: card

::: center

<a id="experience"></a>

### **经历 📖**

:::

花费 <Badge type="danger" text="1 希望点" /> 运用==`经历`==，向掷骰添加一项经历加值（初始 +2）

==`经历`==写在角色卡上——你过去活过的人生，此刻派上用场

<a id="adv-dis"></a>

### **优势 / 劣势 ⬆️**

`优势`：掷骰结果中增加一个 d6 优势骰

`劣势`：掷骰结果中减去一个 d6 劣势骰

优势与劣势应用于同一掷骰时 ==相互抵消==——详见[战斗规则](./combat#cancel-out)

多个来源的优势，只将 ==最高的结果== 加到掷骰中

<a id="roll-results"></a>

## **🎯 掷骰结果**

:::

::: card

### **关键成功 ✨**

希望骰与恐惧骰 ==掷出相同数字==

你如愿以偿，还有额外收获——获得 <Badge type="danger" text="1 希望点" /> 并清除 <Badge type="danger" text="1 压力点" />

:::

::: card

<a id="希望成功"></a>
### **希望成功 🌅**

希望骰更高，总数达标

你顺利完成并如愿以偿——获得 <Badge type="danger" text="1 希望点" />

:::

::: card

<a id="恐惧成功"></a>
### **恐惧成功 🌑**

恐惧骰更高，总数达标

你如愿以偿，但伴随着代价或后果——可能是受到攻击、信息有限。  
引来危险，或其他复杂局面

游戏主持人获得 <Badge type="danger" text="1 恐惧点" />

:::

::: card

<a id="希望失败"></a>
### **希望失败 💡**

希望骰更高，总数未达标

事情没有按计划进行。  
你很可能无法如愿并遭遇一些后果——但你获得 <Badge type="danger" text="1 希望点" />

:::

::: card

<a id="恐惧失败"></a>
### **恐惧失败 🌊**

恐惧骰更高，总数未达标

事情进展得非常糟糕，你很可能无法如愿并引发重大后果或复杂局面

游戏主持人获得 <Badge type="danger" text="1 恐惧点" />

:::

<a id="难度与命中"></a>

## **🎯 难度与命中**

:::

::: card

游戏主持人设定难度，你的掷骰总数与之相比

==任何针对角色的掷骰，难度等同于目标的闪避==

角色的基础闪避由职业决定

攻击敌人时，难度取敌人的难度值

:::

:::: card

::: table

| 总数达到 | 难度体感 |
|:----|:----|
| 5 | 非常简单 |
| 10 | 简单 |
| 15 | 普通 |
| 20 | 困难 |
| 25 | 非常困难 |
| 30 | 几乎不可能 |

:::

::::

详见[扮演与情感 · 难度](./roleplay#难度)

<a id="group-rolls"></a>

## **🤝 协作掷骰**

:::

:::: card

<a id="help-ally"></a>

### **帮助盟友 🫱**

花费 <Badge type="danger" text="1 希望点" />，掷一个 ==d6 优势骰==加入盟友的掷骰中

<a id="group-action"></a>

### **团队动作 ⚔️**

指定该次动作的`领导者`

其他参与者进行`反应掷骰`——使用共同决定的最适合属性（不必相同）

领导者进行`动作掷骰`：每个成功的反应掷骰 +1，每个失败的反应掷骰 -1

<a id="reaction-roll"></a>

### **反应掷骰 🔄**

与`动作掷骰`类似，但 ==不产生== 希望结果。  
恐惧结果或额外的游戏主持人行动——争分夺秒。  
==其他角色不能在反应掷骰中帮助你==

反应掷骰掷出 ==关键成功== 时——不清除压力点、不获得希望点。  
但可以无视原本在成功时仍会生效的任何附加效果。  
（如承受伤害或标记压力）

<a id="relay-roll"></a>

### **接力掷骰 🔥**

==每场游戏一次==，每个玩家可花费 <Badge type="danger" text="3 希望点" /> 发起——发起限每场一次。  
==参与他人发起的接力不限==

两名玩家合作，描述如何以独特且激动人心的方式一起行动——
分别进行`动作掷骰`，判定前 ==选择其中一个结果== 应用于双方

- *希望结果*——所有参与角色获得 1 希望点
- *恐惧结果*——每有一名参与者，游戏主持人获得 1 恐惧点
- *成功攻击*——分别进行`伤害掷骰`，结果相加为总伤害

<a id="生命与伤害"></a>

## **❤️ 生命与伤害**

:::

:::: card

受伤按==伤害门槛==标记生命点。

门槛 = 护甲列出的门槛 + 自身等级

::: table

| 最终伤害达到 | 标记 |
|:----|:----|
| 严重门槛及以上 | 3 生命点 |
| 重度门槛及以上 | 2 生命点 |
| 重度门槛以下 | 1 生命点 |

:::

伤害降至 <Badge type="danger" text="0 或更低" /> 时不标记生命点

==标记最后一个生命点时，角色倒下==

`抗性`：伤害减半后再与门槛比较。

与护甲槽并存时==先抗性，后护甲==

`免疫`：直接无视该类型伤害

压力记满时陷入`脆弱`。

必须标记压力却标记不了时，改为标记 <Badge type="danger" text="1 生命点" />

<a id="攻击与重击"></a>

## **⚔️ 攻击与重击**

:::

:::: card

武器伤害骰的数量 = <Badge type="danger" text="熟练值" />（起始 1，最高 6）。

骰数翻倍，==加值不变==

徒手攻击造成==熟练值个 d4==物理伤害

`重击`：攻击掷骰掷出`关键成功`时，伤害额外加上==全部伤害骰的最大值==

`多目标`：掷一次攻击掷骰，与==每个目标的难度==逐一比较

掷一次伤害，应用于所有命中的目标

同一次行动中的多次伤害==相加后==再与门槛比较

::::

详见[通用规则 · 攻击与伤害](./general_rule#attack-damage)

<a id="defense-status"></a>

## **🛡️ 防守与状态**

:::

:::: card

<a id="armor-slots"></a>

### **护甲槽 🪖**

你的护甲值代表护甲槽数量

受到伤害时，可标记 <Badge type="danger" text="1 护甲槽" /> 将 ==伤害等级降低一级==——
==每次受到攻击只能标记 1 个==

`直接伤害`无法通过标记护甲槽降低伤害等级

<a id="conditions"></a>

### **三状态 ⚠️**

`脆弱`：所有以其为目标的掷骰都具有优势

`束缚`：不能移动，仍可在当前位置采取行动

`隐藏`：不在所有敌人视野内且位置未知——对你进行的所有掷骰都具有劣势；  
敌人看到你、你进入其视线或进行攻击后脱离

<a id="cover-sight-dark"></a>

### **掩护、视线与黑暗 🌑**

躲在掩体后——敌人对你的攻击掷骰具有==劣势==

完全躲在坚固建筑后——==通常无法成为目标==

黑暗中行动——游戏主持人==提高难度或施加劣势==

<a id="压力与希望"></a>

## **💡 压力与希望**

:::

:::: card

==压力满格==时陷入`脆弱`，针对你的掷骰都具有优势

`关键成功`可清除 <Badge type="danger" text="1 压力点" />

短休选择 *缓解压力* 清除 1d4 + 位阶点

---

掷出希望结果时获得 1 希望点——==失败的希望也是希望==

- *帮助盟友*——掷 d6 优势骰加入其掷骰
- *运用经历*——为掷骰添加经历加值
- *激活希望特性*——职业卡上的高光时刻
- *发起接力掷骰*——每场一次，与盟友共同行动

<a id="濒死与伤痕"></a>

## **💀 濒死与伤痕**

:::

:::: card

标记最后一个生命点时，三选一：

- **荣光就义**——再取一个行动，自动`关键成功`，然后跨越死亡之幕
- **回避死亡**——暂时失去意识；
盟友清除 1 点以上生命点或队伍长休后苏醒
- **孤注一掷**——掷`二元骰`：希望骰高，站稳并清除等同于希望骰点数的生命点或压力；
恐惧骰高，跨越死亡之幕。

同数==关键成功==，站稳并恢复所有生命点、清除所有压力

`回避死亡`昏迷后掷`希望骰`——点数 ≤ 角色等级时留下一道==伤痕==

伤痕 = 永久划掉 1 个希望槽

::::

详见[通用规则 · 濒死](./general_rule#dying)

<a id="rest"></a>

## **🏕️ 休整**

:::

::: card

<a id="位阶速查"></a>
### **位阶速查 📊**

等级 1 ▶ 位阶 1  |  等级 2–4 ▶ 位阶 2  |  等级 5–7 ▶ 位阶 3  |  等级 8–10 ▶ 位阶 4

:::

:::: card

<a id="short-rest"></a>

### **短休 ⛺**

==两次长休之间最多三次短休==——被打断的短休无益处。  
被打断的长休按短休结算

每位玩家可将配置中的领域卡与宝库交换（==先换牌，再用休整行动==）。  
然后选择两项行动（==可选同一项两次==）

游戏主持人获得 <Badge type="danger" text="1d4 恐惧点" />

- *处理伤口*——恢复 1d4 + 位阶生命点，可选对盟友进行
- *缓解压力*——清除 1d4 + 位阶压力点
- *修理护甲*——清除 1d4 + 位阶护甲槽标记，可选修理盟友护甲
- *做好准备*——获得 1 希望点；
与队伍成员一起准备则每人 2 希望点

<a id="long-rest"></a>

### **长休 🌙**

领域卡交换同短休，选择两项行动

游戏主持人获得 <Badge type="danger" text="角色数量 + 1d4 恐惧点" />，并可以推进一个长期倒计时

- *处理所有伤口*——恢复所有生命点，可选对盟友进行
- *缓解所有压力*——清除所有压力
- *修理所有护甲*——清除所有护甲槽标记，可选修理盟友护甲
- *做好充分准备*——获得 1 希望点；
与队伍成员一起准备则每人 2 希望点
- *推进长期项目*——建立或推进一个项目。
游戏主持人可能要求掷骰决定进度倒计时推进多少

::: tip 休整刷新什么

持续到下次休息的效果在休整完成时结束；  
标注 ==每长休一次== 的特性只在长休刷新

标注 ==每场游戏一次== 的特性不靠休息刷新——下一场游戏开始时才恢复；  
超长场次中，主持人可裁定中场休息后刷新

:::
