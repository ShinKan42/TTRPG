### **什么是匕首之心？ 🗡️**

::: card

匕首之心是一款 ==以共创叙事为核心== 的奇幻角色扮演游戏

即使在战斗，也能随时提出行动，开启二元骰的对戏

我们每个人都根据骰面自主描述行动的细节，并说明如何体现成功程度

主题由我们决定——奇幻、科幻、现代、任何 IP——==只要我们想讲，就能讲==

:::

::: center

### **共创思维 🎭**

:::

:::: card

::: center

这是匕首之心的根本前提。像即兴戏剧——我接你的戏，你抛我的戏，互相给对方创造空间

你 ==主动抛出事件==。每句话都是你把球抛出去，看对方怎么接

:::

::::

::: tip

如果你说"我不知道该做什么"——答案很简单：==你的角色想做什么？==

匕首之心适合有创作欲的人

创作欲是一份 ==邀请==——你负责想故事要讲什么，系统负责让它在桌上发生


:::

---

::: center

### **共建世界 🌍**

:::

:::: card

::: center

世界没有预设。匕首之心用 ==战役框架（Campaign Framework）== 来启动

:::

::: card

第 0 场时，我们一起讨论：

这个世界什么样的？有什么势力？什么危机？需要有什么规则？

- 我们一起定制 ==专属规则==
- 我们一起填充 ==世设细节==
- 我们一起决定 ==故事方向==

:::

::: center

==这桌讲什么故事，完全由我们决定==

:::

::: center

用现成的 IP 做改编团、从头新建一个世界、把几个设定混在一起玩，都可以

:::

::: center

==只要我们这桌的人想讲，就能讲==

:::

::: important

核心规则 + 战役框架，才是完整的匕首之心

战役框架决定了所有风味——故事、规则。最大的影响是：怎么看待世界，以及怎么经历/游玩世界

:::

### **叙事流动性 💫**

:::

:::: card

::: center

二元骰决定的是 ==谁拿到叙事资源==——希望骰高、资源归玩家；恐惧骰高、资源归 GM

资源就是用来推进故事的：加细节、定结果、推情节

==行动和叙事是所有人+骰子共同拥有的==

### **模块化构建 🧩**

:::

:::: card-grid

::: card

#### **卡片组合**

- *种族*——你是谁  
- *社群*——你从哪里来  
- *经历*——你经历过什么  
- *职业*——你擅长什么  
- *领域*——你的能力领域

五个模块 ==独立运作==

选同一个职业的两个人  
因其他模块不同  
可以是 ==完全不同的角色==

:::

::: card

#### **适合DIY**

如果你想要造一张新卡片

- *本质相同*——五类模块共用同一套格式
- *数值简洁*——核心数值清晰，造新卡门槛低
- *独立运作*——改一个不影响其他模块
- *试错成本低*——不满意就换掉这一张

由于共创与留白  
能力可以随心所欲设计  
平衡起来相对容易  
也没有太多世设的限制

## **❔ 怎么玩？**

:::

::: center

### **共创战役（战役框架与 Session 0）** 🗺️

:::

:::: card

第 0 场谈定的每一件事  
之后都会在桌上回来

- *基调*——大家说话做事的味道  
- *势力*——等着与你们周旋的人  
- *危机*——迟早走到面前的墙

==你在第 0 场说的每个字都算数==  
它们会成为日后每一次判断  
==值不值得冒险== 的依据

::: tip

第 0 场不必一次定满  
框架会在故事里继续生长

:::

::::

---

::: center

### **行动博弈** ⚖️

:::

:::: card

没有固定的出手顺序——想动就能动，故事跟着走  

而每一次出手  
都在往 GM 的恐惧账上记上一笔  

价格摆在骰子之前——  
绕过去，稳，却放走了机会  
硬闯，痛快，却把恐惧递到了对面手里  

==自由是有价格的==  
价格叫 ==恐惧==  

::: tip

不必事事精算  
坐上桌的人都有一杆秤  

==值得就上，不值就绕==  

:::

::::

---

::: center

### **叙事经济（倒计时与恐惧点）** ⏳

:::

:::: card-grid

::: card

#### **希望是你的钱**

希望更高时  
你账上多一枚 ==希望点==

花出去——  
启动更强的招式  
或替同伴垫上一把力  

什么时候花，是你的节奏

:::

::: card

#### **恐惧是世界的力气**

恐惧更高时  
GM 手里的压力便涨一分  

压力在你看不见的地方生长——  
等一个时机，一口气压下来  

墙更厚  
雾更浓  
岔路更少  

:::

::::

两本账同时在长  
==你在赌，对面也在赌==  

倒计时就挂在账上——  
钟不等人，自顾自往前走  
==你不推故事，故事就反推回来==  

::: tip

花钱与攒钱都是推进故事的方式  
区别只在——谁主动

:::

---

::: center

### **是的而且（叙事内容细节的积累）** 🤝

:::

:::: card

骰子一落  
下一句话就有了形状  

*希望骰高*——"是的，而且"  
你接住这一切  
往上再添一笔自己的色彩  

*恐惧骰高*——"是的，但是"  
故事照常向前  
代价也一并登场  

两种都算数——  
世界一直在回应你  
==只是语气不同==  

==每一句话  
都是递给下一句的梯子==  

::: tip **即兴的心法**

不求妙语  
==接住，再添一码==  
就够了  

:::

## **💡 想要进阶？**

:::

:::: card-grid

::: card

#### **濒死的选择**

生命见底时  
轮到你做最后一个决定  

- *壮烈退场*——把最后一幕演成传奇  
- *冒险一搏*——赌一场绝境翻盘  
- *带伤离场*——活着回去，留下印记  

死亡在这里是一扇门  
==由你选推开哪一扇==  

:::

::: card

#### **活着的角色会长大**

每次团结束  
角色都会收获 ==经验==  

拿它去拓宽可能：  
给老模块添上新写法  
或朝新方向重塑一段来路  

第 0 场定下的底稿  
只是一切的开头  

==角色和故事一样，是长出来的==  

:::

::: card

#### **为并肩而生的能力**

许多能力写着 ==帮助他人== 的用法  

替队友挡下一击  
趁自己占优时拉一把劣势中的人  

并肩谋划，远胜单打独斗  

:::

::: card

#### **领域卡的搭配**

每个职业自带两类 ==领域==  
起手的牌从这里配起  

喜欢硬碰硬，还是以巧取胜  
卡组就是你的答案  

用不顺的可以换掉  
==卡组随角色一同成长==  

:::
