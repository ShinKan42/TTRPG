<a id="golden-rule"></a>

## **👑 黄金规则**

:::

::: card

==把游戏变成你自己的==

规则为桌上的故事服务——只要全桌同意，任何规则都可以调整、忽略或改写

规则永远不该挡在你想讲的故事、想玩的角色、想经历的冒险前面

:::

::: card

**裁定优先于规则**

书没有回答所有问题——拿不准时，游戏主持人按叙事逻辑当场裁定

勾爪能拉动一整座城堡吗？规则没禁止，但叙事说不过去——也许拽下几块砖，也许把自己拉向了墙

一切回到虚构本身

:::

::: details 通用条款速查

- *向上取整*——本游戏不使用小数；需要取整时，除非另有说明，向上取整
- *重骰*——必须接受新的结果，不能在旧结果与新结果间挑选（除非特性明确说明）
- *花费纪律*——同一次掷骰不能多次花费资源重复同一效果（「+1d6」不能花双份变 2d6）；不作用于掷骰的效果可多次激活（花 3 希望清 2 护甲槽 → 花 6 清 4）
- *叠加*——状态、优势、劣势不能叠加；其他效果在主持人裁量下可叠加
- *持续效果*——已生效的法术效果不因换出领域卡而中断，直到被终止或剧情自然翻页

:::

## **🎯 命中与闪避**

:::

`闪避`代表角色躲避攻击与其他不良效果的能力

==任何针对角色的掷骰，难度等同于目标的闪避==

角色的基础闪避由职业决定，领域卡、装备、状态等可以修正

::: tip

攻击敌人时，难度取敌人的难度值，同样一目了然

:::

## **❤️ 生命与伤害**

:::

`生命点`代表承受物理创伤的能力——受伤时按伤害门槛标记 1–3 点

角色的伤害门槛 = 护甲列出的门槛 + 自身等级

::: table

| 最终伤害达到 | 标记 |
|:----|:----|
| 严重门槛及以上 | 3 生命点 |
| 重度门槛及以上 | 2 生命点 |
| 重度门槛以下 | 1 生命点 |

:::

伤害被降至 <Badge type="danger" text="0 或更低" /> 时不标记任何生命点

::: details 可选规则：巨额伤害

一次伤害达到 ==严重门槛的两倍或更高== 时，改为标记 4 生命点——为追求险象环生的团队准备

:::

==标记最后一个生命点时，角色倒下==——进入[濒死](#dying)

::: center

<a id="压力的溢出"></a>
### **压力的溢出 🌊**

:::

`压力`记满时，角色陷入`脆弱`状态，直到清除至少 1 点压力

必须标记压力却标记不了时，改为标记 <Badge type="danger" text="1 生命点" />

<a id="伤害类型与抗性"></a>
### **伤害类型与抗性 🛡️**

- *物理*——武器与徒手
- *魔法*——法术

`抗性`：伤害减半后，再与门槛比较——同时有抗性与护甲槽时，==先抗性，后护甲==；  
同类抗性叠加无效

`免疫`：直接无视该类型伤害

物理与魔法混合的伤害，需要同时抗住两种类型才能受益

<a id="attack-damage"></a>

## **⚔️ 攻击与伤害**

:::

<a id="伤害掷骰"></a>
### **伤害掷骰 🎲**

攻击成功后掷伤害——武器伤害骰的数量 = <Badge type="danger" text="熟练值" />（起始 1，随升级提升，最高 6）

骰数翻倍，==加值不变==：熟练值 2 持「d8+2」武器 → 掷 <Badge type="danger" text="2d8+2" />

徒手攻击（`力量`或`敏捷`攻击掷骰）造成==熟练值个 d4==物理伤害

效果要求以`施法`属性造成伤害时，掷等同于`施法`属性值的骰数

### **重击 ✨**

攻击掷骰掷出`关键成功`时，伤害额外加上 ==全部伤害骰的最大值==

例：2d8+1 的攻击重击 → 2d8+1+16

<a id="多目标"></a>
### **多目标 🎯**

一个法术或能力允许多个目标时——掷一次攻击掷骰，与 ==每个目标的难度== 逐一比较；  
掷一次伤害，==应用于所有命中的目标==

同一次行动中的多次伤害==相加后==再与门槛比较；  
分开的行动分开结算

<a id="distance"></a>

## **📏 距离**

:::

::: table

| 距离 | 体感 | 危险中接近近战 |
|:----|:----|:----|
| 近战 | 触手可及 | — |
| 邻近 | 看得清细节 | 随行动自由进入近战 |
| 近距离 | 看得清轮廓 | 随行动自由进入近战 |
| 远距离 | 细节难辨 | 需`敏捷`掷骰成功 |
| 极远 | 只见轮廓 | 需`敏捷`掷骰成功 |
| 超出范围 | 超出场景 | 通常无法指定为目标 |

:::

::: tip

心智想象与地图棋子两相宜——1 英寸地图格约合 5 尺空间

==射程是最大值==：除非另注，更近处照用

:::

<a id="dying"></a>

## **💀 濒死**

:::

::: card

标记最后一个生命点时，从三项`濒死抉择`中选一项：

- **荣光就义**——拥抱死亡，燃尽最后一幕：再取一个行动，自动`关键成功`，然后跨越死亡之幕
- **回避死亡**——避开死亡，承受后果：暂时失去意识，与游戏主持人共同描述局势如何恶化；盟友==清除 1 点以上生命点==或队伍完成长休后苏醒
- **孤注一掷**——掷`二元骰`：希望骰高，站稳并清除等同于希望骰点数的生命点或压力（可任意分配）；恐惧骰高，跨越死亡之幕；同数——==关键成功==，站稳并恢复所有生命点、清除所有压力点

:::

<a id="伤痕"></a>
### **伤痕 🩹**

`回避死亡`昏迷后掷`希望骰`——点数 ≤ 角色等级时留下一道`伤痕`

伤痕 = ==永久划掉 1 个希望槽==，并与游戏主持人确定它的叙事印记

主持人可酌情开放治愈——作为休整时的长期项目、任务奖励，或其他具有同等叙事分量的事件

希望槽全部划掉时，角色的旅程落幕

::: tip

角色死亡后，与游戏主持人一起在下一场之前，按队伍当前等级创作新角色

复活并非不可能——通常是一个漫长、困难且代价高昂的过程；  
辉耀领域的 10 级法术`亡者苏生`是明路之一

故事继续

:::
