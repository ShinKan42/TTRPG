## **👑 黄金规则**

::::

:::: card

==把游戏变成你自己的==

规则为桌上的故事服务——只要全桌同意，任何规则都可以调整、忽略或改写

规则永远不该挡在你想讲的故事、想玩的角色、想经历的冒险前面

::::

:::: card

**裁定优先于规则**

书没有回答所有问题——拿不准时，游戏主持人按叙事逻辑当场裁定

勾爪能拉动一整座城堡吗？规则没禁止，但叙事说不过去——也许拽下几块砖，也许把自己拉向了墙

一切回到虚构本身

## **🎯 命中与闪避**

::::

`闪避`代表角色躲避攻击与其他不良效果的能力

==任何针对角色的掷骰，难度等同于目标的闪避==

角色的基础闪避由职业决定，领域卡、装备、状态等可以修正

::: tip

攻击敌人时，难度取敌人的难度值，同样一目了然

:::

## **❤️ 生命与伤害**

::::

`生命点`代表承受物理创伤的能力——受伤时按伤害门槛标记 1–3 点

角色的伤害门槛 = 护甲列出的门槛 + 自身等级

::: table

| 最终伤害达到 | 标记 |
|:----|:----|
| 严重门槛及以上 | 3 生命点 |
| 中度门槛及以上 | 2 生命点 |
| 中度门槛以下 | 1 生命点 |

:::

伤害被降至 <Badge type="danger" text="0 或更低" /> 时不标记任何生命点

==标记最后一个生命点时，角色倒下==——进入[濒死](#💀-濒死)

### **压力的溢出 🌊**

`压力`记满时，角色陷入`脆弱`状态，直到清除至少 1 点压力

必须标记压力却标记不了时，改为标记 <Badge type="danger" text="1 生命点" />

### **伤害类型与抗性 🛡️`

- *物理*——武器与徒手
- *魔法*——法术

`抗性`：伤害减半后，再与门槛比较；同类抗性叠加无效

`免疫`：直接无视该类型伤害

物理与魔法混合的伤害，需要同时抗住两种类型才能受益

## **⚔️ 攻击与伤害**

::::

### **伤害掷骰 🎲**

攻击成功后掷伤害——武器伤害骰的数量 = <Badge type="danger" text="熟练值" />

骰数翻倍，加值不变：熟练值 2 持「d8+2」武器 → 掷 <Badge type="danger" text="2d8+2" />

徒手攻击造成熟练值个 d4 伤害

效果要求以`施法`特质造成伤害时，掷等同于`施法`特质值的骰数

### **重击 ✨**

攻击掷骰掷出`关键成功`时，伤害额外加上 ==全部伤害骰的最大值==

例：2d8+1 的攻击重击 → 2d8+1+16

### **多目标 🎯`

一个法术或能力允许多个目标时——掷一次攻击、掷一次伤害，同一结果逐一应用于每个目标

同时来自多个来源的伤害，==相加后==再与门槛比较

## **📏 距离**

::::

::: table

| 距离 | 体感 | 危险中接近近身 |
|:----|:----|:----|
| 近身 | 触手可及 | — |
| 很近 | 看得清细节 | 随行动自由进入近身 |
| 近距 | 看得清轮廓 | 随行动自由进入近身 |
| 远距 | 细节难辨 | 需`敏捷`掷骰成功 |
| 很远 | 只见轮廓 | 需`敏捷`掷骰成功 |
| 射程外 | 超出场景 | 通常无法指定为目标 |

:::

::: tip

心智想象与地图棋子两相宜——1 英寸地图格约合 5 尺空间

射程是最大值：除非另注，更近处照用

:::

## **💀 濒死**

::::

::: card

标记最后一个生命点时，从三项`濒死抉择`中选一项：

- *壮烈退场*——拥抱死亡，燃尽最后一幕：再取一个行动，自动`关键成功`，然后跨越死亡之幕
- *带伤离场*——避开死亡，承受后果：暂时失去意识，与游戏主持人共同描述局势如何恶化；盟友清除 1 点以上生命点或队伍完成长休后苏醒
- *冒险一搏*——掷`二元骰`：希望骰高，站稳并清除等同于希望骰点数的生命点或压力（可任意分配）；恐惧骰高，跨越死亡之幕；同数，站稳但什么都不清除

:::

### **疤痕 🩹**

`带伤离场`昏迷后掷`希望骰`——点数 ≤ 角色等级时留下一道`疤痕`

疤痕 = ==永久划掉 1 个希望槽==，并与游戏主持人确定它的叙事印记

希望槽全部划掉时，角色的旅程落幕

::: tip

角色死亡后，与游戏主持人一起在下一场之前，按队伍当前等级创作新角色

故事继续

:::
