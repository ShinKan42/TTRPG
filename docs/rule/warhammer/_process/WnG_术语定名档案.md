# 愤怒与荣耀（Wrath & Glory）术语定名档案

> 本档案是本站 W&G 全部页面的用词唯一依据；页面用词与档案冲突时以档案为准。

> 批复记录：2026-09-25 DM 答复 Q1「推荐很好」——六处分歧点全按推荐定案。

## 三、检定核心（原书第八章）

| 原文 | 定名 | 说明 |
|------|------|------|
| Test / Opposed Test | 检定 / 对抗检定 | |
| Dice Pool | 骰池 | 属性＋技能个 d6，其中一颗异色为愤怒骰 |
| Difficulty Number（DN） | 难度值 | 缩写保留，用法同 DND 页的 DC |
| Icon | 图标 | 骰出 4–5 算 1 个图标 |
| Exalted Icon | 崇高图标 | 骰出 6 算 2 个图标，可移用换效果 |
| Wrath Die | 愤怒骰 | 骰出 6＝愤怒暴击（+1 荣耀），骰出 1＝变故 |
| Wrath Critical | 愤怒暴击 | 攻击检定叠暴击判定 |
| Complication | 变故 | 「成功，但是……／失败，而且……」的叙事钩子 |
| Wrath Points | 愤怒点 | 个人资源，每场开局 2 点：重掷失败骰／叙事宣告／恢复震荡 |
| Glory | 荣耀 | 团队共享池，上限 6 或人数+2 取高 |
| Ruin | 毁灭 | GM 手里的对应资源 |
| Shifting / Shift | 移用 | 把崇高图标从结果里拿出来换效果 |
| Bonus Dice / Penalty | 奖励骰 / 减值 | 加成永远是加骰，减值永远是加难度（+X 难度） |

## 九、增补与查证规则

- 页面写作遇到档案未收的术语：先增补本档案（带原书页码），再进页面正文。
- 设定专名（帝国、阿斯塔特、欧克兽人、艾达灵族、混沌四神、行商浪人、审判庭、机械神教等）按 40K 社区通行译名；关键专名执行轮走灰机 40K wiki 浏览器通道复核，与通行译名有出入的列单交 DM 裁。
- 档案每次修订在「批复记录」追加一行，注明日期与 DM 答复原话。
