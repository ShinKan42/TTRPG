## **🎲 骰池**

:::

:::: center

::: table

| 检定 | 骰池 |
|---|---|
| 技能检定 | 技能等级＋关联属性 |
| 属性检定 | 只算属性 |

:::

::::

骰池里放一颗异色骰当**愤怒骰**。

奖励骰由天赋、能力或情势追加，直接进池。

详见原书 p.159。

## **🎯 难度**

:::

:::: center

::: table

| 调整 | 难度值 | 档位 |
|---|---|---|
| −2 | 1 | 容易 |
| 无 | 3 | 标准 |
| +2 | 5 | 有挑战 |
| +4 | 7 | 困难 |
| +6 | 9 | 极难 |
| +9 | 12 | 几乎不可能 |

:::

::::

标准检定的难度值是 **3**。

减值永远加在难度上，写法是「+X 难度」。

加成永远是加骰，不改难度。

详见原书 p.160–161。

## **🎰 掷骰结果**

:::

:::: center

::: table

| 骰面 | 计数 |
|---|---|
| 4–5 | 1 个图标 |
| 6 | 崇高图标，算 2 个 |

:::

::::

图标总数达到难度值，检定成功。

崇高图标还能拿去**移用**，见下块。

详见原书 p.159。

## **🔥 愤怒骰**

:::

:::: center

::: table

| 骰面 | 效果 |
|---|---|
| 1 | 变故 |
| 2–5 | 无特殊效果，照常计数 |
| 6 | 愤怒暴击，团队 +1 荣耀 |

:::

::::

愤怒骰占骰池一员，照常计图标。

骰面 1 或 6 的效果==成败都触发==。

攻击检定掷出愤怒暴击且命中，改为触发暴击。

主持人可以宣布某次检定不出愤怒效果。

详见原书 p.162–163。

## **✨ 移用**

:::

::: card

把崇高图标从结果里拿出来，换一份效果。

前提：拿走之后，剩下的图标仍然达到难度值。

- **追加伤害**——攻击时每个移用 +1 ED（额外伤害骰）
- **增添荣耀**——移 1 个进团队池，每检定限一次
- **获得情报**——1 个移用换 1 条相关答案
- **提升品质**——不只成功，还做得漂亮
- **加快速度**——每移用 1 个，耗时约减半

:::

移用愤怒暴击那颗骰时，+1 荣耀与暴击==照常生效==。

详见原书 p.165–166。

## **💎 资源点**

:::

:::: center

::: table

| 资源 | 归属与开局 | 赚取 | 花费 |
|---|---|---|---|
| **愤怒点** | 个人<br>每场 2 点 | 达成目标<br>主持人奖励 | 重掷失败骰<br>叙事宣告<br>恢复震荡 |
| **荣耀** | 团队<br>开局 0 点 | 移用崇高图标<br>愤怒暴击 | 骰池加骰<br>伤害每点 +1<br>加重暴击<br>抢占先机 |
| **毁灭** | 游戏主持人<br>开局＝人数 | 主持人侧获取 | 主持人侧消耗 |

:::

::::

重掷失败骰＝把结果里所有 1、2、3 重掷，每检定限一次。

掷出变故的那颗愤怒骰不可重掷。

恢复震荡的量＝阶位＋层级。

荣耀池上限＝6 或人数 +2，取高。

详见原书 p.162–165。

## **⚖️ 对抗检定**

:::

::: card

双方各掷各的，==图标多者胜==。

一方吃的减值，改成对手的奖励骰。

平局算发起方赢。

默认不放愤怒骰，想引入变故才放。

:::

详见原书 p.170。

::: card

:::

详见原书 p.169–170。

## **🧭 关键词**

:::

::: card

关键词是出身与人脉的简写。

它能让相关检定更容易，也是买天赋、吃能力的资格。

影响力检定须与对象共享至少 1 个关键词。

每多共享 1 个，==+1 奖励骰==。

掷完还能行贿：每 1 点财富 +1 图标。

:::

全关键词表见原书 p.375，本块规则在 p.167–169。
