## **🐾 这是什么游戏**

:::

:::: card

《魔法猫猫救世界》（Magical Kitties Save the Day）是 Atlas Games 出版的全龄向角色扮演游戏，四到六人同玩最合适，其中一人担任游戏主持人（GM）。

危险无处不在，而人类毫无察觉，守护他们的正是藏在人类身边的魔法猫猫。

==游戏没有胜负==，大家协作讲述猫猫们的故事，帮自己选中的人类解决问题，把剧集一路讲下去。

会数到 `6` 并且能比较数字大小，就能处理游戏里的全部计算，小朋友和成年人可以同桌同乐。

::: note 身为魔法猫猫

- **隐藏力量**——必须在人类面前隐藏魔法力量，女巫这类知情者面前才可放开用
- **单向理解**——你能听懂人类的话，但他们听不懂你
- **动物之交**——能和其他动物交谈，读懂人类文字要过机敏检定而且常常出错
- **秘密据点**——家里有个人类不知道的地点，可以从那里进出家门

:::

## **🎲 核心检定**

:::

:::: card

日常小事不用掷骰，只有棘手或危险的事才要检定，由 GM 宣告用哪项属性、难度是多少。

---

**骰池构成**

::: table

| **来源** | **骰子** |
|---|---|
| `可爱`／`机敏`／`迅猛` 属性 | +1 至 +4 |
| `天赋` | +1 |
| `魔法力量`（每场景一次） | +2 |
| 上次的成功奖励 | +1 |
| 每个 `伤口` | -1 |

:::

骰池归零时这项属性就不能掷骰了。

---

**难度**

难度从 `3` 到 `6`，拿不准就取 `4`。

难度 `1` 和 `2` 的检定不存在，那么简单的事直接成功。

结果大于等于难度的骰子，算一个成功骰。

::: table

| **难度** | **参考** |
|---|---|
| 3（简单） | 让人类喂你、捉老鼠 |
| 4（普通） | 找到隐藏隔间、交新朋友 |
| 5（困难） | 智胜女巫、穿过火场 |
| 6（极难） | 说服敌人改主意、闯入要塞 |

:::

---

**成功骰分级**

::: table

| **成功骰** | **结果** |
|---|---|
| 0 | 失败，遭遇一场`节外生枝` |
| 1 | 成功但付代价，仍遭遇一场`节外生枝` |
| 2 | 事情如愿以偿 |
| 3 | 成功，另获一个`奖励` |
| 4+ | 超级成功，得到更有用的`超级奖励` |

:::

`节外生枝`的常见形态：承受 `1` 点`疼痛`、敌人使用反应、陷入困境、短暂无法行动、下次掷骰少一骰、被 GM 要求按`缺陷`行事。

`奖励`的常见形态：给同伴下次掷骰加一骰、消一点`疼痛`、顺带达成次要目标、让某个敌人暂时消停。

## **🐱 创造猫猫**

:::

::::::: steps

1. **描述你的猫猫**

:::: card

给猫猫起名（人类叫的名字和猫猫之间的名字可以不同），写下外貌、来历和性格。

::::

2. **记下起始数值**

:::: card

`疼痛极限`记 `2`，`猫粮丸`记 `2`，等级记 `1`。

::::

3. **分配属性**

::::: card

三属性`可爱`（社交）、`机敏`（头脑）、`迅猛`（体力），把 `3`、`2`、`1` 各分配一项，也可以掷骰随机。

:::: details 属性随机表

::: table

| **掷骰** | **分配** |
|---|---|
| 1 | `可爱` 3／`机敏` 2／`迅猛` 1 |
| 2 | `可爱` 3／`机敏` 1／`迅猛` 2 |
| 3 | `可爱` 2／`机敏` 3／`迅猛` 1 |
| 4 | `可爱` 2／`机敏` 1／`迅猛` 3 |
| 5 | `可爱` 1／`机敏` 3／`迅猛` 2 |
| 6 | `可爱` 1／`机敏` 2／`迅猛` 3 |

:::

::::

:::::

4. **选一项天赋**

:::: card

`天赋`是现实中猫猫也可能擅长的本领，比如黑夜视觉、天生舞者、福尔喵斯，检定时额外加一骰。

可以自选、掷表决定，或和 GM 一起自创新天赋。

::::

5. **选一项缺陷**

:::: card

`缺陷`是猫猫的缺点，例如胆小如鼠、馋嘴猫眯、性格内向。

把缺陷玩得有趣、让故事更好玩，GM 就会奖励`猫粮丸`。

::::

6. **选一项魔法力量**

:::: card

`魔法力量`让猫猫做到现实中不可能的事，三十六项见下节。

::::

7. **选择你的人类**

:::: card

写下你最想帮助的人类，再为他选定起始`问题`，级别共 `4`——一个大问题，或若干合计为 `4` 的小问题。

::::

## **🪄 魔法力量**

:::

:::: card

用魔法力量做检定时骰池加 `2` 骰，==每个场景限一次==，但力量本身在故事里可以随意描述。

升级时可以给力量选购`额外特性`扩展用法，也能花一枚`猫粮丸`临时借用一项还没拿到的额外特性。

力量可以自创，和 GM 商量调整即可。

::: details 三十六项魔法力量一览

- **拟态之身**——身体化为指定固体并获得其特性
- **弹性十足**——跳跃或被抛出时像球弹起，普通跌落不受伤
- **遁地高手**——以步行速度在泥土类物质里掘洞穿行
- **两栖猫鱼**——水下呼吸、游泳自如，可以长出鱼尾
- **惟喵惟肖**——创造共享记忆的复制体，触碰可重新合体
- **猫体雷达**——感应五十英尺内特定物品的远近方位
- **梦境旅者**——入定观看熟睡之人的梦境
- **能量偏转**——把接触到的能量攻击偏转开而不受伤
- **绝对力场**——力场泡护住自己，阻挡物理穿透
- **冰霜之息**——呼出寒风，吹得翻小物、冻得住液体
- **如猫添翼**——飞上天空，载重与步行时相同
- **妙爪回春**——移除自己或同伴的一处`疼痛`或`伤口`
- **催眠大师**——催眠一只动物，让它做不危险的事
- **构建幻象**——造出看得见摸不着的单个幻象
- **隐形匿影**——隐去身形，但声音气味与携带物仍在
- **镭射猫眼**——眼中射出激光，强度从光点到切割木头
- **意识投射**——控制视野内一只非人生物，本体瘫倒
- **无效能力**——无效化他人的魔法力量和持续效果
- **穿越固体**——独自穿过固体，不能带人带物
- **火焰操纵**——意念造出并控制篝火大小的火焰
- **影子形态**——融入影子自由移动，但无法物理互动
- **千变万化**——变成体型一半到两倍的陆地动物，不能变人
- **尽收眼底**——看见全城任意地点此刻发生的事
- **放缩随心**——缩到仓鼠那么小，或长到老虎那么大
- **模仿之声**——制造自然声响，或让声音听起来像别的东西
- **伸缩自如**——身体任意部位伸长到接近成人身高
- **超强感官**——变焦视物，兼有夜视与红外视觉
- **超级速度**——以接近音速奔跑，不能搭载其他猫猫
- **洪荒猫力**——轻松举起约一匹马重的物体
- **科技奇客**——意念操控电子机器，可与智能机器对话
- **物随心动**——意念移动一个小物体
- **心灵感应**——听见其他生物此刻在想什么
- **瞬间移动**——传送到同房间约二十英尺内的可见处
- **时间停止**——让除自己外的所有生物静止约一分钟
- **不死之躯**——介于生死之间，被一种非自然的饥渴驱使
- **噼里啪啦**——操控电流，爪间放小闪电或给电器供电

:::

## **🍖 猫粮丸与疼痛**

:::

::::: card-grid

:::: card

::: center

**猫粮丸 🍪**

:::

每个章节开始时拿取等同`猫粮丸`数值的指示物（新猫为 `2`），用不完的不能带进下一章节。

- **重骰**——检定中重掷骰池里的任意或全部骰子
- **免伤**——避免获得一个`伤口`
- **借力**——临时使用一项力量还没有的`额外特性`
- **添笔**——往故事里加入猫猫掌控之外的东西，需 GM 同意

把`缺陷`玩得有趣，GM 会再给一枚，但不是每次提及都给。

::::

:::: card

::: center

**疼痛与伤口 🩹**

:::

新猫的`疼痛极限`为 `2`，极限之内的`疼痛`只做记录，没有惩罚。

疼痛达到极限后再吃一次疼痛，就改记一个`伤口`，并且骰池减一骰。

`伤口`数量等于最高属性时（初始猫猫为 `3`），猫猫`失能`，本场景出局。

**恢复途径**

- **时间**——获得伤口的场景结束时，恢复一个`伤口`
- **奖励**——`奖励`消`疼痛`，`超级奖励`连`伤口`也能消
- **魔法**——治疗系魔法力量一次消 `1` 到 `2` 处
- **重置**——新章节开始时经 GM 同意，全部清零

## **📈 经验与升级**

:::

:::: card

检定失败本身就值 `1` 点经验点——但用`猫粮丸`重骰翻盘的那次不算。

每个章节结束，全桌一起回答故事结束问题：

::: table

| **故事结束问题** | **经验点** |
|---|---|
| 猫猫拯救了世界吗？ | +1 |
| 大家玩得开心吗？ | +1 |
| 猫猫或人类吸取了宝贵教训吗？ | +1 |
| 你在某次检定中失败了吗？ | 每次失败 +1 |
| 你的人类或家园的问题变好还是变糟了？ | 级别变化 -3 至 +3 |

:::

升级时从对应档位的列表选一项，同一列表里一项不能重复选，也可以回头选低档位里还没选过的项。

- **2-4 级**——力量加`额外特性`／单项属性 +1（上限 `3`）／`疼痛极限` +1／`猫粮丸` +1
- **5-7 级**——同上，外加获得一项新`天赋`，属性上限提到 `4`
- **8-10 级**——同上，外加获得一项新`魔法力量`

升级所需经验点从 2 级的 `5` 点起步，之后每级 `6` 到 `9` 点逐级递增。

## **🏰 带团指引**

:::

:::: card

只有当失败有趣时才要求掷骰，想不出有意思的失败，就直接让猫猫成功。

场景、章节、冒险、剧集是四层故事单位——场景是同一地点的一个目标，章节是一次游戏，冒险讲完一个完整故事，剧集是长期连载。

### **问题与级别 🏠**

:::

:::: card

每个人类带着级别共 `4` 的`问题`开场，故乡也有由 GM 记录的`故乡问题`，级别 `1` 到 `4` 代表它要跨多少章节。

每个章节结尾结算问题级别：普通进展 `-1`，大胜可 `-3`，搞砸或置之不理则上升 `1` 到 `3` 级。

级别降到 `0` 问题解决。

人类的所有问题清零即被拯救，剧情可以顺势开启新篇章。

把`故乡问题`和某个`人类问题`设计成互为因果，一次冒险就能同时推动两条线，失败也会两头恶化。

### **冒险配方 📜**

:::

:::: card

创造冒险六步：选一个`故乡问题`、选一个`人类问题`、把两者联系起来、设计冒险引子、挑一个冒险配方、融合成章。

- **过关斩将**——三到五个敌人挡在路上，逐个突破后对决`大坏蛋`
- **五个场景**——首威胁、谜题、扮演、诡计、大结局各占一景
- **简单谜题**——引子、三个场景、结局，场景之间用线索串联
- **突入险境**——画一张看得懂的地图，筹备、突袭，防守方随机应变
- **救援行动**——困境角色、危机列表，失败就走迂回路线

想让猫猫们注意到什么，就至少铺三条线索，这就是三线索法则。

### **敌人与灾难 👹**

:::

:::: card

敌人数据由`疼痛极限`加三个难度组成——`可爱`、`机敏`、`迅猛`难度是玩家对抗时要达标的目标值，不代表敌人自身的能力。

始终由玩家掷骰，敌人不掷。

疼痛达到极限的敌人就被击败，晕倒、被抓、吓跑都算。

敌人强度介于下限松鼠（极限 `1`，三难度全 `3`）与上限巨龙（极限 `5`，三难度全 `6`）之间，创造新敌人时照相近类型微调即可，也可以直接塞给它一项`魔法力量`。

`灾难`是野火、诅咒、闹鬼、地震这类事件形态的挑战：没有`疼痛极限`，只有一个难度加一组反应。

小灾难撑几个场景，大灾难可以就是`故乡问题`本身。
