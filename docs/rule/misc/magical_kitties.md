## **🐾 这是什么游戏**

:::

:::: card

《魔法猫猫救世界》（Magical Kitties Save the Day）是 Atlas Games 出版的全龄向角色扮演游戏，四到六人同玩最合适，其中一人担任游戏主持人（GM）。

危险无处不在，而人类毫无察觉，守护他们的正是藏在人类身边的魔法猫猫。

==游戏没有胜负==，大家协作讲述猫猫们的故事，帮自己选中的人类解决问题，把剧集一路讲下去。

会数到 `6` 并且能比较数字大小，就能处理游戏里的全部计算，小朋友和成年人可以同桌同乐。

::: note 身为魔法猫猫

- **隐藏力量**——必须在人类面前隐藏魔法力量，女巫这类知情者面前才可放开用
- **单向理解**——你能听懂人类的话，但他们听不懂你
- **动物之交**——能和其他动物交谈，读懂人类文字要过机敏检定而且常常出错
- **秘密据点**——家里有个人类不知道的地点，可以从那里进出家门

## **🎲 核心检定**

:::

:::: card

日常小事不用掷骰，只有棘手或危险的事才要检定，由 GM 宣告用哪项属性、难度是多少。

---

**骰池构成**

::: table

| **来源** | **骰子** |
|---|---|
| `可爱`／`机敏`／`迅猛` 属性 | +1 至 +4 |
| `天赋` | +1 |
| `魔法力量`（每场景一次） | +2 |
| 上次的成功奖励 | +1 |
| 每个 `伤口` | -1 |

:::

骰池归零时这项属性就不能掷骰了。

---

**难度**

难度从 `3` 到 `6`，拿不准就取 `4`。

难度 `1` 和 `2` 的检定不存在，那么简单的事直接成功。

结果大于等于难度的骰子，算一个成功骰。

::: table

| **难度** | **参考** |
|---|---|
| 3（简单） | 让人类喂你、捉老鼠 |
| 4（普通） | 找到隐藏隔间、交新朋友 |
| 5（困难） | 智胜女巫、穿过火场 |
| 6（极难） | 说服敌人改主意、闯入要塞 |

:::

---

**成功骰分级**

::: table

| **成功骰** | **结果** |
|---|---|
| 0 | 失败，遭遇一场`节外生枝` |
| 1 | 成功但付代价，仍遭遇一场`节外生枝` |
| 2 | 事情如愿以偿 |
| 3 | 成功，另获一个`奖励` |
| 4+ | 超级成功，得到更有用的`超级奖励` |

:::

`节外生枝`的常见形态：承受 `1` 点`疼痛`、敌人使用反应、陷入困境、短暂无法行动、下次掷骰少一骰、被 GM 要求按`缺陷`行事。

`奖励`的常见形态：给同伴下次掷骰加一骰、消一点`疼痛`、顺带达成次要目标、让某个敌人暂时消停。

## **🐱 创造猫猫**

:::

::::::: steps

1. **描述你的猫猫**

:::: card

给猫猫起名（人类叫的名字和猫猫之间的名字可以不同），写下外貌、来历和性格。

::::

2. **记下起始数值**

:::: card

`疼痛极限`记 `2`，`猫粮丸`记 `2`，等级记 `1`。

::::

3. **分配属性**

::::: card

三属性`可爱`（社交）、`机敏`（头脑）、`迅猛`（体力），把 `3`、`2`、`1` 各分配一项，也可以掷骰随机。

| 3 | `可爱` 2／`机敏` 3／`迅猛` 1 |
| 4 | `可爱` 2／`机敏` 1／`迅猛` 3 |
| 5 | `可爱` 1／`机敏` 3／`迅猛` 2 |

### **拟态之身 🪨**

:::

:::: card

把身体变成事先指定的某种物质，大小形态不变、照常行动，并获得该物质的硬度和重量。

一开始只能模拟木头、石头、金属这类固体，携带的物品不跟着转变。

---

**额外特性**

- **固态之身**——可随心变成任何接触过的固态物质，不限于最初指定的一种
- **液态之身**——可变成任意接触过的液体，比如水、树汁、牛奶
- **气态之身**——变成猫猫大小的气团，无毒可见，能挤过任何不气密的缝隙

::::

---

::: center

### **弹性十足 🏀**

:::

:::: card

跳跃或被抛向物体表面时，像橡胶球一样弹起来，可以团成球或鼓成气球配合弹跳。

普通弹跳不会带来疼痛，但从极高处坠落或被`洪荒猫力`抛出仍然会受伤。

---

**额外特性**

- **无限坠落**——任意高度坠落、任意力度抛出都能安然弹起，检定失败时 GM 也不能拿疼痛当节外生枝
- **超高弹力**——反弹时越弹越快，累积多次后能接近`超级速度`的水平

::::

---

::: center

### **遁地高手 🕳️**

:::

:::: card

以正常步速在泥土或类似物质里掘洞前行，像蚯蚓一样把废土堆在身后，隧道随手闭合不留痕迹。

---

**额外特性**

- **开放隧道**——可以选择在身后留一条开放隧道，让同伴随行
- **岩石挖掘**——坚固的岩石和混凝土也能掘洞穿行

::::

---

::: center

### **两栖猫鱼 🐟**

:::

:::: card

完全的两栖动物，能在水下呼吸，游泳像其他猫猫走路一样轻松，碰到水还可以长出鱼尾。

---

**额外特性**

- **超级泳者**——泳速媲美`超级速度`猫猫的奔跑，只在水中生效，还能借`超级速度`的额外特性再加强
- **操纵水流**——意念指挥约一桶量的水，可悬浮半空、听令急移
- **操纵水体**——可控范围大到游泳池级别（须先获得`操纵水流`）

::::

### **惟喵惟肖 👥**

:::

:::: card

创造一个完美复制体，分享你全部的记忆和经历，甚至可能为谁本体谁复制品争执不休。

触碰复制体就能重新合二为一，并获得它分离期间的所有记忆。

复制前已有的疼痛和伤口复制体同样带着，合体时按伤痛最少的个体计算。

---

**额外特性**

- **我即猫群**——最多同时拥有六个复制体
- **一猫成军**——复制体数量不再受限（须先获得`我即猫群`）
- **灵魂链接**——与所有复制体心电感应，随时知晓彼此方位、自由精神交流

### **猫体雷达 📡**

**疼痛与伤口 🩹**

:::

新猫的`疼痛极限`为 `2`，极限之内的`疼痛`只做记录，没有惩罚。

疼痛达到极限后再吃一次疼痛，就改记一个`伤口`，并且骰池减一骰。

- **时间**——获得伤口的场景结束时，恢复一个`伤口`
- **奖励**——`奖励`消`疼痛`，`超级奖励`连`伤口`也能消
- **魔法**——治疗系魔法力量一次消 `1` 到 `2` 处
- **重置**——新章节开始时经 GM 同意，全部清零

## **📈 经验与升级**

:::

:::: card

检定失败本身就值 `1` 点经验点——但用`猫粮丸`重骰翻盘的那次不算。

每个章节结束，全桌一起回答故事结束问题：

::: table

| **故事结束问题** | **经验点** |
|---|---|
| 猫猫拯救了世界吗？ | +1 |
| 大家玩得开心吗？ | +1 |
| 猫猫或人类吸取了宝贵教训吗？ | +1 |
| 你在某次检定中失败了吗？ | 每次失败 +1 |
| 你的人类或家园的问题变好还是变糟了？ | 级别变化 -3 至 +3 |

:::

升级时从对应档位的列表选一项，同一列表里一项不能重复选，也可以回头选低档位里还没选过的项。

- **2-4 级**——力量加`额外特性`／单项属性 +1（上限 `3`）／`疼痛极限` +1／`猫粮丸` +1
- **5-7 级**——同上，外加获得一项新`天赋`，属性上限提到 `4`
- **8-10 级**——同上，外加获得一项新`魔法力量`

升级所需经验点从 2 级的 `5` 点起步，之后每级 `6` 到 `9` 点逐级递增。

### **问题与级别 🏠**

:::

:::: card

每个人类带着级别共 `4` 的`问题`开场，故乡也有由 GM 记录的`故乡问题`，级别 `1` 到 `4` 代表它要跨多少章节。

每个章节结尾结算问题级别：普通进展 `-1`，大胜可 `-3`，搞砸或置之不理则上升 `1` 到 `3` 级。

级别降到 `0` 问题解决。

人类的所有问题清零即被拯救，剧情可以顺势开启新篇章。

把`故乡问题`和某个`人类问题`设计成互为因果，一次冒险就能同时推动两条线，失败也会两头恶化。

### **冒险配方 📜**

:::

:::: card

创造冒险六步：选一个`故乡问题`、选一个`人类问题`、把两者联系起来、设计冒险引子、挑一个冒险配方、融合成章。

- **过关斩将**——三到五个敌人挡在路上，逐个突破后对决`大坏蛋`
- **五个场景**——首威胁、谜题、扮演、诡计、大结局各占一景
- **简单谜题**——引子、三个场景、结局，场景之间用线索串联
- **突入险境**——画一张看得懂的地图，筹备、突袭，防守方随机应变
- **救援行动**——困境角色、危机列表，失败就走迂回路线

想让猫猫们注意到什么，就至少铺三条线索，这就是三线索法则。

### **敌人与灾难 👹**

:::

:::: card

敌人数据由`疼痛极限`加三个难度组成——`可爱`、`机敏`、`迅猛`难度是玩家对抗时要达标的目标值，不代表敌人自身的能力。

始终由玩家掷骰，敌人不掷。

疼痛达到极限的敌人就被击败，晕倒、被抓、吓跑都算。

敌人强度介于下限松鼠（极限 `1`，三难度全 `3`）与上限巨龙（极限 `5`，三难度全 `6`）之间，创造新敌人时照相近类型微调即可，也可以直接塞给它一项`魔法力量`。

`灾难`是野火、诅咒、闹鬼、地震这类事件形态的挑战：没有`疼痛极限`，只有一个难度加一组反应。

小灾难撑几个场景，大灾难可以就是`故乡问题`本身。
