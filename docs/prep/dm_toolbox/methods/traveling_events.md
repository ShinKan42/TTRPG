## **🎯 这是什么**

:::

::: card

**旅行事件系统**（Traveling Event System，TES）是一套==故事优先==的旅行规则，来自 [Pointy Hat](https://www.youtube.com/@ThePointyHat) 的社区设计（[原文档](https://docs.google.com/document/d/e/2PACX-1vQ7lvWaIR7WlkzJHuqjpbQuDKX0iX9MFQNXJ6tW3YftmnEh8e03tzFvXBxrkloVW-6bTp5up4pgUjqr/pub)｜[原视频](https://www.youtube.com/watch?v=vM18P0WKGFA)）。

它解决旅行在桌上两头不讨好的老问题：拟真派规则要按步速算里程、管口粮，繁琐；不管它，旅行就退化成一句「你们走了三天到了」。TES 的解法是==用事件数丈量旅程==——每段路按远近撞上几件 DM 有意安排的事，事件走完，队伍到达。

原文明确声明：这套系统==不管口粮配给、不管每日脚程==。它要复现的是旅行题材作品里「在路上」的戏剧感，不是真实行军的账目。里程与补给的拟真推演留给 DM 自己的时历轴，TES 承担的是==旅行的桌上呈现==这一层。

:::

## **📜 使用守则**

:::

::: card

- **数字是指南不是铁律**：原文鼓励改动事件数——想让一段路显得漫长就加事件，剧情需要时短路也能撞上大事。「这段旅程该是什么感觉」比「地图上多少里」更重要。
- **事件全部出自 DM 的手**：TES 没有随机表。每个事件都是==提前设计==的，可以和主线、支线、伏笔直接挂钩——这是它区别于随机遭遇表的核心。
- **与拟真层分工**：口粮、脚程、天气、补给按 DM 自己的世界法则推（时历轴），TES 只管「路上发生什么戏」。

:::

## **🧭 核心机制**

:::

::: card

旅程按远近分三档，每档对应固定的==事件数==：

:::: table

| 距离档 | 事件数 | 撞完之后 |
|:--:|:--:|:--|
| 近 Close | 1 件 | 到达目的地 |
| 远 Far | 2 件 | 到达目的地 |
| 非常远 Very Far | 3 件 | 到达目的地 |

::::

距离档==不设官方里程==——「近」可以是 10 公里也可以是 30 公里，由 DM 按地图自行估断：在地图上大致量出路程，就知道这趟旅程有几个事件。事件撞满，旅程结束，队伍抵达。

:::

## **🎨 事件三类**

:::

::: card

事件分三大类，原文给每类配了一种==地图标注色==，DM 可在地图上直接标记引用。

**🔴 战斗事件（红）**——路上的战斗场景。因为是==有意放置==的，可以承载剧情：它可以是主线反派的正面登场、宿敌的寻仇，或展示一方水土的怪物生态；也能在一长段扮演之后把桌上节奏拉起来。随机遭遇表给不了这种剧情贴合度。

**🔵 扮演事件（蓝）**——路上的社交与叙事场景：遇到新 NPC、一场高压谈判，或一次文化礼节的碰撞。扮演事件==不需要像战斗那样平衡==，赌注可以直接压到与生死同级的长度——谈崩的代价可以远比一场战斗重。它也是展示世界文化面的最好位置：世界观不只是地理和怪物，还有各地的规矩与禁忌。

**🟡 探索事件（黄）**——路上的地形与险境，把镜头从人和怪物转向==大地本身==：幻想地貌成为可以互动、必须设法穿越的实体。它让生存、隐匿、驯兽、载具这类==冷门技能==拿到高光，也是引入==技能挑战==（Skill Challenge）的天然入口。

:::

---

::: card

**示例场景**（原文示例的全量重述，DM 可直接搬用或改写）：

- **红 · 切磋**：主线反派终于注意到队伍，亲自到野外拦路，以「友好」切磋的名义试探队伍成色。
- **红 · 寻仇**：几周前被队伍骗光的宿敌找了上来，一言不合开打。
- **红 · 灭口**：反派的探子摸到了队伍行踪——不想消息送进反派耳朵里，就得用任何手段把探子留下来。
- **红 · 越界**：树上那些精致刻痕其实是一只怪物的领地界标，队伍没有理会警告。
- **蓝 · 同路相争**：遇到一支目标高度重合的冒险队伍——一场贯穿整个战役的竞争关系就此展开。
- **蓝 · 马车邀茶**：队伍撞上护送鎏金马车的骑士队，车内的大贵族邀队伍上车喝茶，开出一个==难以拒绝==的价码。
- **蓝 · 亡者之地**：队伍误入亡魂无法安息的地界——某种邪法困住了所有过路者。要让困于此地的亡灵帮忙，先说服它们。
- **蓝 · 「一点人情」**：行商主动凑上来，货价低得反常；每次问价，他都轻描淡写补一句——「一些金币，外加一个人情」。
- **黄 · 吊桥**：深谷上一座摇摇欲坠的旧桥，横在队伍和目的地之间。
- **黄 · 分海古道**：千年前法师分开海水铺出的跨海古道，法力正在逐年衰减——两侧水墙不时喷出水柱，而水下的怪物已经学会==借水柱袭击过路人==。
- **黄 · 活的山**：寻常山峰缓缓睁开眼——那是一头龙龟的背。整片森林随之震颤，队伍要做的第一件事是从一座==会跑的山==上下来。
- **黄 · 人手乌鸦**：旧战场上方，长着人手的乌鸦俯冲而下，眨眼叼走队伍一件珍视之物——追得上、骗得过，才拿得回来。

## **🌈 组合事件**

:::

::: card

一件事可以同时属于两类甚至三类——原文称==组合事件==，用混色标注，用来给旅程增加多样性：可以从一类演变成另一类，也可以同时具备两类的特征。

- **🟣 紫 · 扮演转战斗**：队伍来清算作恶的鬼婆，她开口就用一件==直指某位成员个人目标==的宝物换自己的命——放她走，宝物到手；动手，她保证宝物先毁。事件从扮演开场，走向由队伍的选择决定。
- **🟢 绿 · 探索带扮演**：废弃矿坑里遇到一只迷路的狗头人——它极度警惕；若能交上朋友，它能熟练操纵矿车，把队伍==载出矿坑==。
- **🟠 橙 · 探索加战斗**：把某个邪灵封在庄园里的三件器物散落各处，队伍要==边探索边接战==——灵体不断现形突袭又消散。
- **⚪ 白 · 三合一**：彻底黑化的宿敌据守古堡，掳走了队伍珍视的 NPC 准备献祭。谈判救人、强攻灭队、潜入营救——三条路都通，全队自己选。

:::

## **🎲 上桌使用**

:::

::: card

- **备团时**：量地图定距离档 → 按档定事件数 → 逐个挑事件（或自写），==在地图上用颜色标出事件点==，带团时一眼可查。
- **带团时**：事件可以在任意节奏抛出——刚出发撞第一件，赶路途中穿插余下几件；事件顺序不设限制。
- **节奏阀**：扮演段太长就放一个战斗或探索事件提节奏；连续赶路的单调感本身就是该加事件==的信号==。

:::
