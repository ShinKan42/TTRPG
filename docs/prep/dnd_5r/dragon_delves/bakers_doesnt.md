::: center
#### <a id="bg-candy"></a>糖果生物 Candy Creatures
:::

- **形态改变非数据改变**——变成糖果生物不影响数据：糖果护甲与正常护甲同样坚韧，糖果武器同样致命
- **连带变形**——所着装或携带的非魔法物品一起变形
- **不会变老**——糖果形态下生物不衰老（艾斯格数十年停留童年形态的原理）
- **复原途径**——`高等复原术` Greater Restoration / 吧唧脸死亡（全体复原）/ 鬼婆魔法动作触摸变回 / 讲和交易变回 / **肉桂卷甜食唤醒（魔改新增）**
- **变形抗叠**——已是糖果生物再受糖果变形效应，不再变形但承受其余后果
- **食材属性包（魔改）**——糖果形态获得三条战术属性：

  | 属性 | 效果 |
  |---|---|
  | **怕热** | 受到的火焰伤害 ×2（C10 烤炉区成为高压区） |
  | **脆化** | 受到的钝击伤害额外 +1d4 |
  | **可被吞咬** | 鬼婆与糖果生物命中糖果形态目标时附带「咬下一块」：额外 1d4 嚼食伤害；被吞咬至 0 HP = 被吃掉 |
- **糖果无血肉（魔改）**——糖果形态免疫`中毒`状态与毒素伤害、免疫出血类效果——唯一的补偿面
- **甜食唤醒（魔改新增解法）**——菲尔的肉桂卷对糖果生物同样有效：展示并喂食=解除糖果形态；三块肉桂卷=一块留给龙的诱饵、两块随身解药——救龙还是救人，打不起消耗

::: details **糖果生物规则——原文**
**糖果生物 Candy Creatures**

小屋之内的某些效应可以改变生物的形态，连带其所着装或携带的非魔法物品也一起变形，使其变为活化糖果生物。当某个角色变成糖果生物时，文本将会注明对应糖果的种类。处于糖果形态时的生物不会变老，此外该变形对生物数据无影响。糖果护甲将与同种正常护甲同样坚韧，糖果武器也与原来的武器一样锋利致命。被释放高等复原术 Greater Restoration 或者吧唧脸叔叔死亡时，糖果生物会变回正常形态。该鬼婆可以执行一个魔法动作将他所触摸的一名生物变回来。若一名已变成糖果的生物受到另一项使其转变糖果生物的效应影响，该生物并不会再次变形，但将如常承受其它所有后果。
:::

**收集线索 Gathering Clues**

在糖果店的废墟中或者废墟附近，角色们能够收集到下述线索。

**烧焦的肉桂卷 Burnt Roll 。一名执行搜索动作并成**

功通过 DC12 感知（察觉）检定的角色可以在糖果店后面的草地上发现一根被咬了一半的，略微烧焦的肉桂卷。在村子里到处打听，或者在发现肉桂卷后执行研究动作并成功通过 DC12 智力（历史）检定可以发现这肉桂卷是当地一位名叫菲尔·粉福吉的矮人开的面包房（见“菲尔的面包房”）做的。

**家庭画像 Family Portrait 。在糖果店内部（如果糖**

果店烧毁了那就是在废墟里）进行搜索的角色可以找到一张被烧变色了的画像，上面画着小时候的艾迪丝与她弟弟艾斯格。如果把画还给艾迪丝，她会悲伤落泪并解释道，当她还是个小女孩的时候，她的弟弟“消失在了森林之中，再也没有回家”。她并不会作太多详细叙述。

**不正当竞争 Foul Play 。如果艾迪丝或者某位其他村**

民被强迫指认一名嫌疑人的话，则艾迪丝或该村民将不情不愿地把当地一位面包师菲尔·粉福吉供出来，他可能会受益于村里甜品供应的垄断地位。

**不可靠的目击证人 Unreliable Witness 。若角色们想**

从旁观者之中找目击证人，有一位不太可靠的，喝醉酒的人类女性会声称她见到一条“金蜥蜴”在着火之后飞进了森林。这位名叫皮特拉·希尔芙 Peetra Sylver 的目击证人随后便会大声骂道当时自己还被穴蜥人绑走了，但根本没人相信她。

若角色们救出艾斯格，他们可能会决定让艾斯格与艾迪丝重聚，或者为艾斯格找个新家。艾斯格可能的结局如下：

**为艾斯格找个新家 Finding Asger a New Home 。若角**

色们跟菲尔讲起有关艾斯格的事，这位矮人面包师愿意收养他。算上奶油金卷，尽管他们三个不怎么像是一家人，但从此以后还是过上了幸福快乐的生活。

若角色们将艾斯格送回到艾迪丝身边，这位年长的糖果商在看到弟弟第一眼时会皱起眉头，因为弟弟自从他们一起进入森林以来一点也没有长大。艾迪丝的眼睛湿润起来，心里充满了懊悔，决定弃邪归正，亡羊补牢。艾迪丝兑现了她的承诺。

### 全场通用特征（糖果小屋）

- **天花板**——均高 10 尺（20 尺高的塔楼 C12 除外）；所有天花板覆有一层甜甜的糖霜
- **门**——所有门均为厚巧克力板，雕刻成木头般的粗糙质感；**均未上锁**，硬度与木板门相同
- **可食用物件**——小屋内所有属于吧唧脸的物品均由糖果制成（另有标注除外）；与不可食用的同种物件**同样坚韧且实用**
- **光照**——每间房有一盏球形口香糖魔法台灯提供明亮光照；吃掉口香糖或把它移出小屋都会熄灭光芒
- **外装糖果**——可随意食用装饰小屋的糖果；被吃掉的糖果**10 分钟后魔法性原地刷新**；品尝屋外糖果后产生想进小屋的强烈冲动（可抵抗）

个囚犯都已经只剩骨架，很明显是死了。艾斯格·苹果园是位精力充沛的半身人（小型平民 Commoner），被变成了糖果生物（见“糖果生物”），他坐在其中一个笼子里面，看起来像是淡粉色泡泡糖。艾斯格在数十年前被鬼婆变成了糖果，从此再也没有变老。艾斯格对角色们态度友善。当艾斯格注意到他们时，他将礼貌地请求角色们放他出来。若角色们善待艾斯格，那么他将透露下述信息：

**艾斯格的故事 Asger’s Story 。艾斯格和他的姐姐艾**

迪丝很久以前碰巧来到了这间小屋。他以为吧唧脸叔叔收留了他，但没有留下他姐姐。（艾斯格并不知道艾迪丝和鬼婆的契约。）

**小屋的主人 Cottage Owner 。这间小屋属于一位刻薄**

的老头，他只吃糖果，以及那些被他变成糖果的人们。这位鬼婆很久之前丢失了他那经常放错地方的假牙，而没有假牙他吃不了任何东西。

**厨房帮工 Kitchen Helper 。直至不久前，吧唧脸叔叔**

还在强迫艾斯格当他的厨房帮工，但在一连串烘焙事故之后，鬼婆便把他锁在了这里。艾斯格害怕自己是被取代了，很快就会被吃掉。

**骷髅 Skeleton 。艾斯格并不知道另一个笼子里面化作**

了骨架的囚犯是什么身份，他为这囚犯起了个“糖豆先生”的绰号。在给出这些信息之后，艾斯格会提议在路上陪同角色们。艾斯格对小屋很熟悉，并可以为角色们指出房间，虽然他有时候会忘记房间里面有什么生物。在战斗时，艾斯格会在保持安全距离处躲起来并为角色们加油鼓劲。若角色们拒绝艾斯格的提议，那么他将前往布霸·呜嘎的游戏室（区域 C3），并在冒险剩下的时间中留在那里。

**宝藏 Treasure 。糖豆先生握着一把+1 巨斧+1**

Greataxe 。

#### <a id="i-dust"></a>无踪粉 Dust of Disappearance
:::

- **是什么**——小包里的粉末，看起来像极细的沙，非普通奇物；只够用一次

  - 粉末在魔法生效时消耗掉

#### <a id="i-broom"></a>芭芭·雅嘎的舞空帚 Baba Yaga's Dancing Broom

- **是什么**——妖精领主芭芭·雅嘎打造的众多魔法扫帚之一（没有两把完全相同），非普通奇物，**需同调**

  - PC 回合可心灵命令 30 尺内的活化扫帚（未`失能`时，无需动作）：决定其行动与移动，或下达一般命令（攻击敌人/守卫地点）
  - 扫帚归零 HP→碎裂销毁；在失去全部 HP 前变回无生命形态→恢复全部 HP

#### <a id="i-scroll"></a>`高等复原术`法术卷轴 Greater Restoration

- **是什么**——5 环`防护`学派法术卷轴；施法者可用动作念卷轴文句施放
- **怎么用**——接触一个生物解除：一项属性吸收、一个魅惑状态的效应、`石化`状态，或一个诅咒（如木乃伊腐朽）；或解除一个目标身上使其`力竭`的效应，并使力竭等级降低 1
- **对本案卷**——可把糖果生物变回正常形态（糖果生物规则的两种复原法之一）；也是 C14 木乃伊腐朽诅咒的解药
- **位置**——C12 塔楼桌子抽屉
