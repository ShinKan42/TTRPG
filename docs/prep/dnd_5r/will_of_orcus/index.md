::: tip 银龙雏龙 Silver Dragon Wyrmling

- **银龙雏龙==——最友善的金属龙，本卷主角的种族==**

    - **龙生阶段**：雏龙，即真龙的幼年体（约 5 岁以下）
      - **体型**：体长与大型生物相当，还长不出成龙的体量
      - **奈扎鲁姆正处此段**：力量不足以正面对抗整支教团
        - 所以选了==欺骗==
    - **银龙天性**：十色金属龙里==最友善、最具社会性==的一支
      - 乐于援助有需要的善良生物
      - **这条天性是奈扎鲁姆全部行为的底**
        - 他不是在玩弄邪教徒取乐
        - **行为底色**：是一个善良生物用自己会的唯一办法（演技+恶作剧式命令）阻止恶事发生
    - **巢穴魔法效应（成龙版）**：随心==改变天气==；柔风托起龙与盟友缓缓飘降；云雾可凝成==如石般坚固==的构造
      - **巢穴效应**：雏龙的巢穴效应只是成龙的萌芽（见「⚙️ 全场机制」）
      - **寒雾**：即其天气操纵的幼儿版
    - **桌上会被问**：
      - **找家**：「他多大？」——雏龙期，且神殿数周的落脚期远不足以筑成真巢，他还在找家
      - **战力**：「他打得过希娅吗？」——单挑打不过，所以才需要玩家

::: tip 龙狂迷锁 Dracorage Mythal（感受层）

- **龙狂迷锁==——时代底色的本体，桌面上零说出口==**

    - **是什么**：费伦大陆一种覆盖广域的古老魔法仪式场（迷锁，即巨规模固定魔法效应）
      - **龙狂之祸**：历史上曾令全大陆的真龙集体陷入==龙狂==（疯狂屠戮同类与文明）的失控
      - **本条：DM 面知识**：桌面上不通过任何人之口说出——玩家只从现象感受与推理
    - **时代底色**：迷锁运作的纪元里，巨龙之间的战斗与躁动是常态
      - 龙类整体处于某种被驱使的不安中
    - **本章的表现位**（零点名、可推理）：
      - **物证**——奈扎鲁姆筑巢却==不敢定居==
        - **物证**：数周不睡、反复擦拭龙棋、把雕像内壁挠出细纹
        - **推力方向**：玩家看到的是==行为反常==，推力方向：「这条龙在躲什么」
      - **异象**——山里的雾==比往年早==（欧瑞安被问才答）
        - **习性**：雏龙本能地想筑巢、又本能地不敢久留
      - **真相层（你知）**——驱赶他的是迷锁时代的龙群躁动
        - **回收线**：本章不回答，不给名字；选集后期（成年章/远古章）此线再升
    - **桌上会被问**：「龙为什么这么躁？」——他自己也说不清，只会说「住不安稳」类的模糊话
      - 他说的是真话，他真的不明白

::: tip 奥喀斯 Orcus·不死魔君（生死注记）

- **奥喀斯==——本桌设定：神活着，教团在设法唤醒他现世==**

    - **是什么**：不死生物的恶魔领主
      - **身份**：无底深渊第 113 层的君主，形象：巨大的山羊头行尸
      - **教义**：==不死超越生命==，一切生者终将臣服于死亡
    - **本桌设定（DM 已裁）**：==奥喀斯活着，教团在寻求把他从深渊彻底唤醒现世==
      - **复活路线**：原版「寻求复活」的复活主题，本桌读作==迎神现世==的仪式工程，献祭祝圣就是唤醒流程的一环
      - **消息时滞**：教团在干什么、做到哪一步，外界几乎无人知晓
        - **求证皆过时**：灰水镇只当「邪教又回来了」，各地神职各持传闻版本——玩家求证任何外部来源得到的都是==过时答案==
    - **本桌注记**：官方 5e 现行设定里奥喀斯在无底深渊现役（MM/OotA），与本桌一致
      - **设定出处**：「被弑」线出自 3e 正典（恶魔领主科兰莎丽丝弑奥喀斯），本桌不取
      - **玩家如拿外部设定对质**：世界很大，深渊的事没人说得准
    - **与本案的接缝**：
      - **雕像为何是空的**：教团迎的是神，雕像却始终空着——空得下一条雏龙
      - **假神谕无人识破**：真神从不应声，雕像说什么无从对照
      - **殿内为真**：埃莱斯被骗信的「诸神已死」是假的，但这座神殿里偏偏==有人应声==
    - **桌上会被问**：「奥喀斯到底死没死？」——深渊的事没人说得准，见本条「消息时滞」

::: tip 妖鬼坟语者 Ghast Gravecaller 与食尸鬼族系

- **妖鬼坟语者==——希娅的种族，号令群尸的施法妖鬼==**

    - **族系**：食尸鬼（Ghoul），即食尸的不死生物
      - **妖鬼（Ghast）**：其中更强的形态
      - 希娅与她的食尸鬼助手皆属此族
    - **妖鬼坟语者**：本模组希娅的专属数据卡
      - **专属数据卡**：妖鬼中能==号令群尸==的施法变体（详人物数据卡）
      - 神殿里所有丧尸都由她操控
    - **食尸鬼的饥饿**：永不停歇的食尸冲动
      - **盗尸是囤粮**：希娅「盗尸补充食物储备」是字面意义的囤粮
      - **盗尸也是募兵**：也是字面意义的募兵（尸体就是未来的丧尸）
    - **桌上会被问**：「希娅多强？」——4 级团的首领位，挑战度按数据卡
      - **尸源即命门**：她的力量全在号令群尸，尸源一断她就不存在

::: tip 龙棋 Dragonchess

- **龙棋==——奈扎鲁姆唯一的消遣，破冰通道==**

    - **是什么**：费伦流行的双人对弈棋戏
      - **棋盘制式**：三块 8×8 棋盘（地表/空中/地下三层），棋子对应奇幻生物
      - **桌上用法**：规则书上桌用法按游戏套装（Gaming Set）检定
    - **本案的用法**：奈扎鲁姆被窃来的龙棋：他数周神殿生活里唯一的消遣
      - 一个人下，==自己跟自己==
      - **下棋是破冰通道**：玩家若懂棋（或愿花时间），可作接近他的破冰通道
        - **对陪玩无防备**：一条雏龙对愿意陪他下棋的人==没有防备力==
    - **桌上会被问**：「下棋能给什么？」——态度筹码，不是机制钥匙
      - **信任锚两件**：奈扎鲁姆的信任锚在「实力证明+陪他玩」
      - 棋是「陪他玩」的最佳形态

::::

- **S 源头==——四条势力线与时代底色==**

    - **时代底色**：龙狂迷锁运作的纪元，龙类整体躁动不安（感受层，见背景区）
      - **唤醒潮**：教团在各地执行唤醒奥喀斯的仪式工程
      - **神殿的复辟不是孤例**：是唤醒潮里的一支
    - **教团线**：希娅：二十年前被讨伐打散的旧教团残响，数周前夺殿复辟
      - **教团时钟**：时钟在走：修缮→盗尸→==十里献祭==祝圣（教团自己的理解，就是迎回他们的神）
      - **工程燃料**：尸体库存，既是工程燃料也是她最护的东西
      - **态势**：==远玩家，抢速==——献祭半径固定十里，玩家迟到：半径内村子遭殃
    - **龙线**：奈扎鲁姆——找巢→撞教团→打不过→==装神==
      - **三层目的**：借刀斩首（要玩家）＋安全巢穴（要神殿）＋==躲什么东西==（迷锁线，他不说，玩家推）
      - **态势**：==贴玩家，让速==——他等玩家、配合玩家节奏，三命令：主动权交到玩家手里
    - **镇线**：灰水镇：二十年前讨伐者的后代在主持重演
      - **父母遗产**：酒馆战利品墙是旧讨伐的展览，神殿地图是父母的遗产
      - **未竟之志**：欧瑞安的包袱：「我没跟上父母的脚步」
      - **态势**：静态补给+情报面，玩家的后方
    - **信仰线**：奥喀斯：不死魔君，神殿是活的信仰残躯
      - **教义实物**：绿光山羊头骨、马赛克、仪式书、祭仪密室，都是教义的物质形态

::: details 📖 「开始冒险」·欧瑞安委托（原书朗读层）

> 死亡灾星酒馆坐落于偏远山村==灰水镇==，是当地的一处奇观——它的创办人是一对冒险者夫妇，他们当年英勇讨伐了盘踞在附近山中一座奥喀斯神殿的邪教，随后退役开了这家店。如今酒馆由他们的后代经营，墙上装饰着夫妻俩冒险岁月的战利品。
>
> 你在这处当地名胜的造访却迎来一个沉重的转折：阿斯莫旅店老板==欧瑞安·索拉里斯==向你们求助。欧瑞安是位银发金眼的阿斯莫，神情认真。「邪恶回到了那座神殿，」他们告诉你们，「夜里有拖着脚走的尸首在游荡、刨开旧坟，身边跟着穿猩红袍、戴山羊面具的不祥身影。他们在偷食物、工具，还有颜料，图谋着什么见不得人的事。我敢肯定，用不了多久他们就会掀起新一轮的恐怖统治，就像我父母那个年代的邪教一样。我没有走父母那条光耀的路，但你们有能力阻止这些邪恶。」

:::
