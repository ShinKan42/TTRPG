### **城**

::: center

#### **<a id="bg-city"></a>曼塔德里斯——从贸易前哨到谎言之城**

:::

::: card

  - **地理位置**：暗湖岸边的地下城市，距布灵登石城与魔索布莱城废墟约六天路程；数十条地表洞穴汇入一条通往城心的大隧道——旅程一到六天
  - **来历三步**：
    - 入侵前：卓尔、灰矮人、地底侏儒、散塔林会商人光顾的小型贸易前哨
    - 入侵中：**格拉兹特**通过诱惑与诡计接管了城的领导权
    - 入侵后：**弗拉兹厄鲁**骗过黑暗王子、把他囚进一颗宝石监狱——现在引导这座城市的是弗拉兹厄鲁，穿着格拉兹特的伪装
  - **难民之城**：数年扩张成繁华地下都市，幽暗地域难民在此找到庇护所——**除了卓尔**：他们被公开指为召唤恶魔的罪魁，城悬赏 10gp/卓尔头，上限 200gp
  - **统治方式**：丝绸手套——不露面、不镇压，巧妙影响和操纵市民为他效力

:::

::: details 📖 原文留档：第六章开篇与引言（原书 p39·中文全文）

第六章- 曼塔德里斯并非所有恶魔都通过暴力征服。有些是通过诱惑和诡计。在入侵期间，格拉兹特就是这样接管了曼塔德里斯的领导权。此后不久，弗拉兹厄鲁欺骗了黑暗王子，将他困在一颗宝石监狱中。现在，是幻术恶魔王子弗拉兹厄鲁引导着曼塔德里斯的政治，尽管他是在格拉兹特的伪装下进行的。关于这些事件的更多细节，请参见第一章。引言在入侵之前，曼塔德里斯是一个由卓尔、灰矮人、地底侏儒和散塔林会商人光顾的小型贸易前哨。现在，多年过去了，它已大大扩展。弗拉兹厄鲁已将这个先前隐藏的社区变成了一个繁华的地下城市，幽暗地域的众多难民可以在这里找到庇护所。这位恶魔领主用丝绸手套统治着这个不断发展的城市，巧妙地影响和操纵市民为他效力。这个贸易前哨最初建在一个由数千年滴水雕刻而成的大洞穴中。在过去的几年里，它被扩大以容纳因入侵而无家可归的难民涌入。所有难民都受到欢迎，除了卓尔，他们被公开诋毁并被指责召唤恶魔到幽暗地域，并且向那些愿意追捕并杀死黑暗精灵的人支付赏金（见B1 区）。如果你有一个希望扮演卓尔的角色，与他们合作找到一种进入曼塔德里斯的方式，也许可以从散塔林会获得通行证。这样的角色可能会遇到敌意而非武装敌对。曼塔德里斯位于暗湖岸边。它距离布灵登石城和魔索布莱城的废墟大约六天的路程。有数十个来自地表世界的洞穴和裂缝蜿蜒进入一条通往城市中心的大隧道。这些地下通道的存在曾经是散塔林会独有的秘密。然而，随着城市的发展，它的声名也随之增长，现在这些隧道被任何数量的派系和旅行者自由使用。根据使用的入口，从地表到曼塔德里斯的旅程可能需要一到六天。曼塔德里斯很重要，因为它是角色们被派去寻找的地底侏儒怀斯隆的家（见B10 区）。它也为第七章至第九章中概述的冒险提供了一个行动基地。更一般地说，曼塔德里斯可以作为被遗忘国度的末日中任何以幽暗地域为基础的冒险的友好定居点。

:::

::: details 📖 原文留档：城内概况（原书 p41·中文全文）

曼塔德里斯内部这座城市位于一个巨大的洞穴内，天花板高50 英尺，由自然形成的石柱支撑。附魔石灯柱的光芒反射在嵌入的道路上，这些道路醉醺醺地蜿蜒穿过一堆杂乱无章、不匹配的建筑。到处都是水，从天花板上滴落，形成水坑、池塘和溪流。由于潮湿，霉菌和真菌大量繁殖，在每个可见的裂缝和缝隙中都不同程度地生长。可以看到地底侏儒、灰矮人和人类在城市中行走，他们中的许多人戴着奇怪的石头面具。如果角色们询问怀斯隆，他们会被指引到B10 区。孢子面具为了应对侵染了幽暗地域大片区域的孢子，地底侏儒工匠们创造出了一种石制防护面具。这些装饰性的面具可以被雕刻成各种生物的模样，其中以枭熊的造型最为流行。面具内部嵌有纤薄的菌类切片，用以净化吸入的空气。这种面具通常售价10 金币。任何佩戴此面具的人，在对抗孢子的豁免检定时具有优势，但在进行感知检定时具有劣势。在城市中漫游时可能遇到的遭遇包括：

### **神魔**

::: center

#### **<a id="bg-princes"></a>弗拉兹厄鲁与格拉兹特——被囚的王子与替身的王子**

:::

::: card

  - **弗拉兹厄鲁（欺瞒王子）**：幻术恶魔领主，「所有谎言之父」。本卷的隐形城主——B2 狱火囚徒的幻象、B12 希瑞克神殿、B17 银色宫殿，全城三座最大建筑都是他的作品
    - 正典性格：以谎言为艺术品；不愤怒不报复，只是**重新讲述现实**
    - 在本卷：不追求摧毁曼塔德里斯——他要一座**繁荣、糊涂、什么都信**的城
  - **格拉兹特（欢愉黑暗王子）**：被囚的真城主。他的深渊存在仍玷污着访客灵魂——享乐冲动变燃烧执念（全城区域效应见机制章）
    - 正典性格：傲慢、诱惑、以享乐腐蚀万物
    - 在本卷：宝石监狱中缺席——但城门口的牌匾、舞会的名义、市民的暴食，处处是他的空壳签名
  - **两人恩怨**：弗拉兹厄鲁骗囚格拉兹特：恶魔领主政治的缩影——领主之间没有忠诚，只有下一次背叛。这座城本身就是一个「王子被王子替代」的故事

:::

::: center

#### **<a id="bg-cyric"></a>希瑞克——谎言之神的空壳**

:::

::: card

  - **希瑞克是什么**：疯癫与谎言的邪神，象征是无颚头骨。末日里他「死了」又没死——信徒散落，神殿空壳
  - **空壳在此**：B12 神殿挂着希瑞克的名号，里面没有希瑞克——祭司是弗拉兹厄鲁教徒，整座神殿是恶魔领主送出的幻象礼物
  - **怎么用**：末日信仰真空的样本——众神被维克那杀死的传言下，一座挂神名的建筑照常开张，拜的是别的东西。**连信仰都是租的**

:::

**误读场两处**：
- **B2 狱火囚徒**——初读：这座城有正义（恶棍在受罚）；真读：假正义是统治工具——牌匾落款格拉兹特，火焰是幻象。误读方向：敬畏，真相：工具
- **B12 希瑞克神殿**——初读：末日里信仰还在（总算有个真神殿）；真读：整殿是弗拉兹厄鲁送的幻象礼物——**连信仰都是租的**。误读方向：安慰，真相：幻象产业链

### **E——体验命题**

::: card

  - **世面课**：卷一学会在蘑菇世界里活着，卷二学会**人怎么活着**——享乐、欠债、说谎、假装没事
  - **两个推销员（主题极，处处体现）**：
    - 城卖**假解药**：甜、慢、体面——石酿、舞池、「平安无事」
    - 祖格莫伊卖**真解药**：快、彻底、要你的全部——孢子低语说「放下吧」也真给你放下，代价是你这个人
    - 玩家全程站在两个推销员中间；Ch5 乞求卫兵「请。杀。我。」已是真解药的免费试吃
  - **入城三拍**：城先给你三样东西——恐惧（头颅墙）、秩序（精金门）、价格（入城费）——这座城靠什么运转，一目了然

:::

## **🏙️ 全城机制**

#### **<a id="mech-taint"></a>区域效应——双领主之玷（原文）**

:::

::: card

  - **格拉兹特之玷（享乐执念）**：
    - 欲望变燃烧的执念——市民因不受控的暴食而发胖，血丝的眼睛映着宿醉
    - 机制：角色在曼塔德里斯期间**所有感知豁免检定具有劣势**
    - 扮演：鼓励玩家放大自己角色的理想、羁绊与缺点
  - **弗拉兹厄鲁之影（谎言顺滑）**：
    - 机制：**欺瞒检定具有优势**；辨别幻术的检定具有劣势
    - 《真视术》《诚实之域》在城内**不起作用**——施法者本人察觉不到这一点

:::

::: details 📖 原文留档：区域效应（双领主之玷·侧栏）（原书 p39-40·中文全文）

区域效应。尽管被囚禁，格拉兹特的深渊存在仍然玷污着访问曼塔德里斯的人的灵魂。享乐主义的冲动变得越来越难以抗拒。小小的欲望变成了燃烧的执念。这个地下城镇的市民因其不受控制的暴食而体重增加，他们血丝的眼睛反映出睡眠不足、宿醉，或常常两者兼有。在机制上，这种腐化表现为角色们在曼塔德里斯时所有感知豁免检定都具有劣势。在角色扮演方面，考虑鼓励玩家放大他们任何相关的理想、羁绊或缺点。弗拉兹厄鲁的影响更为微妙，但同样强大。欺瞒(Deception)检定具有优势，而辨别幻术的检定则具有劣势。像《真视术》和《诚实之域》(zone oftruth)这样的法术在曼塔德里斯不起作用，尽管这对施法或使用这些法术的人来说并不明显。

:::

#### **<a id="mech-mask"></a>孢子面具（原文）**

:::

::: card

::: details 📖 原文留档：孢子面具（侧栏）（原书 p41·中文全文）

为了应对侵染了幽暗地域大片区域的孢子，地底侏儒工匠们创造出了一种石制防护面具。这些装饰性的面具可以被雕刻成各种生物的模样，其中以枭熊的造型最为流行。面具内部嵌有纤薄的菌类切片，用以净化吸入的空气。这种面具通常售价10 金币。任何佩戴此面具的人，在对抗孢子的豁免检定时具有优势，但在进行感知检定时具有劣势。

::: details 📖 原文留档：B4 石酿酒坊（原书 p42·中文全文）

B4. 石酿酒坊(Stoneschlager Brewhouse)由于曼塔德里斯的大多数居民几乎每天都饮酒，随着他们耐受性的不断增加以及供应量的减少，问题开始出现。一位名叫布罗格拉·石心(BroglaCobbleheart)的企业家地底侏儒迅速解决了这个问题，他恢复了古老的矮人石头发酵传统，创立了石酿酒坊。石酿酒坊是一座由从遥远的蛇人定居点开采的蛇纹石块建成的大型建筑。它被一圈柔软的苔藓环绕，醉酒的顾客可以在上面睡去他们的昏沉，然后再摇摇晃晃地回家。酿酒厂的前半部分是一个熙熙攘攘的酒吧，常常只有站立的空间，而后半部分则充满了用来发酵和酿造酒吧招牌石酿(stoneschlager)的奇异装置。内部应该充满了呕吐物的恶臭；然而，布罗格拉付钱给一队轮换的学徒巫师，让他们定期施放《魔法伎俩》(prestidigitation)来掩盖臭味。酒馆最受欢迎的饮料是花岗岩狂饮(granite guzzlers)和页岩烈酒(shale shots)，任何一种都可以用1 sp 购买。富有的享乐主义者可以通过亲自支付布罗格拉50 gp 来制作一品脱她臭名昭著的金酿(goldschlager)，从而字面意义上地消费他们自己的钱。一个角色如果饮用任何这些饮料，必须成功通过一次DC 10 的体质豁免检定，否则会陷入中毒状态，直到完成一次长休。由于格拉兹特的区域影响，该角色还必须成功通过一次DC 10的感知豁免检定，否则会立即渴望再喝一杯。每多喝一杯，豁免检定的DC 增加一。任何中毒的角色如果体质豁免失败，会遭受一级力竭。角色扮演。这里的大多数顾客都喝得酩酊大醉，行为举止也相应如此。服务员薪水低，工作过度，因此对闲聊不感兴趣。交谈不仅因为醉酒的喧嚣而变得更加困难，还因为从后台传来的石头研磨声，布罗格拉大部分时间都在那里。这位地底侏儒是一个工作狂，她几乎不睡觉，因为她完全沉浸在她的手艺中。她通常很孤僻，尽管角色们可以通过购买一品脱金酿来赢得她的注意。在这种情况下，她会热情地带角色们到后台，向他们展示酿造过程。任务。如果角色们能引起她的注意，布罗格拉对未来的产品有许多奇特的想法，包括用发酵的蠕虫岩或血石制成的饮料。布罗格拉会很乐意为一磅蠕虫岩支付角色们100 gp，并为带给她的任何血石支付其价值的一百五十个百分点。她建议角色们可以在虫缠迷径找到蠕虫岩，并且在心灵异能者城市赛罗格附近有一个废弃的血石矿。
