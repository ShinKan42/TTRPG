## 0. 背景知识索引

- **克罗库玛（Krokulmar）**：[模组原创] 遥远国度实体。非官方设定集生物，模组自定义，可替换为任何合适的异界存在
- **遥远国度（Far Realm）**：[DMG 第 2 章 / MM 边栏] 异次元空间，与物质位面的物理法则完全不同。从这里来的生物通常具有触手、眼睛、嘴巴等身体恐怖特征
- **密斯特拉（Mystra）**：[PHB 附录 C / DMG 第 4 章] 魔法女神，掌管织法（The Weave）。邪教徒"赐予"的奥术法术与密斯特拉领域一致，但源头是遥远国度——这是一个**伪装**，不是密斯特拉的力量
- **术士 vs 法师**：[PHB 职业描述] 术士的魔法来自血脉/天赋（先天的），法师的魔法来自学习/研究（后天的）。马寇斯以为是后者，实际是前者
- **秘法锁（Arcane Lock）**：[PHB] 二环变化系法术，锁定门/窗/容器。密码解除是常见变体
- **深潜语（Deep Speech）**：[PHB 第 2 章 / MM 边栏] 遥远国度相关生物使用的语言。法尔弗-赫拉克=深潜语"永恒变化"
- **卜筮术（Augury）**：[PHB] 二环占卜系法术，获得关于未来 30 分钟内行动结果的预兆（吉/凶/吉凶参半/无结果）

## 2. 暗流

### S——从哪来

**马寇斯·德尔斐真诚相信自己是密斯特拉神选。** 他的目标是带来"人人都能用法术的天国"。

**真相**：马寇斯出生在法师世家，但他是术士——一个"学不到法术"的孩子。他拥有的天赋从未被正确激活。克罗库玛做的不是从零给予魔法，而是**激活了他体内已有的东西**。马寇斯一直以为自己是法师——家人也这么以为——但没人知道他其实是术士。

克罗库玛 = 一次性威胁。它利用马寇斯的骄傲和对认可的渴望——一个法师家族里"学不好法术"的孩子，突然被告知"你是被选中的"。克罗库玛没有复杂的长期计划，它就是想穿过来看看。

马寇斯的塑造问题 = **法师家庭出人头地的压力**。

**结局**：马寇斯醒来后理想主义崩塌。魔法天赋还在（术士天赋是先天的），但克罗库玛的增幅没了——他变回原本"稍弱"的水平。不够在家族面前得到认可，只能作为"孩子"被领回家。

**密码链**：星座名（天文术语），实际是深渊语。窗户=短名"克罗库玛"，祭坛=全名/坐标（待初稿造词）。

**D24 雕像**：表面上密斯特拉形象，实际是克罗库玛魔力导体。邪教徒是==真诚的密斯特拉信徒==——他们不知道真相，真心相信自己在做善事。

**邪教徒法术**：赐予的是奥术（非神术），和密斯特拉领域一致。源头实际是遥远国度。

### E——体验命题


三个"**真假判断**"：

::: table
| 对象 | 判断 | 本质 |
|------|------|------|
| 马寇斯 | 错 | 但真诚——他真心相信自己在做对的事 |
| 艾尔拉 | 不确定 | 她的判断是对是错？上去和下去各有代价 |
| 邪教徒 | 错 | 但真诚——他们真心信仰密斯特拉 |

:::

**情感落点**：马寇斯醒来魔法掉回原点，被家人轻描淡写领回家。

**身体恐怖**：**还好，小事**。

### 走向——齿轮随时间的演化

- **任务开局（双动机）**：**马寇斯家人**雇佣冒险者带回尸体提供复活——轻描淡写=审视与误解的一环；**瓦西尔**要找回《天界典籍》。黄金宝库委托可选
- **村庄阶段**：完美天国运转中，玩家建立「不对劲」的 感官档案（法术太一致／对话被调校／食物苦味）
- **庄园阶段**：战斗梯度推进（一层→二楼→三楼→地下），魔能浪涌随施法与探索持续触发；马寇斯真相的信息链逐步闭合（D11b 信件→D15 卧室→D24 祭坛→马寇斯自述）
- **管家战（D19）**：挂坠盒=酒窖密门的钥匙之一；红漆地板=可点燃的战术资源
- **仪式时钟（D27）**：马寇斯每回合附赠动作维持仪式，**超过三次=肢节完全占据尸体**——boss 战自带倒计时；四颗水晶=可逐颗拆解的保护层
- **克罗库玛被驱逐后**：扎拉和埃斯奎尔恢复人形，D24 邪教徒逃跑——庄园异变可逆，人物可救

::: details 魔能浪涌设计逻辑

原版 d4 表是**战术变化标杆**——每条都改变玩家决策（移动路线/撤退代价/战斗节奏/行动经济）。新增条目（5-8）在战术影响基础上叠加**身体恐怖**（魔改层）：关节反转、金属融合、器官位移、异体生长。两条腿缺一不可——只做战术=干瘪数值修正，只做恐怖=不能影响玩法。

:::

### D27 仪典室（Boss 战）

**暗流**：马寇斯在这里举行仪式——将克罗库玛肢节附着到艾米莉的无首尸体上。他在自己的每个战斗回合用附赠动作维持仪式，如果超过三次附赠动作，肢节就完全占据尸体。

**场景逻辑齿轮**：
- 四颗水晶 = **保护层**（先打碎解除 boss 特殊保护）。每颗水晶=大型物件，AC 13，10 hp，钝击和雷鸣易伤。每摧毁一颗，马寇斯该回合攻击/检定劣势
- 无首尸体处于**震慑状态**，持续至仪式结束。攻击肢节可以不伤到尸体
- 马寇斯每回合用附赠动作维持仪式，超过三次附赠动作则肢节完全占据尸体（尸体不再震慑）
- 红漆地板 = 易燃（管家铺设的仪式准备）
- 信众（D24 的邪教徒）可能来支援 = 结社施法
- 艾米莉的无首尸体 = D27 的无首骑士身躯

**协助马寇斯**（原文机制）：角色可用一个动作进行 DC 14 魅力（游说）检定说服马寇斯他被操控。成功→马寇斯克制心魔，攻击/检定劣势至下一回合结束。失败→无事发生，动作浪费

**结束威胁**：四颗水晶全毁 + 肢节或尸体被降至 0hp / 马寇斯在仪式完成前被降至 0hp → 肢节回到遥远国度，浪涌停止，马寇斯获救。扎拉和埃斯奎尔恢复人形，D24 邪教徒逃跑

### 艾尔拉的营地

接近庄园 1 英里时，艾尔拉的幽灵头颅出现。她指引角色去她生前营地（庄园南面悬崖）——营地里有庄园地图 + 三张便条（从邪教徒身上搜来）：

1. "马寇斯用以施放仪式的房间位于三楼。"
2. "在地基之下有一个存放着四颗巨大水晶的房间，其作用无从得知。"
3. "庄园的窗户可以通过念出'克罗库玛'来开启。"

**注意**：便条 1 说仪式在三楼——实际仪式在地下 D27。这是艾尔拉队伍被误导的信息，也可能是仪式曾经在三楼进行过。
