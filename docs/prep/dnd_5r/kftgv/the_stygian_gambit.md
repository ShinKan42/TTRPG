#### <a id="bg-mammon"></a>九狱与玛门 Mammon
:::

- **玛门是谁**——九狱第三层**弥瑙洛斯 Minauros** 的统治者，大魔鬼；贪财之魔——对金子的闪烁爱得痴迷，万魔殿中公认的最富有者
- **与本案关系**——昆汀为实现赌场之梦把自己的灵魂卖给了玛门；玛门派下属帮昆汀联系法师团队建造并装饰赌场——==赌场本身就是玛门从主物质位面抽金子的管道==，这座建筑是魔鬼的资产
- **命名即献祭**——赌场九大区域按九狱九层逐层命名（阿弗纳斯/迪斯/弥瑙洛斯/玛尔博吉/弗莱格索斯&斯泰吉亚/马拉多米尼/卡尼亚/奈瑟斯/金库），主题不是装饰是**效忠声明**；伟大弥瑙洛斯邀请赛=向主人献祭的公开仪式
- **带团注**——偷走欲魔雕像+金库金币=当着九狱主人的面掐断管道——昆汀的恐惧不只是商业羞辱，是==对玛门无法交代==

#### <a id="bg-styx"></a>冥河 Styx 与「来世」命名
:::

- **真正的冥河**——通往来世（下层位面）的河流；触碰或吞下河水会夺走记忆（魁伟存在与神明亦不能免）
- **赌场的「冥河」**——通往赌场的天然洞穴由一条河流侵蚀而成，昆汀借冥河之名把它与公司一并命名为「来世赌场」——==凡人谐仿神圣地理==，船夫扮演卡戎、两枚硬币渡资的细节都从这条命名生长出来
- **带团注**——赌场河没有冥河的记忆剥夺效应（原文无此设定）；但「这条不是真冥河」的落差本身是桌面可玩的——懂行的 PC 会紧张，不懂行的 PC 会被氛围骗到

::: details **结局——原文**

**结局Conclusion**

冒险结束时，角色们带着夺宝的成果，或昆汀的信，抑或什么都没有回到维里蒂·凯身边。

**带着战利品返回Returning with the Loot**。如果角色们带回了雕像和钱，则维莉蒂会很高兴。她会付钱给角色们，并感谢他们的服务。

**空手而归Returning Empty-Handed**。如果角色们空手而归，维莉蒂会很失望。但如果他们愿意的话，她会给他们更多证明自己的机会。

**带着昆汀的信返回Returning with Quentin's Letter**。如果角色们没有带着战利品回来，但把昆汀的信给了维里蒂，她会在愤怒的沉默中读这封信。然后她会让角色们离开，并没有给他们任何报酬。

**为黄金宝库工作For the Golden Vault**。如果角色们成功抢劫了赌场金库，维莉蒂会确保黄金宝库知道角色们的成功。她还告诉角色们，他们有权选择一件非普通的魔法物品（经你批准）作为取回雕像的报酬。该物品将在第二天交付给角色们。

::: details **三龙牌 d12 规则——原文**

三龙牌是一种纸牌游戏。如果你和你的玩家有真正的三龙牌卡组，那么你们可以在场外玩真正的三龙牌。否则可以使用d12骰和以下规则判定三龙的游戏结果：

第一步。随机确定哪个玩家是庄家。

第二步。每个玩家（包括庄家）公开下注，然后骰 5 次 d12确定各自手牌，这些掷骰结果对其他参与者保密。

第三步。从庄家左侧开始，按顺时针方向依次进行，每位参与者都要亮出自己的一个骰子。这一步骤会再重复两轮；在第二轮和第三轮，每位参与者都可以在揭示下一个骰子之前加注。其他参与者有三种选择：跟注、加注（在这种情况下，所有参与者必须依次跟注）或弃牌，放弃所有赌注并退出游戏。

第四步。每个没有退出的玩家合计他们的骰子点数。总点数最高的赢。获胜者成为下一局游戏的庄家（假设参与者想继续玩下去）。

::: details **乘船入场——原文**

一个穿着沉重、厚实且带有兜帽的长袍的提夫林船夫（平民Commoner）静静地等待着把角色们送到赌场。这个船夫扮演着冥河上的卡戎（希腊神话中的冥府渡神）的角色。提夫林船夫会一直戴着兜帽，不会跟乘客说话。如果角色们碰触了船夫，或者试图拉开其兜帽。船夫就会打断角色们的行为，要求他们停下来——提夫林船夫只是在做他的工作。

摆渡船巧妙地引导船顺流而下，进入地下通道。当你被洞口吞没时，你听到远处瀑布的回声中传来音乐。洞穴的天花板高过头顶，舞动的灯光在悬挂的钟乳石周围摇曳。这条河蜿蜒地穿过赌场的地板，将这个洞穴赌场一分为二，并在不同的地方从拱形石桥下流过。开阔的场地上满是牌桌和游戏台，每台桌子周围都挤满了叽叽喳喳的顾客。从洞穴深处传来一阵阵欢呼声，寓意着此地充满无节制的兴奋和无限的机遇。

船夫把船驶向左岸，随后摇摇晃晃地撞靠在一个木码头。然后船夫举起一只手，指着你面前纸醉金迷的景象，用低沉沙哑的声音吟唱道:"欢迎来到来世。无尽的诱惑在等待着你们。"

### 赌场通用特征

::: details **赌场特征——原文**

来世赌场建在一个天然的洞穴里。下面几节将介绍它的通用特征。

**收银台Cashier Stations**。赌场有四个收银台（在区域 A2 和 A4），在那里有带着微笑魔鬼面具的收银员（平民 Commoner）提供兑换零钱或将现金换成筹码的服务。赌场的筹码由涂了漆的薄木盘制成。每块筹码的两面都印着赌场的标志：一把金色长柄叉。

收银员身边并没有现金，而是使用收银台魔法印记。收银员把钱放在魔法印记上，就可以直接把钱送到金库；他们也用相同的方法从金库取出钱。超过250 gp的提款需要另一位收银员确认交易。通过这些魔法印记进行的交易将自动记录在职员办公室（A15区）的魔法账簿中。

**天花板Ceilings**。赌场公共区域的天花板有50尺高，上面悬挂着钟乳石。员工专用区域的天花板有20尺高，而且很平整。

**门Doors**。赌场内部的门是木制的。秘法锁Arcane Lock 被施在了通往员工区、金库走廊和金库的门上。这些门都有亮绿色的装饰，对游客来说很明显。（在地图2.2中，这些门用圆点标记，表示它们是锁着的。）

赌场工作人员使用通行卡（见本冒险前文"员工通行卡"）绕过门上的秘法锁Arcane Lock。此外，成功通过一次DC 25的力量（运动）检定也可以强行打开门。

**员工专用区域Employee-Only Areas**。进入员工专用区域需要通行卡（见本冒险前文"员工通行卡"）。保安在员工专用区域遇到未经授权的人，会立即把他们带出去。如果角色们反抗，警卫会试图逮捕闯入者并将他们带到拘留室（区域A17）。

**光照与音乐Lights and Music**。赌场由精心设计的舞光术Dancing Lights 照亮，看上去像是炼狱火焰。这些光芒在不同的高度上下浮动。员工通道里则维持着不灭明焰Continual Flame。

整个赌场播放的音乐都是虚幻飘渺的，听起来很像牛仔乡村音乐。在员工专用区域，音乐播放得更加轻柔。

**保安Security Guards**。五名提夫林保安（使用暴徒 Thug 的资料卡）在赌场楼层巡逻，还有第六个站在装有欲魔雕像的展示柜旁（在区域 A9）。如果角色们引起了骚乱，离他们最近的保安就会走向他们，试图不诉诸暴力来平息骚乱。如果受到攻击，保安会以牙还牙，大声呼救。其他保安会在三轮内到达。

**安保镜Security Mirrors**。整个赌场遍布安保镜，每一面都固定在离地面12尺的墙壁上，呈向下倾斜的角度。侦测魔法Detect Magic 可以探测到每个镜子周围都有预言系魔法灵光。安保镜是大型物件，拥有AC 13，5点生命，免疫毒素和心灵伤害。

除了普通的镜子功能，每面安保镜还都是一个魔法探知装置，让保安办公室（区域 A16）的保安能够透过它看到东西，就像透过一扇窗口观察。以安保镜为目标施放解除魔法Dispel Magic会抑制其魔法效应10分钟。

打碎一面镜子或抑制它的魔力都会导致区域A16的两名保安前来调查，并向昆汀报告了他们了解到的情况。

**作弊Cheating**。在赌博之中作弊被抓到的顾客会被1d3个保安（使用暴徒Thug的资料卡）押送到拘留室（区域A17）。作弊者会被关一天，然后在第二天黎明由保安护送到一艘船上，并被警告永远不要回来，然后被送往上游。

**墙壁和地板Walls and Floors**。围绕赌场外沿的墙壁是由粗糙的自然雕刻的石头制成的。内墙由2尺厚的石头砌成；这些墙看起来很自然，但其实是用塑石术Stone Shape塑造的。地板是用光滑的石头铺成的，上面铺着花哨的地毯。
:::

- **收银台×4**（A2/A4）——微笑魔鬼面具收银员；筹码=涂漆薄木盘双面金色长柄叉；无现金=魔法印记直连金库；>250gp 提款需双收银员确认；全部自动记录 A15 魔法账簿
