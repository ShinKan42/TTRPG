::: tip 地狱屋 Hell House——用恐怖布道的万圣节鬼屋

- **文化注·地狱屋==——用恐怖布道的真实现象==**


  - **真实现象**：非作者杜撰
    - **形制**：极端保守教会办的万圣节「鬼屋」
      - 恐怖布景＋演员表演「罪的代价」
        - 目的是吓人悔改
    - **源流**：1970 年代初起源，1990 年代中期扩散
      - **出圈**：2001 年纪录片==《Hell House》==将其带入公众视野
        - 原书推荐 KP 观看
    - **出口设计**：参观结束设「救赎选择」
      - 志愿者当场带你祷告、归向基督
        - ==天堂帐篷的原型==
  - **分野**：与游乐鬼屋
    - **对照**：常规鬼屋吓完就完；地狱屋的每一吓都是布道
      - ==恐怖是手段，悔改是目的==
  - **作者注**：本模组对地狱屋的呈现没有夸张，有些地方还淡化了
  - **桌上用法**
    - **演足表演性**：调查员初到屋内，把六房间的「表演性」演足
      - **道具**：假的血、塑料魔鬼尾巴、橡皮恶魔角
    - **反差**：玩家以为这只是怪趣味布景时
      - 真死亡就在同一栋屋子里发生
  - **玩家接触层**：招募帖==「用恐怖布景布道」==一句即可，地狱屋概念留桌上展开

::: tip 「死于罪中」——凯莉葬礼的神学

- **文化注·「死于罪中」==——葬礼戏的教义地基==**


  - **教义**：自杀在福音派信仰里是不可赦免的罪
    - **礼制后果**：死于罪中的人不下教会墓地礼仪
      - 韦弗牧师拒绝在教会办凯莉的葬礼
    - **悼词**：他在墓前致悼词，称她「被认识的人爱着、聪明又体贴」——
      - 却==全文避开上帝与救赎==
    - **真心**：他真心相信凯莉已下地狱，为此悲伤
      - 但相信神的审判是终局
  - **定性**：这不是恶毒，是教义——韦弗按信仰行事，越虔诚越冷酷
  - **桌上用法**
    - **葬礼戏的感情重心**：一位牧师真心悼念一个他确信已被定罪的女孩
    - **对峙的墙**：米奇当众对峙就撞在这堵墙上
      - **墙的材质**：牧师不是隐瞒，是信仰不许他说「她安息了」
  - **玩家接触层**：A 钩开场即葬礼——此条为葬礼戏第一块地基
