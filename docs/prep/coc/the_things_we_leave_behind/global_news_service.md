## 🧭 题材与体制补注

::: tip 通讯社与 stringer 体制

- 通讯社自己不发报——稿子卖给各大电视网
- stringer（特约供稿人）＝没有编制的本地供稿人：按篇结账、无保险无底薪，稿子卖不掉这个月就没饭吃
- GNS 卖的是小报商品：桃色、名人、犯罪——「煽情」是卖点不是缺陷
- 定位=各大台的**脏手套**：大台想看丑闻又不想脏手，雇 GNS 去挖（行业术语：维持 plausible deniability，可推卸责任）
- 桌上直接后果：调查员每一次越界都有人买单报销，但被逮住时顶雷的也只有你们

:::

::: tip Kolchak 谱系——「撞鬼的记者」类型片

- 1974 年美剧《Kolchak: The Night Stalker》（卡尔恰克：夜行者）：一个总在凶案现场撞见怪物的记者
- 每次拿到铁证都被编辑部毙掉；警察懒得抓他——「没人在乎这个人」
- 要演的调子：永远追着警笛跑、镜头比命重要、离改变世界的 footage 永远差一步
- 同源推荐：《电视台风云》Network（1976，直播中崩溃的王牌主播——Hot Mess 模板的原型）

:::

::: tip 「残缺者」建卡规则的叙事逻辑

起始 SAN −2D10｜幸运 +3D10（上限 99）｜技能点 EDU×6

- 这不是数值补偿，是类型片契约
- 还能接到活的记者全是伤痕累累的老油条（SAN 低）
- 个个运气反常地好（幸运高——题材惯例：照片会被没收，人总能脱身）
- 什么都干过一阵（EDU 加成=那些被开除过的岗位）
- 向玩家解释的正确心态=「我们不是英雄，我们是来拿画面的」

:::

## 🕳️ DM 专区

:::: details 招募真相

- GNS 在你最低谷时**接管过你的人生**：一段消失的时间、醒来时的陌生公寓、莫名解决的官司、突然缓解的仇家
- 代价=左耳后植入物——巫术生物芯片，配方：受术者血液＋Geraldine 卵子＋一次血祭＋手机芯片改装符印（Narlato 印记变体）
- 功能三合一：**追踪器＋监视器＋脑瘤开关**
- 一年期满可以体面离开——前提是从不外泄
- 人员账：2001 年重组以来 37 名供稿人，10 名死亡或失踪
- 唯一干净离开的人：Bob Tyler（新泽西，绝口不提 GNS）——他怕 Geraldine，因为她影子的形状不对

::::

:::: details 谁是老板

- Tony Patel 及历代「家族前辈」（自 1914 年起同一支电话号码）＝同一个存在＝奈亚拉托特普化身，驻拉斯维加斯
- GNS 是他给人类「温水煮真相」的长局——让社会慢慢消化超自然的存在
- Geraldine＝1603 年塞文河谷女巫「左手卢克蕾西亚」的第七十几个马甲；1951 年吃了原主 Estelle Winthrop 换皮
- 另一马甲=中年女精神科医生（招募仪式主持人）
- Vince 无辜，什么都不知道
