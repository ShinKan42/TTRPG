:::: details Recruit No. 38：招募剧本真人演示

Jules Thomas，26 岁，卡头判词「Complete Jackass Paparazzo」（彻头彻尾的混账狗仔）。洛杉矶富家子：父亲是混得不错的好莱坞导演，母亲是八十年代 B 级片「尖叫女王」退休。人生坐标只有一个——够上家里的成功线，而他没够上。

技术是真有：剪辑、镜头戏法、电脑特效。少年案底也真有，照样考进了 UCLA 电影系。大一学年期末那晚的兄弟会派对「发生了点什么」——他自己完全不记得；只知道第二天早上父亲赶来保释，把他直接送去英国；一个女生的死被裁定为意外；大学哥们儿从此没人接他电话——**其中至少一个被父亲花钱封了口**。

在伦敦小报《The Weekly Eye》干了三年「技术摄影专家」，绝活是拿「钞票镜头」：光纤、strategically 摆放的高反光面、把别人的无线设备改造成「僵尸相机」。去年他黑一个从没听说过的公爵夫人的手机——被穿特种部队装备的人一针扎进脖子。手机上看到了什么，他不记得了；只是从那以后睡不好。

醒来时在内华达 Henderson 一套不错的公寓，行李都在，==丢了两周==。守着他的是个不肯报名字的中年女西装——他一眼认出那是精神科医生：「这些年爸爸送他去过够多了。」她摊牌：这是你最后的机会，**你爸问候你**。他想走；她放出一段那晚派对的手机录像——他从未见过的机位。他坐下，闭嘴。

条件：只为一家的自由供稿；住拉斯维加斯随叫随到；克利夫兰 Skype 派单；底薪养不活自己，猛料重赏；「只要你干活，你的『过去的不检点』就伤不到你。不干的话——公爵夫人朋友很多。那个女学生也是。」去年他挣了 ==25 万美元==。收尾一句原文：**他连做梦都没想过辞职。**

  - 53 岁，卡头判词「Stressed Out Heart Attack In The Making」

    - SAN 35
  - 数据卡最说明问题
    - Fast Talk 10%、Intimidate 0%——天天咆哮拍桌的人，哄骗和威吓双零蛋
    - 真高分是 Library Use 70
  - Kent State 新闻系（就在俄亥俄）
  - 来历：克利夫兰报纸大裁员第一批被裁、**遣散费一分没拿**；2001 年重组后第一个员工
  - 住办公室楼上；没老婆；朋友只有几个牌友——==他的人生就是 GNS==
  - 职权幻觉：他可以「炒你」，五分钟后反悔
    - 真正的解雇由 Patel 决定，坏消息由 Geraldine 宣布

  - 两样真本事：**卖稿**，和**把稿子改得更可信**

    - 所以专门把颗粒感模糊照片圆成说得通的自然事件

### **瓢虫收尾的用人标准 ✅**

:::

:::: card

- 需要精神科帮助的、对所作所为严重不安的、真心为蕾吉娜难过的、想喝个烂醉忘掉这一切的

## **🧭 题材与体制补注**

:::

::: info 通讯社与 stringer 体制

- 通讯社自己不发报——稿子卖给各大电视网
- stringer（特约供稿人），就是没有编制的本地供稿人
  - 按篇结账、无保险无底薪
  - 稿子卖不掉，这个月就没饭吃
- GNS 卖的是小报商品：桃色、名人、犯罪——「煽情」是卖点不是缺陷
- 定位是各大台的**脏手套**
  - 大台想看丑闻又不想脏手，雇 GNS 去挖
  - 行业术语：维持 plausible deniability，可推卸责任
- 桌上直接后果：调查员每一次越界都有人买单报销，但被逮住时顶雷的也只有你们

:::

::: tip Kolchak 谱系——「撞鬼的记者」类型片

- 1974 年美剧《Kolchak: The Night Stalker》（卡尔恰克：夜行者）：一个总在凶案现场撞见怪物的记者
- 每次拿到铁证都被编辑部毙掉；警察懒得抓他——「没人在乎这个人」
- 要演的调子：永远追着警笛跑、镜头比命重要、离改变世界的 footage 永远差一步
- 同源推荐：《电视台风云》Network（1976，直播中崩溃的王牌主播——Hot Mess 模板的原型）
