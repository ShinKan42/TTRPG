## **🎬 GNS 战役总览**

:::

:::::: card

- 调查员不是超自然侦探——是==要钱不要命、浑身毛病的记者和狗仔==
- 他们不找怪物、起初也不在乎怪物，只是不知为何总撞上
- 答案：他们最后的雇主、新闻业里最后的机会，就是全球新闻社
- 而 GNS 不是它看起来的样子

::::: details ✍️ 书的来历与作者意图（评语 · 可跳过）

**书的来历是一个电视迷的较真**

作者看 1974 年美剧《Kolchak: The Night Stalker》其中一集——恰好就叫 "We Have Been, We Are, We Will Be"——看出了三个元问题。

剧里那个记者撞上一个隐形的爱手艺式怪物。

他目睹铁证，看着它把成群的警察无形地甩飞，甚至找到了它偷遍芝加哥物资修好的飞船。

可他只能报道出最不痛不痒的零碎——太离奇的部分全被主编毙掉。

更怪的是，围捕现场那么多警察和政府官员，居然放这个记者自由离开（作者打了感叹号）。

:::::

:::: details DM 真相（玩家不可见）

- GNS 是 Patel 经营的长局骗局
  - Patel 是奈亚拉托特普化身：温文尔雅，基本不使用暴力
  - 秘密驻于拉斯维加斯
- 一台自我供血的肮脏机器
  - 设计用途：==嚼碎吐出那些正在堕入疯狂与毁灭的末路记者==
- 他要用社会自己的「真相捍卫者」之口，一点点喂出真实真相的碎片
  - 把社会腌入味，让它接受越来越大的真相
- 他要的效果精确到剂量
  - 模糊的照片、掩盖的指控、给偏执狂的燃料
  - 「缓慢而稳定的堆肥，通向更深的启示」
- 他给愿意为一个故事一张钞票出卖灵魂的人提供手段
  - 等他们抵挡不住「最后一条独家」的诱惑时，就连人带魂收下
